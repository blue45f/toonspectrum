# Rust crate 작업 규칙

이 디렉터리에서는 루트 `AGENTS.md`와 이 규칙을 함께 적용한다.

- 공개 API, FFI/WASM 경계, 메모리 소유권과 오류 모델을 먼저 정의한다.
- `unsafe`는 최소 범위에 두고 안전 조건을 한글 주석과 테스트로 증명한다.
- panic을 정상 제어 흐름으로 사용하지 않으며 JS/WASM 호출자에게 안정적인 오류를 반환한다.
- 성능 변경은 실제 병목 근거와 전후 측정 없이 복잡도를 늘리지 않는다.
- vendor 코드는 직접 수정하기보다 원본·패치·라이선스 경로를 명확히 한다.
- 관련 `cargo fmt`, `cargo clippy`, `cargo test`와 상위 JS/WASM 통합 검증을 실행한다.

# ToonStudio Character Pipeline Blender Extension

`toonstudio_blender_kit` is the production DCC side of ToonStudio character authoring. It turns a
versioned JSON recipe plus a trusted VRM/GLB/Blend source into a deterministic package containing
an authored toon-hair mesh, semantic facial shape keys, quality reports, contact-sheet renders,
and portable GLB/VRM/Blend outputs.

## Product boundary

The extension is deliberately not a general Python executor. The MCP surface only accepts these
commands:

- `inspect_character`
- `build_authored_hair`
- `create_semantic_face_shapes`
- `render_quality_views`
- `validate_character`
- `export_character_package`
- `run_pipeline`

It does not invoke a shell, download assets, install packages, reset preferences, or evaluate source
text. File access is declared in `blender_manifest.toml`; no network permission is requested.

## Install

From the repository root with Blender 5.2 LTS installed:

```sh
pnpm exec tsx scripts/setup-toonstudio-blender-pipeline.mts -- --install-addons
```

This validates and builds the local extension, installs it into Blender's `user_default` extension
repository, downloads the pinned VRM Add-on for Blender 4.5.0 archive, verifies its SHA-256, installs
it, and probes the required Blender operators.

## Run headless

```sh
BLENDER_PATH=/Applications/Blender.app/Contents/MacOS/Blender \
  pnpm exec tsx scripts/setup-toonstudio-blender-pipeline.mts -- --check

$BLENDER_PATH --background \
  --python scripts/blender/toonstudio_character_pipeline.py -- \
  --config config/blender/reference-character.json
```

For the audited Orion source:

```sh
$BLENDER_PATH --background \
  --python scripts/blender/toonstudio_character_pipeline.py -- \
  --config config/blender/avatar-orion-production.json
```

## MCP usage

An MCP host should import the installed extension and call the allowlisted dispatcher rather than
passing arbitrary Python generated by a model:

```python
from toonstudio_blender_kit.mcp import dispatch

receipt = dispatch(
    "run_pipeline",
    {
        "projectRoot": "/absolute/path/to/toonspectrum",
        "configPath": "/absolute/path/to/toonspectrum/config/blender/avatar-orion-production.json",
    },
)
print(receipt)
```

All write destinations are constrained to the supplied project root unless a human explicitly sets
`scene["toonstudio_allow_external_output"] = True` in a trusted isolated session.

## Package contract

Each run creates:

```text
batch_generated/blender-character/<character-id>/
├── character-package.json
├── quality-report.json
├── <character-id>.blend
├── <character-id>.glb
├── <character-id>.vrm        # when requested and the official add-on validates it
└── previews/
    ├── index.html
    └── <expression>--<view>.png
```

`character-package.json` records every file size and SHA-256, the config digest, quality metrics,
semantic face controls, hair LOD triangle counts, source provenance, and the generator versions.
ToonStudio's TypeScript parser rejects traversal, failed quality reports, missing VRM/GLB runtime
artifacts, and malformed hashes before import.

## Authoring conventions

### Face

- Existing blink, phoneme/viseme, emotion, and look-at keys are never renamed or reused.
- New semantic keys use paired `TS_*_Pos` / `TS_*_Neg` names.
- Detection uses explicit metadata first and fails closed when confidence is below the recipe.
- Vertex displacement is bounded as a fraction of the detected face dimensions.

### Hair

- LOD0 is a closed scalp shell plus flattened, tapered, closed six-sided clumps.
- Hair is generated from style-specific guide curves; it is not a sphere/capsule assembly.
- `COLOR_0`, UVs, shade/highlight zones, back-face outline shells, and three explicit LODs are
  generated deterministically.
- Original hair is hidden only when it is a separable hair-only mesh and the recipe explicitly asks
  for replacement.

### Quality gate

Strict release fails on any blocking issue: triangle or material budget, non-manifold/degenerate
geometry, too many skin influences, oversized textures, negative transforms, incomplete humanoid
rig for VRM, missing semantic facial controls, missing authored hair, or a score below the recipe.

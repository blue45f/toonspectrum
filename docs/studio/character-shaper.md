# 캐릭터 셰이퍼 (Character Shaper) — 사용 설명서

경로: `/studio/character` · 여는 법: 상단 메뉴 **3D ▸ 캐릭터 셰이퍼**, 왼쪽 도구 레일의 **캐릭터 셰이퍼**,
⌘K 팔레트에서 "셰이퍼", 통합 검색에서 "캐릭터 만들기".

셰이퍼는 스튜디오가 이미 쓰고 있는 VRM 런타임 위에 얹힌 **프리셋 우선 작업실**입니다. 별도의 장면
문서를 만들지 않습니다 — 카드로 고른 값은 그대로 기존 아바타 포지·워드로브·소품·표정·포즈 상태가
되고, 저장·되돌리기·캡처·내보내기는 전부 원래 쓰던 권위를 그대로 씁니다. 그래서 셰이퍼에서 만든
캐릭터를 **고급 편집**(기존 3D 캐릭터 대화상자)에서 이어서 손볼 수 있고, 그 반대도 됩니다.

---

## 1. 화면 구성

| 영역 | 하는 일 |
|---|---|
| 요약 바 | 모델 이름·모델 바꾸기, 스타일 요약(예: "7두신 · 보브 · 교복"), 팔레트 스와치, 바뀐 슬롯 수, 되돌리기/다시 실행, 처음 상태와 비교(누르는 동안), 변형 저장, 고급 편집, 닫기 |
| 슬롯 레일 | 15개 슬롯. 화살표 키로 이동, `1`–`9`·`0`으로 앞의 열 개 슬롯 바로 가기 |
| 선반(Shelf) | 검색·장르 필터·추천 스트립·2열 카드 그리드. 카드는 4:5 미리보기 + 이름 + 한 줄 설명 + 호환 배지 |
| 뷰포트 | 3D 화면, 카메라 프리셋, 턴테이블, 투명 배경, 표면 드로잉 HUD |
| 정밀 조절(인스펙터) | 선택/미리보기 항목의 확대 미리보기, 슬라이더 + 숫자 입력, 색상, 지원 범위 노트, Blender 패키지 불러오기 |
| 독(Dock) | 참고 이미지 · 사진 포즈 · 웹캠 · 표면 드로잉 · 투명 배경 · 캔버스에 추가 · PNG 저장 · PSD 내보내기 |

데스크톱(≥1280)은 레일·선반·뷰포트·인스펙터 4열, 태블릿은 인스펙터가 오른쪽 슬라이드오버,
모바일(<768)은 뷰포트가 위·가로 슬롯 레일·바텀 시트(프리셋/정밀 조절 탭)로 접힙니다.

## 2. 15개 슬롯

| 슬롯 | 무엇을 바꾸나 | 런타임 |
|---|---|---|
| 얼굴형 | 두상·볼·턱 비율 프리셋 7종 | 아바타 포지 `face` |
| 눈 | 눈 크기·간격·눈꼬리 조합 9종 | 모델 셰이프키(`eyeSize`/`eyeSpacing`/`eyeTilt`) |
| 눈동자 | 홍채 크기 3종 + 색 8종 | `irisSize` 셰이프키 + 셰이퍼 자체 홍채 틴트 |
| 코 | 코 높이·너비 6종 | `noseHeight`/`noseWidth` |
| 입 | 입 너비·입술 볼륨 7종 + 미세한 표정 하한 | `mouthWidth`/`lipFullness` + VRM 표정 가중치 |
| 귀 | 귀 크기 + 엘프/동물 귀 | `earSize` + 소품 |
| 헤어 | 원본 유지 + 절차형 스타일 × 팔레트 | 아바타 포지 `hair` |
| 체형 | 8·7·6·5·4·3두신 + 실루엣 프리셋 | 비율 리그 프리셋 |
| 상의 · 하의 · 신발 | 원본 유지 + 워드로브 의상 | 워드로브 장착 |
| 액세서리 | 머리·몸 소품(여러 개 동시) | 소품 부착 |
| 표정 | VRM 표정 프리셋 | `handleExpressionPresetSelect` |
| 포즈 | 전신 포즈 프리셋(일상·감정·액션·앉기/눕기·리액션) | `handlePoseSelect` |
| 손 포즈 | 손 모양 13종 + 왼손/오른손/양손 | `applyHandPosePreset` |

**규칙**

- 카드를 한 번 누르면 바로 적용되고, 되돌리기 한 단계로 남습니다. 마우스를 올리는 것만으로는
  장면이 바뀌지 않습니다(인스펙터 미리보기만 바뀝니다).
- 한 슬롯을 바꿔도 다른 슬롯은 그대로입니다.
- 모델이 지원하지 않는 항목은 흐리게 표시하고 **이유를 카드에 적습니다**. 비슷한 걸로 몰래
  바꿔치기하지 않습니다. 예: "이 모델에는 눈 크기 셰이프키가 없어 적용할 수 없습니다."
- 액세서리는 다중 선택입니다. 이미 붙어 있는 카드를 다시 누르면 벗깁니다.

## 3. AI 추천 · 사진 포즈 · 웹캠

독의 **참고 이미지**를 열면 왼쪽 서랍이 셀프 위로 올라옵니다.

- **AI 추천** — 이미지 임베딩(MediaPipe 이미지 임베더, 기기 안에서 처리)으로 번들 레퍼런스와
  비교해 얼굴·헤어 레시피를 제안합니다. 미리보기 → 적용 순서이고, 적용은 되돌릴 수 있습니다.
- **팔레트 추출** — 같은 이미지에서 대표 색 최대 8개와 피부/머리/포인트 색을 뽑습니다. 완전히
  기기 안에서·동기적으로 계산합니다(네트워크 요청 없음). 한 번 눌러 머리색·눈동자색에 넣습니다.
- **사진 포즈** — 사진에서 관절을 읽어 모델에 옮깁니다. 상체/하체/팔/전체 중 어디를 가져올지
  고를 수 있습니다. 참고 탭에서 이미 이미지를 골랐다면 **「이 사진에서 포즈도 읽기」** 한 번으로
  같은 사진을 넘겨 색과 포즈를 모두 읽습니다 — 같은 파일을 두 번 고를 필요가 없습니다.
- **웹캠** — 동의 후 카메라로 얼굴·상체를 추적하고, 마음에 드는 순간을 고정(freeze)합니다.

> 서랍이 열려 있는 동안 셰이퍼는 호스트의 참고 이미지 표면을 잡습니다(추천 카탈로그가 그
> 표면에서만 로드되기 때문). 그래서 **표면 드로잉이 켜져 있을 때 참고 이미지 탭을 열면 드로잉이
> 잠시 꺼지고, 서랍을 닫으면 되돌아옵니다.**

## 4. 표면 드로잉

독의 **표면 드로잉**(또는 `B`)을 켜면 모델 표면에 직접 칠할 수 있습니다. 브러시·지우개·스포이드·
채우기와 크기·불투명도, 되돌리기/다시 실행/초기화가 뷰포트 HUD에 붙습니다. 칠한 결과는 텍스처에
남고, PSD의 「표면 드로잉」 그룹으로도 나갑니다.

표면 드로잉을 켤 수 없을 때(모델 없음, 캡처 중, 웹캠 켜짐 등)는 HUD가 그 이유를 그대로 적습니다.

## 5. 내보내기

| 버튼 | 결과 |
|---|---|
| 캔버스에 추가 | 지금 화면을 현재 페이지에 이미지로 넣습니다. 투명 배경이 켜져 있으면 캐릭터만 남습니다. |
| PNG 저장 | 같은 그림을 PNG 파일로 내려받습니다(투명 배경 옵션 그대로). |
| PSD 내보내기 | 의미 레이어가 나뉜 `.psd`를 내려받습니다. |

**PSD 레이어 순서**(포토샵에서 위 → 아래)

1. 「주선」 — 윤곽선
2. 「표면 드로잉」 — 브러시 획 (표면 드로잉 텍스처가 있을 때만)
3. 「하이라이트」 — 밝은 면(스크린)
4. 「음영」 — 어두운 면(멀티플라이)
5. 「밑색」 — 눈 · 얼굴 · 머리 · 액세서리 · 상의 · 하의 · 신발 · 피부(각각 평면색 × 마스크)
6. 미리보기 (Beauty) — 숨김 상태로 들어갑니다

마스크는 메시뿐 아니라 **재질 슬롯 단위로도** 나뉩니다. VRoid 계열처럼 얼굴·눈·속눈썹이 한
메시 안에 재질로만 나뉘어 있어도 「눈」과 「얼굴」이 각각의 레이어로 나옵니다.

만들지 못한 레이어는 **생략 목록에 이유와 함께** 적힙니다. 눈이 얼굴과 **한 재질로** 합쳐져
이름으로도 구분되지 않는 모델은 눈 마스크를 분리할 수 없고, MToon(툰) 재질이 없는 모델은
음영·하이라이트가 평면과 같아져 두 레이어가 빠집니다.

## 6. 단축키

| 키 | 동작 |
|---|---|
| `1`–`9`, `0` | 슬롯 레일에 포커스가 있을 때 앞의 열 개 슬롯으로 이동 |
| `←` `→` `↑` `↓` · `Home` `End` | 레일·카드 그리드 안 이동 |
| `Enter` / `Space` | 카드 적용 |
| `⌘Z` / `⇧⌘Z`(`⌘Y`) | 셰이퍼 되돌리기 / 다시 실행 (표면 드로잉 중에는 획 히스토리가 가져갑니다) |
| `T` | 턴테이블 |
| `B` | 표면 드로잉 켜기·끄기 (드로잉 중 뷰포트 안에서는 브러시 도구 키) |
| `Esc` | 서랍 → 바텀 시트 → 표면 드로잉 → 대화상자 순서로 닫기 |

되돌리기는 최근 **60단계**까지 보관합니다. 한 단계는 카드 한 번 또는 정밀 조절 한 번(드래그를
끝낸 시점)이며, 되돌리면 그 직전의 원본 상태(포지·워드로브·소품·포즈·표정·색·홍채 틴트·의상
표시)가 통째로 돌아옵니다.

## 7. Blender 캐릭터 패키지 불러오기

체형 슬롯의 **정밀 제작** 블록에서 Blender 파이프라인(`tools/blender/toonstudio_blender_kit`)이
만든 `character-package.json`과 같은 폴더의 `.vrm`(또는 `.glb`)을 함께 고르면 셰이퍼로 바로
불러옵니다.

- 매니페스트는 저장소의 파서로 검증합니다. 스키마가 안 맞거나 품질 게이트를 통과하지 못한
  패키지는 **파서가 낸 이유를 그대로 보여 주고 불러오지 않습니다.**
- 런타임 파일은 매니페스트에 적힌 바이트 수와 SHA-256으로 대조합니다(브라우저가 WebCrypto를
  주지 않으면 크기만 대조하고 그 사실을 적습니다).
- 브라우저는 Blender를 실행하지 않습니다. 패키지를 만드는 방법은
  `docs/studio/blender-character-pipeline.md`에 있습니다.

## 8. 정직한 한계

- 셰이프키가 없는 모델에서는 눈·코·입 카드가 적용되지 않습니다. 카드가 그 사실을 적습니다.
- 홍채 틴트는 눈동자 재질을 이름으로 찾습니다. 눈동자·속눈썹·흰자가 한 재질로 합쳐진 모델은
  색만 따로 바꿀 수 없습니다.
- 체형(두신) 변경은 관절을 옮기는 비율 리그를 씁니다. 리그를 지원하지 않는 VRM은 얼굴·헤어만
  편집할 수 있고, 그 이유가 인스펙터에 표시됩니다.
- 손 모양 인스펙터는 **전체 굽힘**과 **손가락 하나씩**을 모두 제공합니다. 손가락별 조절은
  「손가락 하나씩」을 펼치면 나옵니다.
- AI 추천·팔레트·포즈 인식은 모두 기기 안에서 처리합니다. 서버로 이미지를 보내지 않습니다.

## 실제 조작 — current

- 입장 화면의 네 풍경 버튼은 선택 상태를 명시하고 해당 아트를 로드한다. 이미지 실패 시 설명을
  제공하며 캐릭터·닉네임·입장 버튼은 계속 동작한다. 다른 풍경 선택은 실패 상태를 초기화한다.
- 장소 검색은 NFKC 정규화, 대소문자·공백 정리, 여러 검색어의 교집합을 사용한다. 이름·설명·분류를
  함께 찾고 선택 분류와 결합한다. 개인 모드의 프로젝트 전용 장소 제외를 먼저 적용한다.
- 검색 결과 수·빈 상태·전체 장소 복귀를 표시한다. 모드 변경으로 분류가 사라지면 표시 가능한
  전체 분류로 계산한다. 검색 자체로 장소 이동이나 업무 도구를 실행하지 않는다.
- 햇살 아틀리에·노을 해변·비 오는 숲·달빛 도시·꽃잎 정원 프리셋은 기존 환경 `onChange`를 통해
  배경·시간대·날씨를 한 번에 바꾼다. 수동 조합은 직접 설정 상태로 표시한다. 오디오·미디어를 켜지 않는다.
- 주요 검색·풍경·환경 버튼은 44px 이상의 조작 영역과 키보드 포커스를 제공한다. 모션 감소와

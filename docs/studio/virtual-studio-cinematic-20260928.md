가상 공간 전체 회귀는 166파일·1,533테스트가 통과했다. 새 UI·초기화·품질·홈 ARIA·알림 계약의

바꾼 뒤 하네스가 통과했다. 실패를 삭제하거나 타입 검사를 우회하지 않았다.

실제 Chromium에서 네 이미지 선택·입장, 다섯 프리셋의 적용과 캐릭터 보존, 환경음 미실행,

Enter 적용·Escape 닫기·더 보기 버튼 포커스 복귀, 검색/분류/초기화 및 개인 아틀리에 이동을 확인했다.
입장 아트와 프리셋에 대한 axe 위반은 각각 0개였다. 베타 안내 확인 버튼은 수정 후 포인터로 조작됐다.

별도의 기존 RTC harness에서는 네 가지 실제 브라우저 검증을 실행했다. 네이티브 데이터 채널의
동료 좌표·반응 전달, 요청만으로 실행하지 않는 상호 수락·취소, 월드 내용이 다른 상대의 검수 거부,
4인 합성 비디오의 12개 수신 방향 프레임 디코딩과 퇴장 후 정리를 확인했다. 합성 캔버스 4개를

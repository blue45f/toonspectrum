첨부 §13은 우선순위를 선행 의존성으로 설명한다. §15에서 대형 행사·유료 에셋·3D 소셜 월드 등은 수요·원가·품질 검증이 필요한 조건부 확장으로 유지한다. 이를 무조건 활성화하라는 배포·지출 허가로 해석하지 않는다. 원문이 우선 완결 대상으로 정한 세 흐름은 **같은 컷/버전 검토 → 수정 요청 → 재검토**, **산출물 제출 → 인수인계 → 다른 시간의 후속 작업**, **팀 템플릿 → 소품/도구 배치 → 권한 있는 공동 세션**이다.

원본 아트, 실제 자세가 바뀌는 동작, 자연스러운 이동과 NPC, 접근 가능한 공간/목록/집중 작업 경로는 위 기능들의 공통 품질 조건이다. 전체 30개 기능의 존재를 버튼이나 링크만으로 판정하지 않으며, 저장된 결과·권한·동의·취소·복구와 실제 사용자 흐름을 함께 검증한다.

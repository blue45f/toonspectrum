상태: **target 요구사항 / current 출처 확인**. 2026-09-20에 [사용자가 제공한 공유 대화](https://chatgpt.com/share/6aaee800-d520-83ee-ac26-d2a1f812cece)의 **상세 확장 전략·30개 기능 백로그 검토서** 버튼을 열고, `ToonStudio_Virtual_Studio_Expansion_Strategy_2026-09-20.md`의 표시된 본문과 §14 표를 직접 확인했다. 이전 조사에서 수신하지 못했던 첨부다. 아래 VS-01–VS-30은 그 표의 원래 식별자와 완료 기준이며, B01–B20와 E01–E25는 별도로 작성한 내부 추적 식별자다.

첨부 §13은 우선순위를 선행 의존성으로 설명한다. §15에서 대형 행사·유료 에셋·3D 소셜 월드 등은 수요·원가·품질 검증이 필요한 조건부 확장으로 유지한다. 이를 무조건 활성화하라는 배포·지출 허가로 해석하지 않는다. 원문이 우선 완결 대상으로 정한 세 흐름은 **같은 컷/버전 검토 → 수정 요청 → 재검토**, **산출물 제출 → 인수인계 → 다른 시간의 후속 작업**, **팀 템플릿 → 소품/도구 배치 → 권한 있는 공동 세션**이다.

원본 아트, 실제 자세가 바뀌는 동작, 자연스러운 이동과 NPC, 접근 가능한 공간/목록/집중 작업 경로는 위 기능들의 공통 품질 조건이다. 전체 30개 기능의 존재를 버튼이나 링크만으로 판정하지 않으며, 저장된 결과·권한·동의·취소·복구와 실제 사용자 흐름을 함께 검증한다.

## 함께 첨부된 두 플랫폼 설계의 접점

2026-09-20에 같은 공유 대화의 파일 미리보기를 열어
`ToonStudio_sitewide_preimplementation_blueprint_2026-09-17.md`(§0–18)와
`ToonStudio_all_in_one_webtoon_platform_blueprint_2026-09-17.md`(§0–26)의 본문도 확인했다.
두 파일은 **target 설계**다. 이 출처 확인은 사이트 전체 기능의 구현 완료나 이번 가상스튜디오
범위의 자동 확대를 뜻하지 않는다. 다음은 VS 기능이 의존하거나 연결하는 요구만 추린 것이다.

- 사이트 설계 §6.9와 올인원 설계 §12.5–12.6은 고정 검수본에 위치·영역·객체 의견을 남기고,
  담당자·기한·필수 여부와 수정 버전을 연결한 뒤 사용자가 해결을 확인하고 별도로 승인하도록 한다.
  현재 source mapping, 의견 배정, 기존 제작 작업/인계 연결, 편집기 이동 및 수정본 비교·해결 흐름은
  이 접점의 구현이다. 멘션, 영상 timecode와 내부/외부 댓글 권한 분리는 별도 검증이 필요한 target이다.
- 사이트 설계 §3.3–3.4와 올인원 설계 §4.4–4.5의 외부 참여자는 할당 범위·입력본·완료 기준·제출
  결과만 접근한다. 외부 검토자의 만료 링크와 모바일 검토는 VS-13/E21의 target이며, 현재 인증된
  작품 팀원의 검수 화면만으로 외부 접근 권한까지 완성했다고 판정하지 않는다.
- 올인원 설계 §14.3–14.6은 고정 입력, 담당자·검수자, 산출물, 선행 작업, 완료 기준 및 권리 조건을
  단계 전환과 연결한다. 현재 저장된 의견의 `reviewRef`와 기존 인계 기준 연결은 그 일부이며,
  제작 보드의 모든 상태 전환 조건을 완성했다는 증거는 아니다.
- 사이트 설계 §6.9의 승인 후 변경 재평가와 올인원 설계 §6.4/§12.6/§16의 불변 승인본을 함께
  보존한다. 과거 승인을 덮어쓰지 않고 현재본과 승인본의 차이 및 재검토 필요를 구분해야 한다.
  검수 결정, 실제 승인 Revision, 공개 Release는 별도 권한이고 승인본 기반 출력은 export 접점의 target이다.
- 올인원 설계 §22는 2·5·10·20인, 연결 단절·복귀, 권한 회수, lease 만료, 동일 객체 충돌과 승인본
  불변 검증을 요구한다. 실제 장치 성능·키보드·44px 터치·동작 줄이기·대체 목록도 품질 조건이다.
  로컬 합성 HTTP/브라우저 검증과 4인 대화 계약을 WAN·20인 또는 전체 실기기 검증으로 확대하지 않는다.

두 문서는 장기 제품 범위의 표현에도 차이가 있다. 사이트 설계 §15는 자체 연재 포털을 핵심 사업으로
바꾸거나 기능 수 중심의 올인원 문구를 사용하는 일을 보류하지만, 올인원 설계 §1/§16/§26은 자체
연재까지 장기 목표로 제시한다. 이번 우선순위는 더 최근인 가상스튜디오 확장 첨부의 30개 요구와
세 핵심 흐름으로 추적하며, 플랫폼 전면 확장은 별도 범위로 남긴다. 원본/파생 미리보기 분리,
기존 URL·runtime 보존, 저장·검수·승인·게시 상태의 구별, 명시적 AI 적용 및 자동 승인 금지는
공통 보존 조건이다.

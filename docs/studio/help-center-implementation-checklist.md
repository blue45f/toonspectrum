# Studio 도움말 센터 검증 체크리스트

- [ ] 도움말 > 현재 도구에서 맥락형 도움말 센터가 열린다.
- [ ] 도움말 홈, 현재 도구, 문제 해결을 키보드만으로 이동할 수 있다.
- [ ] F1 검색으로 이동할 때 도움말 모달이 닫힌다.
- [ ] 진단, 복구, 용어 사전, 라이선스, 버그 보고 화면으로 전환된다.
- [ ] Escape, 포커스 순환, 배경 inert, 스크롤 잠금이 동작한다.
- [ ] 모바일 상단 탐색과 본문 스크롤이 독립적으로 동작한다.
- [ ] 핵심 도구 19개 명령의 30초 가이드가 노출된다.
- [ ] 증상 검색이 한국어, 영문 기술어, 타 제품 용어를 찾는다.
- [ ] 기존 도움말 채널 API와 진단·복구 화면의 회귀가 없다.

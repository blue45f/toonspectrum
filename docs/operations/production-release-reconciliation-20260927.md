# 2026-09-27 운영 DB 정합성 복구

상태: migration. 제품명과 운영 계약 복구는 PR #2151의 구현을 유지한다.
중복된 브랜드 호환성 변경은 제거하고, 이 변경은 DB 원장과 음성 리뷰 검증만 보완한다.

## 적용 범위

`0001`부터 `0092`까지 기존 SQL 원문은 변경하지 않는다. 기존 운영 호환성 검사와
`config/production-migration-baseline.json`이 이 이력을 고정한다.
`0092`는 Supabase 제공자 이력에 적용됐지만 저장소 전용 원장에는 빠져 있다.
멱등적인 원문을 단일 작성자 트랜잭션에서 재확인하고 정확한 체크섬을 원장에 기록한다.

`0093_review_voice_note_constraints_repair`는 부분 부트스트랩에서 누락된 음성 리뷰의
보존 기간, 삭제 상태, 검토 대상, 객체 참조, 길이·크기·해시 검증을 복구한다.
기존 `toonspectrum` 객체 식별자와 본문·해시는 변경하지 않는다.
검증은 `IS TRUE`를 요구하여 누락된 JSON 필드가 SQL NULL로 통과하지 못하게 한다.
기존 불변성 트리거와 제한된 런타임 역할을 유지하며 DML 권한을 확대하지 않는다.

## 검증 및 복구

로컬 일회성 PostgreSQL에서 기존 행 보존, 잘못된 JSON·변조·직접 삭제 거부,
재적용, 잘못된 기존 행이 있을 때 전체 롤백을 검증한다. 운영 적용 전 영향 범위의
행 수와 제약조건·함수 정의를 기록한다. 이 기록은 전체 데이터베이스 덤프가 아니다.
마이그레이션은 잠금 5초·문장 90초 제한을 가지며 실패 시 데이터를 고쳐 맞추지 않는다.

운영 원장의 기존 체크섬과 활성 잠금을 검증하고, 승인된 main SHA 및 새 SQL 체크섬을
성공한 DB 변경과 같은 트랜잭션에서 기록한다. 원장의 과거 체크섬을 덮어쓰지 않는다.
앱 롤백은 직전 검증된 이미지와 Worker 버전을 사용한다. 새 제약은 기존 앱과 호환되므로
검증된 제약을 제거하거나 저장된 사용자 데이터를 삭제하는 복구를 자동 실행하지 않는다.

## 배포 및 소스 개수

실제 Worker `toonspectrum-web`, R2 `toonspectrum-public-assets`, Render
`toonspectrum-core-api`를 유지한다. DNS·유료 플랜·자동 배포·인증 비밀은 변경하지 않는다.
이미 진행 중인 같은 앱 릴리스를 중복 실행하지 않고, DB 전용 변경과 앱 배포의 실제
SHA 및 적용 상태를 각각 검증하여 기록한다.
새 관리 SQL 파일 한 개가 추가되어 `apiDatabaseFiles`만 139에서 140으로 증가한다.
나머지 소스·import 경계 및 권한·체크섬 검증은 그대로 유지한다.

## 공개 Data API 차단

음성 리뷰 테이블에는 공개 `anon`·`authenticated` 권한이 없음을 확인했다. 방어적으로
RLS를 활성화하고 두 공개 역할을 거부하되, 기존 서버 SQL 역할의 제한 권한은 보존한다.
로컬에서는 공개 역할에 SELECT/INSERT를 잘못 부여해도 행 조회와 쓰기가 차단되는지 검증한다.

## 신청 없이 먼저 사용할 수 있는 추가 공개 소스

- Wikimedia/MediaWiki: Commons CC0 전용 검색을 Open Creation에 연결했다. 파일별 라이선스·저작자·크레딧·원문·조회일을 저장하고, CC0가 아니거나 제한·호스트 검증에 실패한 파일은 제외한다. 문서 제목·다국어 식별자 확장은 후속 후보로 유지한다.
- NDL Search·Japan Search: 일본 판본과 문화자료의 발견용 메타데이터에 적합하다. 상업·지속적 이용 통지와 원 제공기관 조건을 기능 활성화 전에 다시 확인한다.
- IIIF: `rights`와 `requiredStatement`를 보존하는 공통 뷰어·확대 보기 어댑터 후보로 유지한다.
- OpenStreetMap: 공개 타일 서버를 운영 트래픽에 직접 사용하지 않고, ODbL 출처표시와 데이터베이스 조건을 지키는 별도 인프라가 있을 때만 활성화한다.

## 유료·상업 계약 가능성이 있어 이번 범위에서 제외한 항목

AniList 상업 라이선스, TMDB 상업 사용, Freesound API 계약, Open-Meteo 상업 운영 플랜, 기타 결제수단 등록 또는 유료 전환이 필요한 서비스는 발급·가입·운영 연결을 진행하지 않았다.

## 비밀 관리 원칙

1. 브라우저 `VITE_*`, URL query, 로그, 문서, 테스트 fixture에 실제 키를 넣지 않는다.
2. 서버 환경변수와 배포 플랫폼의 암호화된 비밀 저장소만 사용한다.
3. 가능한 경우 API 단위 제한을 적용하고, 고정 egress IP가 확보된 배포 환경에만 IP 제한을 추가한다.
4. 키 교체 시 기존 키를 먼저 폐기하거나 짧은 중첩 기간만 허용한다.
5. 무료 쿼터를 비용 안전장치로 보지 않는다. 앱 내부 요청 제한·캐시·백오프를 함께 유지한다.

# ToonSpectrum — 법적 컴플라이언스 운영 노트

> 목적: 실서비스 운영 시 저작권·청소년보호·개인정보·크롤링 관련 리스크를 "방어 가능한 저위험"으로
> 유지하기 위한 코드/운영 방침을 한곳에 모은다. **이 문서는 법률자문이 아니다.** 정식 출시 전
> IP/엔터테인먼트 전문 변호사 1회 검토를 권장한다(특히 §1 표지·§2 크롤링).

상태 범례: ✅ 코드에 반영됨 · ☑️ 운영자 체크리스트(코드 외 절차) · ⚠️ 잔존 리스크

---

## 1. 표지 이미지 (저작권) ✅

- 표지의 저작권은 각 플랫폼·권리자에게 있다. 기본 표지는 **자체 제작 타이포그래픽 커버**이고,
  실제 표지는 색인·식별을 돕는 썸네일로 **출처 링크와 함께** 표시한다.
- 표지 프록시(`apps/api/src/modules/catalog/catalog.controller.ts`)는 **Referer 를 플랫폼 도메인으로
  위조하지 않는다**(핫링크 보호 우회 금지). 원본 CDN 이 핫링크를 거부하면 그 거부를 존중하고
  타이포그래픽 커버로 폴백한다.
- **킬스위치**: `COVER_IMAGE_POLICY=off` 로 두면 제3자 표지를 일절 표시하지 않는다. 정적 빌드·런타임
  API(`replaceCatalogData` → `lib/server/cover-policy.ts`)와 프록시가 모두 표지를 끈다(이미 캐시된
  정적 JSON 의 표지 URL 도 프록시가 404 로 무력화).
- 캐시는 `immutable` 을 쓰지 않는다 → 권리침해 신고·정책 변경이 빠르게 전파된다.
- ⚠️ 잔존: `proxy` 모드의 표지 표시 자체는 비영리·인용 항변이 가능한 영역이나 다툼의 여지가 있다.
  권리자 요청을 받으면 즉시 §6 절차로 비노출하거나 `off` 로 전환한다.

## 2. 데이터 수집·크롤링 (DB제작자 권리·부정경쟁) ✅ ☑️

> **핵심(정직한 인식):** 개별 데이터 포인트(작품명·작가·조회수·랭킹)는 "사실"이라 저작권 대상이
> 아니다. 그러나 플랫폼 카탈로그 **전체를 체계적으로 추출**하는 것은 저작권과 별개로 **데이터베이스
> 제작자의 권리**(저작권법 §91~98)와 **부정경쟁방지법 §2조1호 성과도용**에 해당할 수 있다(잡코리아↔
> 사람인, 야놀자↔여기어때 계열 판례). robots/약관 준수만으로 치유되지 않는다. 표지·시놉시스 완화는
> "저작권 층"만 줄이며, 크롤 자체에서 오는 DB권리·성과도용 층은 남는다. **근본 해결은 데이터 출처의
> 정당성** — ①공식 제휴/라이선스 ②자체/UGC ③허용된 공식 API.

- **런타임 크롤 없음.** 배포된 서비스는 요청 시점에 외부 플랫폼을 호출하지 않는다. (2026-07-03:
  런타임에 네이버/카카오를 페치해 랭킹을 보정하던 `lib/server/live.ts`와 자동 ingest 스케줄러를
  **폐기**했다. 랭킹은 커밋된 스냅샷에 대한 산식 전용.) 카탈로그는 커밋 스냅샷(`apps/api/data/
  catalog.json.gz`)을 정적 서빙하며, 수집(`CATALOG_INGEST_MODE`)은 **기본 off**·오프라인 수동
  작업(`pnpm catalog:update`)이다.
- **공식 API 전환(진행 중):** 근본 대응으로 **KMAS(한국만화영상진흥원 만화규장각) 오픈 API**(공공
  데이터: 도서·웹툰 메타 + 이미지 URL, REST/JSON, 일 1000회)를 채택. 2026-07-03 사용 신청 완료
  (승인 대기). 승인 후 KMAS 데이터를 정당한 소스로 카탈로그에 병합하고 KMAS 이미지를 표지로 사용
  (크롤 표지 대체)한다. 관련정보(`docs/related-info.md`)는 이미 네이버 검색 API·YouTube Data API
  전환 경로(env 키)를 갖춰 뒀다.
- 소스 레지스트리(`lib/server/catalog-sources.ts`)는 플랫폼별 `implementation`·`risk`·`requiredReview`
  를 둔다. `partner-required`/`high` 소스는 **제휴·공식 피드 확인 전까지 운영 활성화 금지**.
- ⚠️ **잔존 갭 — 시놉시스 원문:** detail 샤드(`s` 필드)에 플랫폼 시놉시스가 원문 그대로 저장된다.
  시놉시스는 사실이 아니라 **창작 표현**이라 저작권 직접 대상이다. 완화안: 짧은 스니펫만 노출하거나
  자체 요약으로 대체, 또는 KMAS 등 공식 소스 시놉시스로 교체(콘텐츠 깊이 vs 리스크는 운영 판단).
- ☑️ 오프라인 수집을 돌릴 때(운영자 체크리스트):
  - [ ] 대상 플랫폼 `robots.txt` 의 `Disallow` 준수 확인
  - [ ] 이용약관의 자동수집·재이용 금지 조항 확인
  - [ ] 공식 API/제휴 피드 우선 사용(KMAS·네이버검색API 등)
  - [ ] 호출량 제한(rate limit)·식별 가능한 User-Agent 설정
  - [ ] 저장 범위를 메타데이터·공개 수치·플랫폼 URL·출처 메타로 한정(본편·회차 이미지·개인정보 금지)
- 권위 있는 해결책은 **공식 API/제휴 전환**(JustWatch·왓챠피디아 모델)이다.

## 3. 청소년보호 (19+) ✅

- 성인(만 19세+) 작품의 **표지는 정책과 무관하게 항상 비노출**한다(`isCoverAllowed`). 본인확인 없는
  성인 표지 송출을 피하고 타이포그래픽 커버 + "19+" 배지로 대체한다.
- 19+ 작품은 **SEO 사이트맵에서 제외**한다(`scripts/build-static-catalog.ts`).
- ⚠️ 클라이언트 연령 게이트(`components/age-gate-modal.tsx`)는 자기신고형이다. 본 서비스는 성인
  콘텐츠 본편을 호스팅하지 않으므로(메타데이터만) 비례적이나, 성인 작품 비중을 키우거나 본인확인이
  필요한 기능을 추가할 경우 PASS/휴대폰 본인확인 연동을 검토한다.

## 4. 개인정보 (PIPA) ☑️

- 회원·리뷰·라이브러리 기능은 개인정보를 처리한다. 약관/개인정보처리방침은 TermsDesk 게시본을
  `/legal` 에서 노출한다(`src/domains/legal`).
- ☑️ 출시 전: 개인정보처리방침 정식 게시, 수집·이용 동의 플로우, 만 14세 미만 처리 정책, 안전성
  확보조치(암호화·접근통제), 처리위탁(Neon·Vercel 등) 고지.
- ✅ 권리침해 신고 창구에서 개인 휴대폰 번호를 제거하고 이메일 단일 창구로 통일했다.

## 5. 상표·수익화 ✅

- 플랫폼명은 **지명적 사용(텍스트)** 으로만 쓰고 로고/BI 는 사용하지 않는다.
- 수익화는 **기본 비활성**(`monetizationEnabled=false`). 제휴 파라미터 주입 모듈은 구현하지 않았고
  "보러가기"는 **순수 딥링크**다. 제휴는 계약이 있는 플랫폼에 한해, 계약 범위 안에서만 추가한다.
- B2B 데이터 판매 시 추정값(≈) 지표를 실측처럼 제공하지 않는다(표기 분리 유지).

## 6. 권리침해 신고·테이크다운 (Notice & Takedown) ✅

- `/copyright` 에 이메일 신고 창구와 **영업일 48시간 이내 비노출 SLA** 를 명시했다.
- 운영 도구: 개별 항목은 다음 스냅샷에서 제외, 전체 표지는 `COVER_IMAGE_POLICY=off` 로 즉시 차단.

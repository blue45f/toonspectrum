## 사용 경로

스튜디오 에셋 메뉴의 **CC0 에셋 라이브러리**에서 종류별 필터와 한국어·영어 검색으로 찾는다. 2D 배경·투명 소품은 **캔버스에 삽입**한다. 3D는 **GLB 받기** 후 기존 3D 모델 가져오기를 사용한다. 이번 변경은 새로운 3D 원클릭 배치 기능을 추가하지 않는다.

미리보기 이미지와 실제 삽입 원본을 구분한다. 비모델 목록 미리보기는 최대 384px이며, 확대·삽입에는 원본 해상도를 사용한다. 기존 브라우저의 1년 고정 캐시를 피하기 위해 목록 URL을 버전 갱신하고 HTTP 재검증 및 서비스 워커의 목록 갱신 정책을 분리했다. 모델·이미지 바이너리의 장기 캐시는 유지한다.

## 출처와 비용

Poly Haven 공식 API와 다운로드 도메인의 CC0 원본을 사용했다. 공급자 표기와 원본 링크, 라이선스, 공식 체크섬, SHA-256 및 변환 기록을 각 SOURCE.json에 유지한다. 사이트의 예시 렌더 썸네일을 원본처럼 재포장하지 않았다.

추가 유료 API·구독·저장소를 신청하지 않았다. 사용자가 에셋을 볼 때 공급자 API를 호출하지 않는다. 자체 호스팅 트래픽은 기존 서비스의 사용량 제한을 적용받으며, 무제한 무료 트래픽을 보장하지 않는다.

사진 배경은 손그림이나 생성형 AI 일러스트가 아니다. 사진 속 사람·상표·간판·미술품 등의 별도 권리가 모든 사용 상황에서 해결되었다고 보장하지 않는다.

## 검수와 검증 범위

컨택트 시트 12장 전체를 확인했다. 식재 구성 세트와 그 렌더, 사용하기 어려운 배경 7종, 명암 대비가 약한 백색 조각상의 2D 렌더를 제외했다. 모든 각도의 예술적 검수나 전체 작품 저장·재열기 검증을 완료한 것은 아니다.

판정 기록은 `data/studio-assets/diversity-20260913-decisions.json`, 수집 및 검사 근거는 `data/asset-releases/studio-diversity-20260913/`에 있다.

`node scripts/verify-studio-premium-release.mjs TOOLS_DIRECTORY diversity-20260913`으로 등록 파일과 PBR 보조 맵, 3D 원본과 2D 파생본의 연결, 비모델 81개 전부의 브라우저 로딩 및 PNG 출력, 실제 라이브러리 컴포넌트의 필터·검색·확대·삽입을 검사한다.

기존 읽기 전용 에셋 품질 워크플로에서 신규 팩과 기존 팩을 함께 검사한다. 메인 병합과 배포 상태는 실제 PR 및 배포 결과로 별도 확인한다.

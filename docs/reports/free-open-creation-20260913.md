## 무료 운영 경계

새 기능에는 API 키, 유료 AI 모델, DB 테이블, 새로운 서버 함수, 유료 플랜, 카드 등록이 필요 없다. 검색 버튼을 눌렀을 때 선택한 제공처 하나만 호출하며, 미공개 원고·작가 메모는 외부 API로 보내지 않는다. 페이지 초기 표시·입력·추천어 선택만으로 검색하지 않는다.

검색 캐시는 24시간, 최대 12개 검색 결과, 결과당 최대 18개 자료로 제한한다. 외부 이미지 원본을 자체 서버에 대량 복제하지 않는다. 429 발생 시 Retry-After를 존중하고 자동 재시도·유료 대체·우회 호출을 하지 않는다. 브라우저별 제한은 제공기관의 전체 IP 한도를 보장하지 않으므로 기관의 429가 최종 기준이다.

기존 호스팅·도메인·대역폭·기존 서비스 비용까지 0원이라는 의미는 아니다. 기존 유료 기능의 계정·플랜·설정은 변경하지 않는다. 페이지가 이미 열린 상태에서 재료 메타데이터와 브리프 도구는 오프라인 사용이 가능하지만 최초 페이지 로딩·외부 이미지의 완전 오프라인 동작은 보장하지 않는다.

## 권리·데이터 보호

AIC는 `is_public_domain === true`만 채택하며 별도 라이선스인 `description`을 요청하지 않는다. Cleveland는 메타데이터 공개 여부만으로 판단하지 않고 `share_license_status === 'CC0'`을 요구한다. 위키백과 본문·검색 스니펫·이미지는 복제하지 않는다. 기존 도서·지원사업 정보를 CC0 이미지 권리로 승격하지 않는다.

크레딧·원문 URL·제공처·조회일·권리 표시를 저장하고 내보낸다. 이는 초상·상표 등 제3자 권리의 보증이 아니므로 최신 원문 확인 안내를 유지한다. API 호출 대상은 고정 HTTPS 도메인이며, 응답 속 외부 URL은 허용 호스트와 HTTPS 여부를 검사한다.

보드는 항목별 키를 사용해 서로 다른 항목의 탭 간 저장이 전체 보드를 덮어쓰지 않게 한다. 손상된 자료를 읽으면 쓰기를 중지하고 원본을 보존한다. 저장 공간 부족을 성공으로 표시하지 않는다. 검색 캐시 실패는 정상 검색 결과를 막지 않는다. Vercel CSP는 새 API 도메인 3개만 추가하며 연결 정책을 `https:` 전체로 넓히지 않는다.

## 검증 기록

- 핵심 모듈 `open-creation.ts`: `tsc --strict --noEmit --target ES2022 --module ESNext --moduleResolution bundler` 통과.
- 단위 검증 20개: 동일한 테스트 본문의 테스트 러너 import만 Vitest에서 Node의 `node:test`로 바꾼 임시 복사본을 `node --experimental-strip-types --test`로 실행, 20개 성공·0개 실패. 저장소에는 Vitest 버전만 추가한다.
- UI TSX: TypeScript transpile 구문 진단 0개. 전체 앱의 타입 검사·브라우저 상호작용 검증과는 다르다.
- CSP: 수정 전 내용의 Git blob 해시가 기존 파일과 일치함을 확인한 뒤 정확한 도메인 3개만 추가. JSON 형식 및 무제한 connect-src 미도입 확인.
- 원격 개발 장치가 응답하지 않아 전체 저장소 설치·앱 빌드·브라우저 E2E는 실행하지 못했다. 이 문서는 실제 외부 API 연결, CORS, 운영 배포 성공을 증명하지 않는다. 병합 전 저장소 CI와 실브라우저 검증이 필요하다.

주요 단위 검증은 한 글자 한글 검색, 페이지 범위, 고정 API 주소, 위험 URL, 권리 누락·불일치 차단, 잘못된 응답, 기존 자료의 권리 보존, 저장 손상·용량 초과, 캐시 만료·실패, 여섯 브리프의 출처·한계 표시를 포함한다.

## 후속 확장 제안 — 이번 PR에서 완료된 기능 아님

**3D 장면 재료실:** Poly Haven의 무료 API를 식별 User-Agent와 눈에 띄는 출처 표시를 갖춘 제한적 정적 인덱스 방식으로 연결. 모델·텍스처·HDRI 메타데이터 탐색부터 제공하고 대용량 원본 자동 복제는 피한다.

**고증 비교 노트:** 기존 Met와 새 미술관 보드의 시대·지역·재질을 나란히 비교하고 사실·작가 해석을 분리해 기록한다. 서로 다른 지표를 하나의 인기 점수로 합산하지 않는다.

**한국 창작 기회 캘린더:** 기존 기업마당 어댑터와 승인된 공공 API가 있을 때 공식 마감일·자격·원문 링크를 재사용한다. 회원 인증·이메일 확인이 필요한 신규 신청을 완료된 연동으로 가장하지 않는다.

**자료 기반 연재 콘텐츠:** 복식에서 캐릭터로, 유물에서 소품으로, 회화에서 컷 구도로 이어지는 편집형 시리즈를 제작한다. 단순 원문 복제 대신 관찰 과제·비교 기준·원문 근거를 더한다.

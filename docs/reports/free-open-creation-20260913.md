# 무료 공개 API 기반 창작 재료실 — 2026-09-13

## 구현 범위

새 경로 `/research/open-creation`을 추가하고 `/insights/resources`에서 진입할 수 있도록 연결한다. API 주소 목록을 늘리는 것에서 끝내지 않고, 검색 → 재료 보드 → 출처 포함 제작 브리프로 이어지게 한다.

| 공개 미술·복식·유물 검색 | Art Institute of Chicago, Cleveland Museum of Art 어댑터 |

콘텐츠 생성은 **로컬 규칙 기반 브리프**다. 생성형 AI, 자동 사실 검증, 완성 그림·영상 생성, Studio 자동 삽입은 구현 범위에 포함하지 않는다. 사용자 메모와 생성된 초안은 자동 저장하지 않으며 화면에 내보내기 필요성을 안내한다.

## 무료 운영 경계

새 기능에는 API 키, 유료 AI 모델, DB 테이블, 새로운 서버 함수, 유료 플랜, 카드 등록이 필요 없다. 검색 버튼을 눌렀을 때 선택한 제공처 하나만 호출하며, 미공개 원고·작가 메모는 외부 API로 보내지 않는다. 페이지 초기 표시·입력·추천어 선택만으로 검색하지 않는다.

검색 캐시는 24시간, 최대 12개 검색 결과, 결과당 최대 18개 자료로 제한한다. 외부 이미지 원본을 자체 서버에 대량 복제하지 않는다. 429 발생 시 Retry-After를 존중하고 자동 재시도·유료 대체·우회 호출을 하지 않는다. 브라우저별 제한은 제공기관의 전체 IP 한도를 보장하지 않으므로 기관의 429가 최종 기준이다.

기존 호스팅·도메인·대역폭·기존 서비스 비용까지 0원이라는 의미는 아니다. 기존 유료 기능의 계정·플랜·설정은 변경하지 않는다. 페이지가 이미 열린 상태에서 재료 메타데이터와 브리프 도구는 오프라인 사용이 가능하지만 최초 페이지 로딩·외부 이미지의 완전 오프라인 동작은 보장하지 않는다.

## 권리·데이터 보호

AIC는 `is_public_domain === true`만 채택하며 별도 라이선스인 `description`을 요청하지 않는다. Cleveland는 메타데이터 공개 여부만으로 판단하지 않고 `share_license_status === 'CC0'`을 요구한다. 위키백과 본문·검색 스니펫·이미지는 복제하지 않는다. 기존 도서·지원사업 정보를 CC0 이미지 권리로 승격하지 않는다.

크레딧·원문 URL·제공처·조회일·권리 표시를 저장하고 내보낸다. 이는 초상·상표 등 제3자 권리의 보증이 아니므로 최신 원문 확인 안내를 유지한다. API 호출 대상은 고정 HTTPS 도메인이며, 응답 속 외부 URL은 허용 호스트와 HTTPS 여부를 검사한다.

보드는 항목별 키를 사용해 서로 다른 항목의 탭 간 저장이 전체 보드를 덮어쓰지 않게 한다. 손상된 자료를 읽으면 쓰기를 중지하고 원본을 보존한다. 저장 공간 부족을 성공으로 표시하지 않는다. 검색 캐시 실패는 정상 검색 결과를 막지 않는다. Vercel CSP는 새 API 도메인 3개만 추가하며 연결 정책을 `https:` 전체로 넓히지 않는다.

신규 계정, API 키 발급 신청, 유료 계약, 카드 등록은 수행하지 않았다. 이번 세 API는 신청이 필요 없는 구조다. 기존 목록의 국내 공공 API 등 인증이 필요한 제공처는 이번 작업에서 신청·승인 완료로 표시하지 않는다.

- 추가로 자료실 폴더 전체를 포함한 확장 검사는 282개 통과 / 4개 실패였다. 실패는 `product-ux-foundation.test.ts`의 기존 홈 런처·전역 내비게이션·마켓 문구 검사이며, 검사 파일과 대상 소스가 통합한 main(599e316d)과 동일함을 확인했다. 이 기존 불일치를 신규 기능 검증 성공과 혼동하거나 검사에서 숨기지 않는다.
- 운영 CSP를 적용한 실제 Chromium 페이지에서 AIC·Cleveland·한국어 Wikipedia 검색이 각각 HTTP 200/CORS 응답 및 유효한 결과 18개를 반환했다. 검색 키워드는 공개 테스트 소재인 갑옷/한복만 사용했다.
- Cleveland 실제 이미지가 로드되어 너비 600px을 확인했다. AIC IIIF 이미지 서버는 이 검증 환경에 HTTP 403 및 Cloudflare challenge를 반환했다. 실제 AIC 썸네일 로드 성공으로 표시하지 않으며, 이미지 실패 안내와 원문 링크를 유지한다. 제공처 차단을 우회하지 않았다.
- main의 무료 소재 도감 진입 카드 및 Poly Haven/ambientCG 정적 카탈로그 안내를 보존하면서 신규 창작 재료실을 함께 연결했다.

CodeQL이 지적한 단일 정규식 태그 제거를 상태 기반 텍스트 추출로 교체했다. `constructor`, `toString`, `__proto__`가 사전 치환에 끼어들지 않도록 자체 속성만 조회한다. AIC가 공식 지원하는 CORS 이미지 요청에 `crossOrigin="anonymous"`를 사용하며 전역 CSP/COEP는 완화하지 않는다.

CI 최종 결과와 머지 상태는 PR #1369의 최신 head 기준 체크에서 확인한다. 로컬 빌드·API 검증은 운영 배포 성공을 의미하지 않는다.

## 후속 확장 제안 — 이번 PR에서 완료된 기능 아님

**3D 장면 재료실:** main에 별도로 추가된 Poly Haven·ambientCG 소재 도감을 보존한다. 향후 확장은 현재 정적 카탈로그와 구분하고 대용량 원본 자동 복제를 피한다.

**고증 비교 노트:** 기존 Met와 새 미술관 보드의 시대·지역·재질을 나란히 비교하고 사실·작가 해석을 분리해 기록한다. 서로 다른 지표를 하나의 인기 점수로 합산하지 않는다.

**한국 창작 기회 캘린더:** 기존 기업마당 어댑터와 승인된 공공 API가 있을 때 공식 마감일·자격·원문 링크를 재사용한다. 회원 인증·이메일 확인이 필요한 신규 신청을 완료된 연동으로 가장하지 않는다.

**자료 기반 연재 콘텐츠:** 복식에서 캐릭터로, 유물에서 소품으로, 회화에서 컷 구도로 이어지는 편집형 시리즈를 제작한다. 단순 원문 복제 대신 관찰 과제·비교 기준·원문 근거를 더한다.

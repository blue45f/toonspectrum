# SHAPER 벤치마크 후속 — 3D 원고 구도와 설정화 제작

조사·구현일: 2026-09-14. 기준 브랜치: `feat/character-production-framing-20260914`.

이 변경은 기존 캐릭터 셰이퍼의 외형·포즈·표면 드로잉·PNG/PSD 기능 위에, 웹툰 제작에서 반복되는 **원고 비율 결정**과 **다각도 설정화 생성**을 실제 출력 경로로 추가한다. 기능 이름이나 UI 표시만으로 SHAPER 우위를 주장하지 않으며, 설치형 SHAPER와 동일 자산·동일 작업의 직접 실측은 별도 과제로 남긴다.

## 구현한 제작 흐름

- 현재 화면, 1:1, 3:4, 9:16, 4:3, 16:9 출력 프레임을 즉시 전환한다.
- 삼분할·중앙 십자·5% 안전 여백을 DOM 오버레이로 보여 주며 파일에는 포함하지 않는다.
- PNG와 semantic PSD가 같은 투영 crop과 같은 픽셀 비율을 사용한다.
- PNG 긴 변 1024·2048·4096px와 PSD 최대 2048px 정책을 유지한다.
- 현재 포즈·표정·의상·소품을 4방향 또는 8방향의 동일 축척 설정화 한 장으로 만든다.
- 설정화는 기준 카메라 방향에서 90° 또는 45°씩 회전하고, 각 셀에 방향을 기록한다.
## 품질 경계

프레임 crop은 FOV나 aspect를 다시 계산하지 않고 기존 projection matrix를 직접 자른다. 따라서 perspective/orthographic, zoom, lens shift, 카메라 roll을 보존한다. crop된 전체 프레임과 1024px 타일 crop이 중첩될 때도 MToon `screenCoordinates` 외곽선의 투영 배율을 보정하고 각 타일 뒤 원래 값을 복원한다.

다각도 범위는 정적 bounding box를 신뢰하지 않는다. 표시 중인 morph와 skinning이 적용된 실제 정점을 CPU에서 읽고 world 좌표로 합친다. 최대 200만 정점·5만 객체를 허용하고 8,192정점마다 이벤트 루프에 양보하며 취소·장면 권한을 다시 확인한다. 숨긴 부모, 다른 camera layer, 숨긴 재질은 제외하고, 정확히 처리하지 못하는 InstancedMesh는 잘못 맞추는 대신 명시적으로 거부한다.

모든 방향은 한 번 계산한 중심·orthographic 축척을 공유한다. 각 방향을 따로 자동 맞춤해 캐릭터 크기가 흔들리는 방식을 사용하지 않는다. 소스 PNG는 순차 생성해 GPU 캡처를 겹치지 않으며, 최대 40MiB retained PNG 예산 뒤 기존 contact-sheet Worker에서 합성한다. 취소·모델 변경·context loss·worker 실패 시 부분 파일을 다운로드하지 않는다.

## SHAPER 비교에서 추가되는 작업 가치

기존 벤치마크에서 확인한 SHAPER의 강점은 캐릭터 프리셋, 포즈, 표면 드로잉, 투명 배경, 항목별 PSD다. 이번 경로는 그 기능 목록을 복제하는 대신 후속 웹툰 제작 시간을 줄이는 데 초점을 둔다.

- 원고 비율을 정한 뒤 같은 crop으로 PNG와 PSD를 즉시 전달한다.
- 현재 편집 상태를 유지한 채 4·8방향 캐릭터 시트를 자동 작성한다.
- 모바일에서도 구도 설정과 출력 도구를 스크롤 가능한 내보내기 시트 안에서 사용한다.
- 캔버스 삽입은 의도적으로 기존 현재 화면 전체를 유지해 파일 crop 설정과 혼동하지 않는다.
- 네트워크 AI나 운영자 토큰 없이 브라우저 안에서 실행한다.

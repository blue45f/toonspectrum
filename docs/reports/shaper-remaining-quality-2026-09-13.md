# SHAPER 후속 품질 개선 — 2026-09-13

이 변경은 `4ab96607a53d03bc0e8efc0d118b44978f056afc`에서 시작한 후속 작업이다. 앞선 엔진 비교와 단계별 도입 판단은 기존 보고서를 유지하고, 이번에는 PSD의 실제 편집 레이어, 비대칭 카메라 출력, 치마의 신체 접촉, 반복 내보내기 수명을 검증한다. SHAPER 전체와 동등하다는 결론이나 실기기 성능 인증으로 해석하지 않는다.

## 검증 방법

PSD 참조 합성기는 생산 조립 함수나 이미지 수학 함수를 가져오지 않는다. 실제 PSD 바이트를 다시 읽어 기본 표시 레이어·격리 그룹·래스터 마스크·Normal/Multiply/Screen을 합성하며, merged preview와 숨김 Beauty를 읽지 않는다. PNG와 알파를 비교하고 검정/흰색 배경 위에서 색상 오차도 검사한다. 모든 알파 값, 겹친 마스크, 미분류 영역, 색상 경계와 레이어 편집을 별도 회귀로 검사한다. 이 기준은 [W3C 합성 규칙](https://www.w3.org/TR/compositing-1/)과 [ag-psd 레이어 구조](https://github.com/Agamnentzar/ag-psd/blob/master/README_PSD.md#layers-and-groups)를 사용한 byte/sRGB 참조이며 Photoshop/CSP의 실제 앱 실행 결과가 아니다.

BG3D 비교는 실제 Three 렌더를 기준으로 Babylon WebGL2·WebGPU의 Beauty, depth, normal, object ID, material ID를 확인한다. `63×112 / 거리 4`, `192×65 / 거리 300`, `65×113 / 거리 10000`의 비대칭 장면에서 양·음 렌즈 시프트를 사용한다. 경계는 독립 Three 픽셀에서 정하며, Babylon 결과를 이용해 검사 범위를 좁히지 않는다. 직교 투영은 현재 snapshot에 frustum 치수가 없어 계속 지원 불가로 처리한다.

치마 행렬은 실제 `sample.vrm`, `AvatarSample_B.vrm` 두 자산과 pleated/longskirt를 사용한다. 데스크톱 물리 계획에서는 fit 0.75/1/1.35와 서기·실제 허벅지 90도 앉기·보폭 자세를 조합하고, 모바일 물리 계획에서는 fit 1을 확인한다. 총 48조합과 서기 재설정, 정점/인덱스 버퍼 재사용, 핀, retain/release 수명을 검사한다. front/side 이미지 24장을 함께 남겨 수치 통과와 실제 의상 외관을 구분한다. 모바일 계획도 데스크톱 GPU에서 실행하므로 실기기 결과로 기록하지 않는다.

장시간 출력 검증은 하나의 실제 VRM·WebGL 렌더러를 유지한다. 원근/직교 warmup 이후 부분 타일 PNG, 4K 취소, 재시도, viewport 프레임과 상태 복원을 반복하고 모든 PNG Worker의 종료를 검사한다. 자원 수는 warmup 기준 textures/geometries/programs와 같아야 한다. heap/backing storage 측정은 정보이며 운영체제 RSS나 전체 GPU 메모리 상한이 아니다. 상세 접근 범위와 재현 명령은 [외부 검증 기록](./shaper-external-validation-2026-09-13.md)에 있다.

## 유지하는 제한

- 의상은 보이는 스킨 표면의 캡슐 근사이며 신체 전체의 정확한 삼각형 충돌이나 천의 자체 충돌을 구현했다고 주장하지 않는다. 의상은 기존 실험 노출 정책을 유지한다.
- PSD 최대 긴 변 2048px와 파일 크기 256MiB 제한을 유지한다. 커버리지 분배 과정은 2K 정사각형에서 추가 일시 버퍼가 최대 32MiB이며 전체 프로세스 메모리 상한을 의미하지 않는다.
- SHAPER 직접 실행, 동일 자산 반입 가능성, 외부 편집기 PSD 호환성, 실제 휴대전화/저사양 기기 검증은 각각의 증거로만 판정한다.
- 렌더러 라이브러리 교체만으로 의상·입출력·편집 품질이 자동으로 해결되지 않는다. 현재 Three 편집 런타임과 격리된 Babylon 출력 경로의 검증 범위를 유지하며 게임 엔진 전면 이식의 완료를 주장하지 않는다.

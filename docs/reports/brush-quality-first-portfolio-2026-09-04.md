# 브러시 품질 우선 포트폴리오 결정 기록

## 목적

기본 브러시 선택면은 사용자가 재질과 손맛의 차이를 빠르게 이해할 수 있는 대표 브러시로 구성한다. 이 축약은 등록된 브러시를 삭제하거나 저장 문서의 브러시 ID를 변경하는 작업이 아니다.

## 제품 계약

- 기본 포트폴리오는 품질이 검증된 대표 브러시 48개를 우선 노출한다.
- 전체 비검역 브러시는 `전체` 탭, 검색, 즐겨찾기, 최근 사용, 저장 문서 ID 해석 및 품질 감사에서 계속 접근할 수 있어야 한다.
- 격리된 브러시는 기본 포트폴리오에 들어갈 수 없다.
- 대표 브러시가 품질 검역으로 이동하면 정적 계약 테스트가 실패해야 한다.
- GPU나 대체 엔진은 질감, 손맛, 라이브·커밋 일치성 및 기하 품질이 동등하거나 더 좋다는 증거가 있을 때만 승격한다.
- 처리량과 메모리는 위 품질 조건을 통과한 후보 사이에서만 비교한다.

## 대표 브러시 검역 처리

- 검역 대상인 `acrylic`은 기본 대표 포트폴리오에서 제외한다.
- 유화 계열의 필버트 대표는 `oil--filbert-ribbon`, 단단한 평붓 질감 대표는 `oil--flat-ribbon`으로 분리한다.
- `acrylic`을 포함한 등록 브러시 ID는 삭제하지 않으며, 기존 문서의 ID 해석과 검역 정책은 그대로 유지한다.
- 대표 브러시 교체는 이름이나 처리 속도가 아니라 질감 구분력과 검역 상태를 기준으로 결정한다.

## 품질 평가 비중

| 평가 축 | 비중 |
| --- | ---: |
| 질감 구분력 | 30% |
| 손맛과 압력 반응 | 25% |
| 라이브·커밋 일치성 | 20% |
| 기하 연속성 | 10% |
| 처리 성능 | 10% |
| 메모리 효율 | 5% |

## 병합 게이트

- 대표 포트폴리오 크기와 재질별 최소 커버리지
- 기본 포트폴리오와 exhaustive inventory의 분리
- 검색·즐겨찾기·최근 사용을 통한 전체 비검역 ID 접근성
- 저장 문서 및 직접 ID 해석 보존
- quarantine 누출 차단
- 브러시 라이브러리 점진 로딩과 키보드 대체 경로
- focused Vitest, ESLint, TypeScript, 정적 품질 포트폴리오 감사

이 기록은 브러시 렌더러를 강제 전환하지 않는다. 픽셀 또는 질감 품질을 낮춰 기본 포트폴리오를 넓히는 변경도 허용하지 않는다.

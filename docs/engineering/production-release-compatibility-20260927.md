# 운영 릴리스 호환성 복구 — 2026-09-27

상태: **migration**. 사이트 디자인·동선 변경의 운영 반영을 준비하며, 구현·검증·배포를 구분한다.

## 확인한 운영 기준

운영 API의 배포 이미지가 가리키는 소스는
`01a69fabf9f92799ad280a97db3bcf8391b0b84b`다. 운영 리소스는 제품 표시명과 별개다.

- Cloudflare Worker: `toonspectrum-web`, R2: `toonspectrum-public-assets`.
- Render 서비스: `toonspectrum-core-api`, 기존 이미지 저장소도 같은 식별자를 유지한다.
- 사용자에게 표시하는 제품명과 정본 도메인은 ToonStudio와 `www.toonstudio.cloud`를 유지한다.

## 복구한 결함

1. contracts가 Zod 4.5.4, API가 4.4.3으로 설치되어 DTO의 기본값이 사라졌다.
   실제 빈 마켓 라이브러리 조회의 `view` 기본값 실패를 재현했고, 여섯 소비자의
   Zod를 검증된 4.4.3으로 고정한 후 같은 테스트가 통과했다.
2. 과거 migration 13개의 SQL 원문이 브랜드 변경으로 수정되어 있었다.
   배포된 92개 파일의 원문을 기존 소스와 바이트 단위로 복구하고 SHA-256 기준을
   `config/production-migration-baseline.json`에 기록했다. 신규 DDL은 추가하지 않는다.
3. 실제 저장소 참조·라이선스·artifact descriptor의 식별자가 기존 DB 제약과 달라졌다.
   네 가지 영속 식별자만 복구한다. 제품 문구나 무관한 브라우저 키를 일괄 치환하지 않는다.
   하드코딩한 기배포 v1/v2 파일 참조의 파싱·locator 보존 회귀는 수정 전 실패, 수정 후 통과했다.
4. 새 이름의 Worker와 R2는 운영 계정에 존재하지 않았다. 기존 리소스명을 배포 구성에
   복구하고 `keep_vars`로 운영의 기존 일반 환경변수가 의도치 않게 지워지지 않게 한다.

## 재발 방지

`verify-production-release-compatibility.mjs`가 과거 SQL 바이트, 실제 설치된 공유 Zod 버전,
운영 Worker·R2 식별자와 변수 보존 설정을 검사한다. 웹 prebuild와 API build에서 실행한다.
기존 migration 테스트에도 양성 검사와 원문 변경·파일 누락·버전 분리의 음성 검사를 추가했다.
CI나 권한 검사를 삭제하거나 완화하지 않는다.

## 이 기록 시점의 실제 검증

- 좁힌 변경 범위와 전체 마켓 관련 회귀: 1,459개 테스트 통과, 실패·건너뛰기 0.
- `pnpm harness:verify`: 웹·API 타입 검사, 변경 lint, 구조·경계 검사 통과.
- 보안 감사: 알려진 취약점 없음. 라이선스 감사 통과.
- 격리된 로컬 PostgreSQL: 준비된 검수 스키마에서 390개 중 386개 통과,
  3개 실패, 1개 기존 조건부 생략. 실패는 전체 readiness용 스키마/역할 준비가
  검수 전용 준비기보다 넓은 범위를 요구한 경우이며 전체 DB 검증 통과로 합산하지 않는다.
- API·웹 최종 빌드, 최종 PR CI, 실제 브라우저와 운영 배포 결과는 별도 릴리스 근거로 기록한다.

## 운영 경계와 롤백

사용자는 구현 완료와 운영 배포를 승인했다. 자동 배포·유료 플랜 변경·DB migration·
운영 데이터 변환·secret 변경은 실행하지 않는다. 필수 CI를 통과한 정확한 main SHA로
API와 웹을 수동 반영하며 각 공급자의 기존 정상 version과 image digest를 롤백 대상으로 보존한다.
실제 배포 ID와 배포 후 점검 없이는 이 문서를 운영 배포 완료의 근거로 사용하지 않는다.

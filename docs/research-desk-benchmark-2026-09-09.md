# ToonStudio 리서치 데스크 고도화 벤치마크

작성일: 2026-09-09  
대상: `https://www.toonstudio.cloud/research`

## 목표

기존 `/research`는 검색 제공처 상태, 브라우저 로컬 작업공간, 출처 내보내기, JSON 백업·복원까지 이미 갖춘 안전한 기반이다. 이번 고도화의 목표는 링크 모음이나 카드 수 확장이 아니라, 창작자가 다음 질문에 한 화면에서 답하도록 만드는 것이다.

1. 지금 무엇을 조사해야 하는가?
2. 어떤 자료를 얼마나 모았고, 서로 다른 근거를 비교했는가?
3. 이용조건과 조회일을 다시 확인해야 하는 자료는 무엇인가?
4. 조사 결과를 이야기 설계와 실제 제작으로 어떻게 넘기는가?
5. 작업 기록을 읽기 쉬운 형태와 복구 가능한 형태로 어떻게 휴대하는가?

## 공식 제품 벤치마크

### Milanote

- 공식 제품 페이지는 visual boards, moodboards, storyboarding, creative writing, project management를 하나의 시각적 작업공간 안에서 연결한다.
- 적용: ToonStudio는 자유 배치 보드를 복제하지 않고, `발견 → 교차 확인 → 이야기 설계 → 제작 준비`의 명시적 작업 흐름과 목적별 도구 진입점을 제공한다.
- 출처: https://milanote.com/product

### Are.na

- 공식 홈페이지는 Capture, Arrange, Search, Connect의 연속 흐름을 핵심으로 설명한다. 사진·노트·파일·웹페이지를 채널에 모으고, 검색하고, 다시 연결해 쓰는 방식이다.
- 적용: 저장한 자료를 단순 보관하지 않고 최근 자료, 제공처 분포, 보드 검색, 출처 내보내기, Story Lab·Studio 전환으로 이어지게 한다.
- 출처: https://www.are.na/

### Pinterest

- 공식 도움말은 보드를 Pin의 컬렉션으로 정의하고, 저장 과정에서 새 보드를 만들 수 있게 한다.
- 적용: 저장 단위를 유지하되, ToonStudio에서는 이미지 취향 수집보다 제공처·조회일·이용조건과 원문 링크를 우선한다.
- 출처: https://help.pinterest.com/en/article/create-a-board

### Raindrop.io

- 공식 기능 페이지는 collections, tags and filters, duplicate and broken-link checking, full-text search, multiple views, permanent copies, reminders, batch processing을 제시한다.
- 적용: 현재 스키마를 무리하게 확장하지 않고, 기존 필터에 설명 검색·제공처 분포·점진적 렌더링·조회일 재확인 신호·검색 결과 출처 내보내기를 추가한다.
- 출처: https://raindrop.io/

## 구현 결정

### 1. 목적형 통합 검색

- 시각 레퍼런스, 글로벌 판본, 작가 기회 중 목적을 먼저 선택한다.
- 실제 검색은 기존 전용 페이지로 이동하며, 존재하지 않는 통합 검색 API나 가짜 결과를 만들지 않는다.
- 검색어는 NFKC 정규화, 공백 축약, 2~80자 검증을 거친 URL 공유 가능한 쿼리로 전달한다.

### 2. 사실 기반 작업공간 요약

- 저장 자료 수, 제공처 수, 작성한 기획 항목, 예정 마감 수를 계산한다.
- 자동 품질 점수 대신 실제 로컬 데이터에서 확인되는 사실만 보여준다.
- 네 단계 진행도는 작업 안내이며 작품 품질, 고증 정확성, 권리 확보를 보증하지 않는다고 명시한다.

### 3. 동적 다음 행동

- 자료가 없으면 첫 공개 자료 탐색을 제안한다.
- 근거가 적거나 한 제공처에 치우치면 교차 확인을 제안한다.
- 자료는 충분하지만 기획이 비어 있으면 Story Lab을 제안한다.
- 오래된 자료가 있으면 원문 재확인을 우선한다.
- 기획과 준비가 갖춰지면 Studio로 연결한다.

### 4. 출처·이용조건 점검

- CC0와 원문 조건 확인이 필요한 자료를 분리해 집계한다.
- 지원공고 7일, 카카오 도서 메타데이터 90일, 미술·글로벌 서지 180일을 재확인 작업 기준으로 사용한다.
- 이 기간은 제공처의 보증이나 법률 기준이 아니라, 외부 정보 변경 가능성을 놓치지 않기 위한 ToonStudio 내부 UX 휴리스틱이다.

### 5. 최근 자료와 대량 보드

- 최근 저장 자료 최대 3개를 첫 화면에 보여준다.
- 이미지 미리보기는 기존 파서가 허용한 CC0 Met 이미지 URL만 사용한다.
- 전체 보드는 처음 12개만 렌더링하고 사용자가 12개씩 더 펼친다. 저장 상한 200개에서 초기 DOM 부담을 제한한다.
- 제목·저작자·설명·ISBN 검색, 제공처·마감 필터, 정렬, 필터 초기화를 제공한다.

### 6. 이중 내보내기

- 사람이 읽을 수 있는 Markdown 리서치 브리프: 직접 작성한 기획, 출처, 조회일, 이용조건, 최종 확인 안내를 결합한다.
- 복구 가능한 JSON 백업: 기존 버전 1 스키마와 1 MB 검증, 안전한 합치기, 명시적 완전 대체를 그대로 유지한다.
- 브리프는 결정적 템플릿이며 AI가 내용을 생성하거나 사실을 보충하지 않는다.

### 7. 첫 화면 비용 절감

- 제공처 설정 상태는 상세 영역을 펼칠 때만 조회한다.
- 검색 결과, 건강 상태, 쿼터를 확인했다고 오인하지 않도록 인증키 설정 여부만 표시한다.

## 의도적으로 포함하지 않은 범위

- 실시간 링크 생존 여부 자동 검사
- 이미지·본문 재사용 권리 자동 판정
- 클라우드 동기화, 공동 편집, 계정 간 보드 공유
- 태그·메모·폴더를 위한 작업공간 스키마 마이그레이션
- 사용자 행동 기반 추천 알고리즘
- 여러 제공처를 한 번에 호출하는 신규 서버 통합 검색 API

이 기능들은 UI만 추가하면 데이터 권위, 개인정보, 비용, 권리 판정, 동기화 충돌을 잘못 약속할 수 있으므로 이번 변경에서 지원한다고 표시하지 않는다.

## 검증 범위

- 검색어 정규화·길이 검증·목적별 URL 생성
- 자료 수, 제공처 다양성, 라이선스 분류, 조회일 재확인, Story Lab 작성도, 출판 체크, 예정 마감 계산
- 사용자 상태별 다음 행동 결정
- Markdown 브리프의 기획·출처·권리 한계 포함
- 빈 작업공간, 저장 자료가 있는 작업공간, 보드 검색·초기화·삭제
- 12개 점진 렌더링과 추가 표시
- 안전한 백업 합치기와 기존 기획 우선 규칙
- 제공처 상태의 지연 마운트

# 이벤트 · 프로모션 운영 가이드

ToonSpectrum의 공개 이벤트 페이지, 최초 방문 프로모션, 홈 이벤트 배너를 운영하는 기준을 정리한다.

## 현재 베타 오픈 이벤트

- 이벤트 ID: `beta-open-2026`
- 이벤트 허브: `/events`
- 공개 상세 URL: `/events/beta-open`
- 시작일: 2026-09-18 (Asia/Seoul)
- 종료일: 미정. 확정되면 카탈로그의 `endsAt`을 설정한다.
- 베타 기간에는 주요 서비스를 이용료 없이 제공하되, 저장공간·파일 크기·업로드·동시 처리량에는 서비스 안정성을 위한 공정 사용 및 기술 안전 한도를 적용한다.
- 베타 기간 중 가입자는 가입일부터 6개월 동안 대상 서비스를 이용료 없이 이용한다. 공정 사용 및 기술 안전 한도는 동일하게 적용한다.
- 베타 기간 중 가입 후 공개 콘텐츠 1개 이상을 30일 동안 공개 상태로 유지하면 가입일부터 최대 1년 무료 혜택을 적용한다.
- 6개월 혜택과 1년 혜택은 합산하지 않는다.
- 이벤트로 확정된 무료 이용 기간은 해당 사용자에게 안내한 기간 동안 유지한다.
- 무료 기간 종료 또는 베타 종료 이후 일부 또는 전체 서비스가 유료화될 수 있음을 가입 전부터 안내한다.

## 이벤트 데이터

이벤트의 단일 설정 기준은 다음 파일이다.

`apps/web/src/domains/marketing/events/event-catalog.ts`

카피, 시작·종료 시각, 최초 방문 노출 여부, 무료 개월 수, 공개 콘텐츠 수와 공개 유지 기간은 페이지에 흩어 놓지 않고 카탈로그에서 관리한다.

새 이벤트는 `MARKETING_EVENTS`에 추가하고 `/events/<slug>` 상세 라우트를 등록한다. 공개 검색 노출이 필요한 이벤트는 public route 분류와 SEO route policy도 함께 확인한다.

## 최초 방문 노출

`BetaOpenEventGate`는 공개 크리에이티브 라우트의 첫 방문에서만 동작한다.

Studio, Admin, 인증 콜백, 계정·메시지·설정처럼 작업 연속성이 중요한 화면은 가로막지 않는다. 이벤트 허브와 이벤트 상세에서도 자기 자신을 다시 띄우지 않는다.

사용자가 닫기, 가입, 바로 시작, 상세 보기 중 하나를 선택하면 브라우저 로컬 저장소에 seen 상태를 남긴다. 비로그인은 guest 키를 사용하고 로그인 사용자는 원본 사용자 식별자를 노출하지 않는 해시 기반 account 키를 사용한다. 같은 브라우저에서 guest 상태로 이미 닫았다가 로그인하면 해당 seen 상태를 account 키로 승계한다.

향후 서버 계정 설정으로 seen 상태를 동기화할 경우에도 로컬 저장 상태는 오프라인·장애 시 폴백으로 유지한다.

## 회원가입 CTA

이벤트의 비로그인 CTA는 기존 인증 모달 요청 이벤트를 사용하고 `mode: "signup"`을 전달한다. 이벤트용 가입 폼을 별도로 만들지 않는다.

인증된 사용자는 가입 CTA 대신 `/studio/new`의 바로 시작 흐름으로 연결한다.

## 이벤트 종료와 유료 전환

종료 또는 유료 전환 시 다음을 함께 확인한다.

1. 카탈로그 `endsAt` 설정 또는 `firstVisitExposure: false` 전환
2. 홈 배너와 최초 방문 게이트가 종료 상태에서 숨는지 확인
3. 기존 사용자에게 확정된 무료 기간이 서버 정책에서 보존되는지 확인
4. 유료 플랜, 적용 시점, 무료 혜택 종료일을 충분히 사전 안내
5. 운영 정책 위반 및 비정상적·자동화된 대량 이용에 대한 제외 기준을 별도 정책으로 유지
6. 이벤트 허브에는 종료 이벤트를 기록으로 남기고 상태를 `ended`로 표시

혜택 문구는 현재 무료 이용 조건과 향후 유료 전환 가능성을 같은 화면에서 확인할 수 있도록 유지한다.

# 전문 3D 제작: 조작·배치 작업 흐름 고도화

## 범위와 반영 원칙

저장소: blue45f/toonspectrum. 대상 PR: #747.
기존 정밀 작업대 커밋: `51e66c67343c6e22cdd497901678df824d661ace`.
선행 소스 검사 경로 수정: `440de586277ff7a2aee558a3e2e7f3fcb3a0630c`.

메인 병합을 먼저 시도했으나 필수 `core` 검사가 queued여서 GitHub가 차단했다. 보호 규칙을 우회하지 않고 자동 병합을 설정했다. 이 후속 구현은 동일 PR에 추가하여 검사를 받는다. 자동 병합 설정은 병합 완료나 배포 완료가 아니며, 실제 결과는 최신 PR 상태로 확인해야 한다.

이 변경은 전문 편집의 조작 정확성·안전한 변환·배치 효율 개선이다. Blender 전체 기능 동등성, 전체 저장소 검증 또는 프로덕션 활성화를 주장하지 않는다.

## 구현한 작업 흐름

### 카메라와 화면 맞춤

- 메시 해시·위치·선택 변경만으로 카메라를 초기화하지 않는다.
- 전체/선택 맞춤은 명시적인 사용자 요청으로만 실행한다. 일반 맞춤에서는 현재 관찰 방향을 유지한다.
- 같은 표준 보기 버튼을 다시 누르면 해당 방향으로 다시 정렬한다.
- 세로형 화면의 수평 시야각까지 고려해 구 경계를 화면 안에 맞춘다.
- 원근/직교 전환 시 현재 관찰 대상·방향·겉보기 높이를 유지한다.
- 직교 뷰포트 크기 변경 시 사용자의 관찰 위치를 유지하며 배율을 보정한다.
- 정면/후면/좌측/우측/상단/하단/등각 보기와 키패드 단축키를 제공한다.

### 실제 드래그 스냅과 변환 취소

- 고정값이던 이동 거리·회전 각도·크기 배율 스냅을 사용자가 조절한다.
- 스냅 끄기는 실제 TransformControls에 null을 전달한다. 단순 표시 전환이 아니다.
- Esc, 창 포커스 상실, pointercancel, WebGL 컨텍스트 상실 시 임시 변형을 취소한다.
- 드래그 시작 시 원본 에셋·메시 버전·변환을 기록하고, 종료 시 같은 원본인지 확인한다.
- 중복 mouse-up, 무변경 클릭, 특이 스케일, 비유한 값은 편집 명령으로 저장하지 않는다.
- 비동기 명령 실패로 가짜 위치가 화면에 남지 않도록 임시 표시를 원본으로 복원한 뒤 기존 변환 콜백으로 전달한다.
- 크기 기즈모는 로컬 축으로 명시하며, 드래그 직후의 클릭이 선택을 잘못 해제하는 것을 억제한다.

### 격리·입력·표시 설정

- 선택 오브젝트만 잠시 표시하고 전체 보기로 돌아간다. 문서의 숨김 상태는 변경하지 않는다.
- 대상이 숨겨지거나 삭제되거나 다른 대상을 선택하면 격리를 해제한다.
- 그리드·좌표축·바닥 그림자 표시와 스냅 설정을 브라우저 로컬에 보관한다.
- 잘못된 저장 데이터, 저장소 접근 제한·용량 오류는 문서 편집을 중단시키지 않는다.
- 단축키는 뷰포트 내부에 한정한다. 텍스트 입력·IME·반복 키·이미 처리한 이벤트를 차단한다.
- Shift+Tab은 캔버스에서만 스냅을 전환하고 툴바에서는 정상적인 역방향 포커스 이동으로 남긴다.
- 툴바 상태 변경 시 전체 메시 검증을 다시 실행하지 않도록 스냅샷 계산을 메모화한다.

### 변환 복사·반전·오브젝트 정렬

- 작업대 메모리에서 변환 복사, 전체 또는 위치·회전·크기별 붙여넣기와 초기화.
- 원본 메시를 굽지 않는 로컬 X/Y/Z 반전.
- 실제 표시 정점으로 측정한 월드 경계의 최솟값·중심·최댓값을 다른 오브젝트 기준점에 정렬.
- m/cm/mm 수식으로 축 방향 간격 지정. 예: Y축 선택 최솟값을 선반 최댓값보다 2cm 위에 배치.
- 모든 변경은 기존 onCommitAssetTransform 명령 경로를 사용한다. 별도 저장·Undo 경로를 만들지 않는다.
- 미선택·미표시·읽기 전용·작업 중·요소 편집·조형 모드는 적용을 차단한다.

## 발견하여 수정한 결함

1. 이동된 뷰포트의 소스 검사 테스트가 여전히 얇은 공개 래퍼를 읽던 경로 오류.
2. 배열의 빈 슬롯이 every 검사를 통과하던 XYZ 변환 입력 검증 오류.
3. -0과 0이 다른 해시가 되던 오류. 기존 +0 해시 표현은 유지하면서 음의 0도 같은 값으로 처리해 무변경 기록과 JSON 왕복 불일치를 방지한다.

기존 원본/수정자 캐시 검증·자원 해제·색 관리·메시 안전 예산은 유지한다.

## 실제 실행한 검증

- 변경한 순수 계산 모듈 4개: TypeScript strict + noUncheckedIndexedAccess 통과.
- 동일 생산 코드와 native assert를 사용하는 회귀 테스트: 26/26 통과.
- 36개 화면 비율·반지름 조합, 구 표면 18,432개 점의 화면 맞춤 검사.
- 1,024개 유효 드래그 후보와 stale/특이값/희소 배열/음의 0 검사.
- 3축 및 기준점 조합 27개 정렬 검사.
- TS/TSX 소스 16개 구문 변환 진단 0개.
- 기존 뷰포트 함수 21개 본문 동일성 및 기존 소스 검사 15개 통과.

로컬 검증 환경은 Node 22.16.0 / TypeScript 5.8.3이다. 저장소 전체의 요구 도구 체인·의존성 검증과는 구분한다.

재현 가능한 순수 계산 검사:

```sh
node scripts/verify-studio-hybrid-dcc-viewport-kernels.mjs
```

스크립트는 프로젝트 TypeScript로 4개 모듈을 엄격 컴파일하고, Vitest 테스트의 등록기만 node:test로 바꿔 동일 assertion을 실행한다. React/Three.js/WebGL을 모의 구현하여 통과했다고 하지 않는다.

## 추가했지만 실행하지 못한 통합 검사

카메라 5개, 기즈모 7개, 뷰포트 연결 8개: 합계 20개 테스트를 추가했다. 실제 React·Three.js 의존성과 온라인 데스크톱을 확보하지 못해 이 환경에서는 실행하지 않았다. 전체 typecheck/lint/build 및 브라우저 WebGL/E2E도 통과로 간주하지 않는다.

## 미구현·미검증 범위

다중 오브젝트 동시 변환, 면/정점 표면 스냅, 영구 원점 변경·메시 bake, 완전한 편집 모드 기즈모, Blender급 Sculpt/리토폴로지·UV/셰이더 노드·리깅/애니메이션·시뮬레이션·최종 렌더 동등성은 이 변경의 완료 범위가 아니다. 경계 정렬은 표면 접촉/충돌 계산이 아니며 복사 버퍼는 시스템 클립보드가 아니다.

기존 오목 다각형·혼합 split-normal 렌더 제한과 대용량 안전 예산을 해제하지 않았다. 제대로 구현되지 않은 경로를 지원한다고 표시하거나 검사만 제거하지 않는다.

# ToonStudio 창작자 연결·홍보 커뮤니티

조사 및 작성: 2026-09-13. 대표 서비스의 공식 소개·도움말·공개 커뮤니티를 비교했다. 모든 국내외 사이트를 전수 조사한 결과가 아니며, 로그인 후 거래·결제·운영자 기능을 실제 이용한 것으로 표현하지 않는다.

## 제품 방향

창작 도구 → 작품 공개 → 독자 피드백 → 협업자 발견의 흐름을 만든다. 유료 작업 의뢰와 팀원 모집, 작품 홍보를 구분해 탐색 목적과 공개 정보를 다르게 설계한다. 프로필을 공통 연결점으로 사용하되 지원 연락처를 공개 댓글이나 검색 목록에 노출하지 않는다.

## 별도 진행 중인 협업 모집 작업

로컬 별도 worktree `toonstudio-collaboration-board-20260913`에 팀원 모집/작업 의뢰/작업자 홍보, 역할·보수·분량·납품·권리 조건, 지원·북마크·신고 코드가 이미 작성 중이었다. 그 worktree는 수정하지 않았다. 이 PR은 해당 구현을 완료·검증하거나 병합한 것으로 간주하지 않는다.

협업 게시판과 통합할 때에는 다음을 유지한다.
- 어시 역할: 콘티/선화/밑색/채색/배경/3D/식자/모션 등.
- 보수 유형과 컷·회차·프로젝트 단가, 유급 테스트 여부, 수정 횟수, 지급 일정, 크레딧·권리 조건.
- 무보수 협업과 유료 용역의 명확한 분리. 수익배분은 비율·정산 기준 명시.
- 연락처는 작성자와 지원자, 필요한 운영자에게만 표시. 지원 철회와 마감 처리.
- 새 라우트/모듈/스키마 export/마이그레이션 manifest 충돌 해결 시 양쪽 추가 내용을 보존.

## 이번 PR의 구현 범위

- `/community/promote`: 작품·신작 소개, 홍보 영상, 작업 과정, 피드백 요청.
- 아마추어/첫 작품·신작/연재 작가, 장르, 제목·작품명·태그 검색.
- 최신 등록순 keyset pagination, 내 게시물, 저장한 작품. 가짜 인기·조회수·샘플 게시물 없음.
- `/community/promote/new`, `/:id/edit`: 소유자 편집, 버전 충돌, 오류 시 입력 유지, 권리 확인.
- `/:id`: 작품 링크, 작가 프로필, 북마크, 댓글, 자기 댓글 삭제, 신고, 보관/복구.
- `/community/promote/moderation`: 운영자 신고 열람, 상세에서 비공개/복구.
- 표지는 기기 내에서 JPEG로 변환, 최대 640×800px / 128KB. 원본 이미지 메타데이터를 업로드하지 않음.
- YouTube/Shorts 또는 공개 Vimeo 링크. 정확한 호스트·영상 ID만 허용하고 사용자가 클릭하기 전 iframe을 생성하지 않음. 자동재생 없음. 제한 영상은 원본 서비스 링크로 이동.
- API 저장 실패는 503으로 전달. 장애를 빈 목록이나 등록 성공으로 위장하지 않음.
- 작성자만 수정/보관. 운영 비공개는 작성자가 편집해도 해제되지 않음. 댓글 쓰기는 게시물 행 잠금으로 공개 상태와 동시성 확인.
- 로그인된 사용자당 최근 24시간 게시물 5개, 총 100개 제한. DB advisory lock으로 동시 등록 할당량 경쟁 방지. 댓글은 게시물당 최대 1,000개, 화면에는 최근 50개.
- 새로운 유료 API, 결제/에스크로, 서버 영상 변환, 신규 스토리지 가입 없음.

## 제공하지 않는 기능 / 운영 전 주의

원본 동영상 직접 업로드, 자체 영상 저장·트랜스코딩·CDN, 자동 홍보 영상 생성, 실시간 알림·작가 팔로우, 거래 보증/에스크로, 상세 조회수 통계, 성인 인증은 구현 범위가 아니다. 성인 콘텐츠는 허용하지 않는다. 콘텐츠 권리 체크박스는 소유권 검증이나 자동 심의를 의미하지 않는다. JPEG 검사는 형식·크기 검증이며 서버 측 이미지 디코더 검사나 악성코드 검사가 아니다.

추가 유료 서비스를 도입하지 않았다는 뜻이지 기존 DB/호스팅의 사용량이 무제한 무료라는 뜻은 아니다. 공개 규모가 늘면 전체 저장량·응답 크기·트래픽·신고 처리량을 관측하고 무료 한도 내에서 전역 게시 한도 및 보관 정책을 결정해야 한다. 개별 작가의 새 계정 생성을 통한 도배까지 완전히 차단하는 시스템은 아니다.

## 검증 및 배포

`node --experimental-strip-types --test scripts/verify-promotion-contract.mjs`는 Node 24에서 별도 패키지 설치 없이 공통 입력/응답/URL/크기/커서/라우트/CSP/마이그레이션 계약을 검증한다. `PromotionVideo.test.tsx`는 클릭 전 외부 플레이어 없음, 허용 호스트, 영상 변경 시 동의 초기화를 확인한다. GitHub workflow는 웹/API 타입 검사도 실행한다. 테스트 파일을 추가한 사실과 해당 테스트의 실제 통과는 구분하며 PR 체크 결과를 확인해야 한다.

운영 적용 순서: 기존 CI 통과 → 별도 임시 DB에서 `0046_creator_promotion_community.sql` 검증 → 배포 시스템의 manifest 기반 마이그레이션 → API/웹 배포 → 비로그인 목록·계정 간 권한·등록/수정/댓글/북마크/신고·모바일·실제 영상/CSP smoke test.

현재 변경은 운영 DB를 수정하거나 main에 병합하지 않는다. 기존 데이터를 삭제하지 않는다. 동시 작업 중인 협업 게시판의 마이그레이션 번호와 export/라우트 추가를 모두 보존해야 한다. 운영 적용 전 현재 main으로 재동기화하고 개인정보 처리방침에 공개 게시물·댓글·신고·외부 영상 제공자 관련 항목을 검토한다.

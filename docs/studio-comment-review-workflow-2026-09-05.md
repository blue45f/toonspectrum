# Studio 댓글 검수 워크플로 고도화 — 2026-09-05

## 목표

캔버스의 댓글 핀에서 검토 레일로 이동할 때 대화 맥락과 작성 중인 답글을 잃지 않고, 많은 댓글을 키보드만으로 빠르게 순회할 수 있게 한다.

## 사용자 흐름

1. 캔버스 핀을 선택하면 최근 대화와 빠른 답글을 바로 확인한다.
2. 이전 메시지가 있으면 같은 팝오버에서 전체 대화를 펼치거나 다시 최근 메시지만 접는다.
3. 검토 레일의 `나와 관련` 필터로 자신이 작성·참여·담당·멘션된 댓글을 한 번에 모은다.
4. 검색은 댓글 본문, 작성자, 답글, 담당자, 멘션 이름을 함께 찾는다.
5. `/`로 검색창에 진입하고 `J`·`K`로 현재 결과의 다음·이전 댓글을 순서대로 검수한다.
6. 검색 중 `Esc`는 검색어를 먼저 지우며, 빈 검색 상태에서만 기존 닫기 동작으로 이어진다.

## 유지하는 계약

- 댓글 문서 스키마와 앵커 정체성
- 팀 댓글 권한 및 mutation disabled 사유
- 읽음 처리와 전체 읽음 처리
- 캔버스 핀 팝오버·검토 레일이 공유하는 답글 초안
- retry-safe mutation ID와 receipt 소유권
- 해결·재열기·담당자 배정 흐름

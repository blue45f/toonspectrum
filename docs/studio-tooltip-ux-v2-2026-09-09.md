# Studio Tooltip UX v2

작성일: 2026-09-09

## 목표

Studio의 툴팁은 단순 라벨이 아니라 도구 발견, 단축키 학습, 비활성 조건 설명, 동작 미리보기를 제공하는 경량 코치다. v2는 기존의 포커스·호버·터치 롱프레스·2단계 리치 미리보기 구조를 유지하면서 다음 문제를 줄인다.

- 촘촘한 툴바를 지나갈 때 연속으로 열리는 툴팁 소음
- 컴팩트 설명에서 리치 미리보기로 커질 때 방향이 뒤집히거나 위치가 튀는 현상
- 모바일 브라우저 주소창, 화면 키보드, 핀치줌 이후 보이는 영역 밖으로 밀리는 현상
- 긴 번역이나 사용 조건이 작은 화면에서 잘리는 현상
- 드래그, 스크롤, 탭 전환, 창 포커스 상실 뒤 남는 잔상
- 세션 내 자동 노출 상한에 도달한 뒤 도움말을 다시 발견할 수 없는 현상

## 상호작용 계약

| 입력 | 노출 | 확장 | 종료 |
| --- | --- | --- | --- |
| 첫 마우스 호버 | 280ms 의도 지연 | 리치 모드에서 추가 620ms 머무르면 동작 미리보기 | 타깃과 버블 양쪽을 벗어난 뒤 280ms, Escape, 스크롤, 외부 클릭 |
| 이미 열린 호버 툴팁에서 다른 도구로 이동 | 90ms 웜 전환 | 동일 | 동일 |
| 키보드/보조기기 포커스 | 즉시 | 리치 모드에서 즉시 | Blur, Escape, 창 포커스 상실 |
| 터치 롱프레스 | 사용자 설정 시간 뒤 즉시 | 컴팩트 유지 | 외부 탭, Escape, 스크롤 |
| 드래그 중 진입 | 노출하지 않음 | 해당 없음 | 버튼을 놓고 새 의도를 만들 때 다시 평가 |
| 비활성 도구 | 포커스 가능한 비상호작용 그룹으로 조건 설명 | 사용 조건을 항상 제공 | 일반 툴팁과 동일 |

## 노출 정책

자동 호버는 명시적 도움 요청과 분리한다.

1. 동일한 의미 도구는 자동 노출 뒤 90초 동안 다시 열지 않는다.
2. 도구를 실행한 뒤에는 5분 동안 같은 의미 도구의 자동 코칭을 멈춘다.
3. 한 도구는 15분 학습 창 안에서 최대 2회 자동 노출한다.
4. 20초 안에 서로 다른 도구를 포함해 자동 노출이 6회 발생하면 남은 창 동안 새 호버 노출을 멈춘다.
5. 15분이 지나면 도구별 학습 창이 초기화되어 긴 편집 세션에서도 도움말이 영구 소진되지 않는다.
6. 키보드 포커스와 터치 롱프레스는 항상 명시적 도움 요청으로 취급해 위 제한을 적용하지 않는다.
7. 비활성 이유는 작업을 완료하는 데 필요한 운영 정보이므로 반복 제한을 적용하지 않는다.

## 배치 및 반응형 처리

- `VisualViewport`가 있으면 `offsetLeft`, `offsetTop`, `width`, `height`를 사용한다.
- 리치 모드에서는 컴팩트 단계부터 최종 코치 크기(304px × 예상 높이)를 배치 선택에 예약한다.
- 한 번 선택한 방향은 실제 버블이 들어가고 예약 크기의 부족분이 작은 동안 유지한다.
- 타깃이 리사이즈되거나 브라우저 방향, 레이아웃 뷰포트, 시각적 뷰포트가 변하면 한 프레임으로 측정을 합친다.
- 타깃이 DOM에서 제거되거나 보이는 뷰포트 밖으로 완전히 이동하면 떠 있는 잔상 대신 툴팁을 닫는다.
- 긴 내용은 화살표를 자르지 않는 내부 스크롤 영역에서 읽을 수 있다.

## 모션 언어

- 진입은 타깃 방향에서 5~6px 이동하며 160ms 안에 정착한다.
- 리치 미리보기는 상단 기준으로 짧게 페이드·스케일 인한다.
- 좌표, 너비, 그림자 변화는 같은 감속 곡선을 사용해 확장 단계가 한 동작처럼 보이게 한다.
- `prefers-reduced-motion` 또는 Studio의 모션 감소 설정에서는 애니메이션과 전환, `will-change`를 제거한다.
- 고대비 설정에서는 블러를 제거하고 테두리와 그림자 경계를 강화한다.

## 접근성 기준

- 포커스는 항상 트리거에 남고 버블은 `role="tooltip"`과 정확한 `aria-describedby` 관계만 제공한다.
- Escape로 즉시 닫을 수 있다.
- 포인터가 트리거에서 버블로 이동해도 내용을 읽을 수 있도록 호버 가능 상태를 유지한다.
- 사용자 입력 없이 사라지지 않도록 타깃/버블 이탈 유예를 둔다.
- 네이티브 `title`과 커스텀 툴팁의 중복 노출을 막되 접근 가능한 이름은 유지한다.
- 비활성 네이티브 버튼의 상태는 바꾸지 않고 별도 그룹 프록시에서 사용 조건을 탐색할 수 있게 한다.

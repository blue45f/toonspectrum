# ToonStudio: 품질·다양성 중심 에셋 확보 기준

조사일: 2026-09-06. 아래 목표와 제작 브리프는 확보 완료 수량이 아니다.

## 결론과 적용 범위

1,000개는 공개 가능한 독립 원본의 최소 수량이다. 계획 수량은 12분류 1,200개로 잡되 품질 점수나 재배포 권한을 낮춰 채우지 않는다. 다운로드한 ZIP, ZIP 내부 파일, 포맷·해상도·색상 변형, 텍스처의 구성 맵을 독립 에셋으로 집계하지 않는다.

이번 변경은 조사 문서, 명시적으로 고른 무료 원본의 격리 수집기, 검수 증빙 검사기, 오프라인 테스트 및 소규모 수집 워크플로다. 기존 편집기 UI, 공유 카탈로그 API, 업로드 명령, main, 운영 배포에는 연결하지 않았다. 실제 고품질 원본의 제작·인간 검수·편집기 E2E 검증을 대신하지 않는다.

## 원본별 승인 기준

작화 완성도 25, 편집성 20, 스타일 일관성 15, 장면 유용성 20, 기술 품질 10, 검색·미리보기 10의 가중치다. 서로 다른 두 명의 검수 기록이 각각 85/100 이상이고, 모든 항목이 4/5 이상이어야 한다. 실제 검수 기록 없이 기본 점수를 채워 넣지 않는다.

권리, 원본, 미리보기, 검수 기록, 편집기 검증 결과는 SHA-256으로 연결한다. 원본이 바뀌면 과거 기록으로 통과할 수 없다. CC0·CC BY 또는 직접 계약으로 원본 재배포와 서비스 내장 권한이 확인된 항목만 후보로 인정한다. CC BY는 출처 표기를 필수로 남긴다. 유료 구매·수수료 계약은 이번 작업에서 진행하지 않는다.

단순 상업적 사용 가능 표시만으로 통과시키지 않는다. CC0도 상표·인격권·개인정보와 원본 진위를 자동 해결하는 것은 아니다. 권리 검수자가 원본별로 검토하며 법률 의견을 대체하지 않는다.

### 포맷별 검수 차이

- 네이티브 템플릿·말풍선·효과음: 내부 요소, 한글 텍스트, 꼬리, 프레임 간격을 실제 수정하고 저장·재열기·실행취소·내보내기 확인. 한 장의 SVG/PNG 삽입은 네이티브 편집형으로 인정하지 않음.
- 이미지·효과: 실제 사용 크기에서 선명도, 투명 가장자리, 흰색·검정색 배경 합성. Kenney 512px 파티클은 작은 효과용 후보이며 전체 컷용 고해상도 소재로 표시하지 않음.
- 패턴·스크린톤: 반복 이음새, 축소 시 모아레, 출력 해상도에서의 밀도. 고해상도라는 이유만으로 선화 웹툰에 적합하다고 판단하지 않음.
- 3D: 실제 단위·축·피벗, 재질·텍스처 포함, 실루엣, 화면별 폴리곤 예산, 카메라 커버리지. glTF 원본은 외부 텍스처 누락을 해소한 GLB 및 편집기 결과 검증 필요.
- 포즈: 리그 호환, 관절 제한, 리타게팅, 의자·소품·몸의 관통 확인. 포즈 수와 애니메이션 프레임 수를 혼동하지 않음.

## 구현과 실행

Python 3.11 이상, 외부 패키지 없이 실행한다.

```bash
python3 -m unittest discover -s scripts/tests -p test_studio_asset_curation.py -v
python3 scripts/acquire_studio_asset_pilot.py data/studio-assets/acquisition-plan.json --output /tmp/toon-asset-quarantine-new
python3 scripts/studio_asset_curation.py /tmp/toon-asset-quarantine-new/curation-manifest.json --root /tmp/toon-asset-quarantine-new --release
```

마지막 명령은 아직 검수한 에셋이 없는 격리 목록이므로 실패하는 것이 정상이다. 최초 빈 매니페스트를 1,000개 확보 성공처럼 통과시키지 않는다. 실제 검수 완료 매니페스트를 별도로 작성한 후 `--release --output report.json`으로 확인한다. 샘플 단계에서 `--release`를 빼더라도 `releaseReady`는 false다.

수집기는 5개의 명시적 무료 ZIP 링크만 사용한다. 호스트와 리다이렉트를 제한하고, ZIP 경로 이탈·심볼릭 링크·암호화·용량 초과를 차단한다. 다운로드 최대 192MiB, 압축 해제 최대 384MiB다. 실행 파일·중첩 압축·폰트는 보존하지 않으며 원본 ZIP도 배포하지 않는다. 에셋 코드나 플러그인을 실행하지 않는다.

`quarantine-index.json`은 수집 성공·실패, 원본 URL, 다운로드 해시, 실제 저장 파일을 기록한다. `approvedOriginals`와 `productionPublished`는 수집기에서 항상 0이다. 모든 검수 전에 자동으로 기존 업로드 파이프라인에 연결하지 않는다.

현재 검사기는 검수 기록의 누락·변조와 집계·정책을 검사한다. 검수자 실명 인증, 실제 미적 평가, 이미지 디코딩 안전성, 네이티브 편집기 JSON 스키마 전체 검사, perceptual hash 유사도 검색, 운영 권한 관리 시스템을 구현한 것은 아니다. 라이브러리에 배포하기 전 해당 연결과 실제 사용 검증이 추가로 필요하다.

테스트에는 가짜 파일·모킹한 1,200개 메타데이터가 사용된다. 이들은 테스트 코드일 뿐 실제 제작된 에셋도 확보 수량도 아니다. 전체 애플리케이션 빌드·브라우저 E2E를 통과했다는 의미가 아니다.

# ToonStudio — 가상 스튜디오 중심 개편 설계 v2

2026-09-21 · 구현 기준안. 승인·전체 구현·운영 배포와 구분한다.
기준: `cb2913ecf67241f3055111a1b23f600b91e90505`, PR #1884, 기존 사이트 개편 워크트리.

## 1. 제품 정의

**혼자 시작하고, 함께 만들고, 완성한 작품을 공개하는 창작자의 온라인 스튜디오.**
공간은 작업을 시작하고 돌아오는 장소다. 가상세계 이동이나 꾸미기는 작업의 선행 조건이 아니다.
전역 탐색 → 작품 작업실 → 집중 도구의 세 층으로 구성한다. 공간/목록 보기는 같은 작품의 다른 표현이다.

## 2. 기존 구현에서 유지/수정할 것

유지: 4개 메뉴, 기존 문서/프로젝트 ID, 정확한 이어하기, 저장·복구, 원본 아트, 계정 흐름, 모바일 목록 기본값.
수정: 208px 사이드바와 상시 284px 작업 카드가 공간을 압박하는 구조, 작은 상태 글씨, 숫자만 보이는 공간 핀.
보류: 신규 세계 엔진, 신규 workspace DB, 실시간 세션/드로잉 엔진 교체, 운영 배포.
검증 보완: 중단된 QA 이어쓰기, 실제 theme store 전환과 계산 색상 차이, 낮은 화면 높이에서 행동 노출.

## 3. 전역 메뉴와 페이지 책임

| 메뉴 | 질문 | 포함 | 제외 |
|---|---|---|---|
| 스튜디오 | 무엇을 이어서 하나? | 공간/목록, 현재 작품, 이어하기, 실제 공간 입장 | 홍보 대시보드, 공개 피드 |
| 작품 | 원고·결과물을 어떻게 관리하나? | 목록, 회차, 진행, 검수, 소재, 저장·복구·내보내기·게시 | 공개 전시를 내 작업으로 대체 |
| 팀 | 누구와 어떤 권한으로 일하나? | 멤버·권한 / 모집·의뢰 / 대화·면접 준비 | 소재 거래, 아바타 설정 |
| 둘러보기 | 무엇을 발견하나? | 작품 / 소재 / 사람 / 배움·라운지 | 비공개 원고 관리 |

검색·계정·설정·도움말은 유틸리티. 실제 알림 데이터가 없는 배지나 접속 숫자는 만들지 않는다.
작품 내부: 개요 → 이야기·회차 → 원고·진행 → 검수 → 소재 → 내보내기·게시 → 작품 설정.
관리자 화면은 별도 표면이며 전역 사용자 메뉴에 합치지 않는다.

## 4. 화면 구성

홈: 상단 약 64px, 라벨 있는 탐색 약 96px, 하단 이어하기·상태 약 64px. 중앙 원본 공간이 우선이다.
공간 홈에는 상시 ActivityRail과 최근 작품 카드를 쌓지 않는다. 작업 요약은 기존 work 패널에서 열고 최근 작품은 목록 보기·작품 선택기에서 찾는다.
이미지의 종횡비·화풍을 유지한다. 공간 컨테이너와 실제 이미지의 면적은 별도로 측정하며 아트를 가로로 늘리지 않는다.
원고 이어하기와 실시간 공간 입장은 다른 행동이다. 대상이 없으면 '작품 열기', 사라졌으면 '원고 목록 확인' 또는 '저장 공간 확인'으로 표시한다.
신규 방문: 새 작품 만들기 / 파일 가져오기. 기존 로컬 편집을 로그인 필수로 바꾸지 않는다. 투어·설명은 도움말로 분리한다.
목록: 현재 작품 → 실행할 작업 → 최근 작품. 기존 사용자 보기 선택을 유지하며 모바일 신규 기본값은 목록이다.
작품: 실제 목록·검색·정렬·보관·휴지통 우선. 설정과 전문 도구는 접어서 제공하되 제거하지 않는다.
팀: 작품 멤버십과 채용 그룹을 분리. 모집 게시·면접 참가·원고 공유는 각각 별도 행동과 권한이다.
둘러보기: 기존 쇼케이스/마켓/리서치/구인/학습 URL을 보존한다. 소재 적용은 사용 조건 확인 뒤 명시적으로 수행한다.
집중 도구: 기존 원고·3D·검수·면접 화면이 UI와 상태를 소유한다. 홈 CSS를 도구에 강제 적용하지 않는다.

## 5. 공간과 행동

| 공간 | 행동 | 실패 처리 |
|---|---|---|
| 내 책상 | 같은 작품의 정확한 원고 이어하기 | 누락 문서를 다른 문서로 대체하지 않음 |
| 이야기/콘티 벽 | 선택 작품 이야기·회차 | 작품 없으면 선택 안내 |
| 작품 보드 | 선택 작품의 진행·검수 | 공간 위치나 아바타 반응을 승인으로 보지 않음 |
| 소재장 | 작품 소재 또는 개인 소재 | 조회/미리보기와 삽입을 구분 |
| 팀/회의 공간 | 현재 작품 팀 또는 해당 세션 | 권한 확인, 미디어 직접 실행 |

핵심 행동은 텍스트와 키보드로도 접근한다. 숫자 핀만 암기하게 하지 않는다.

## 6. 상태·권한·패널

선택 작품은 화면 전환으로 바꾸지 않는다. project/scope 파라미터는 참조이지 권한이 아니다.
원고 본문·파일·미디어·접속자 정보를 URL이나 새로운 거대 UI store로 복제하지 않는다.
패널은 기본 닫힘, 동시에 하나. 대화상자는 Escape·초점 복귀·한국어 조합 입력을 유지한다.
향후 업무 inspector의 비모달화는 별도 검증하며, 기존 모달의 초점 보호를 단순 제거하지 않는다.
로딩/실제 빈 상태/누락 문서/저장소 오류/권한 만료/공간 실패를 구분한다.
공간 실패는 같은 작품의 목록 보기로 복구한다. 로딩·오류 상태에 새 작품이나 엉뚱한 원고를 대신 열지 않는다.
로컬 저장, 서버 동기화, 공유, 검수 승인, 인수, 게시를 같은 완료 상태로 합치지 않는다.

## 7. 경로·호환성

| 경로 | 책임 |
|---|---|
| /, /home | 같은 스튜디오 홈, 기존 소개 앵커 호환 유지 |
| /studio | 작품 라이브러리; id/remix/mode 구 링크는 기존 resolver |
| /studio?view=archived 또는 trash | 보관·복구와 기존 확인 절차 |
| /studio?view=storage 또는 exports 또는 publications | 저장·결과 관리 |
| /studio/new, /studio/import | 기존 생성·분석·원본 보존 |
| /studio/p/:id/* | 기존 작품·문서·버전 route registry |
| /studio/p/:id/space | 실시간 공간, 홈 미리보기와 구별 |
| /team, /collaborate/* | 팀·모집·세션 |
| /hub, /showcase, /market, /research, /discover, /ranking, /community, /learn | 기존 공개 발견·학습 |
| /about/studio, /product-tour, /help, /settings, /my | 소개·도움·계정·환경 |

원본 세계 엔진/데이터/브러시와 병행 중인 세션·월드·드로잉 워크트리는 임의 병합하거나 삭제하지 않는다.

## 8. 비주얼·검증

기존 warm-ink/persimmon, 한국어 UI 글꼴과 테마 토큰을 재사용한다. 원고 픽셀에는 테마를 적용하지 않는다.
핵심 조작은 14–16px, 상태는 12–13px 목표. 8–10px는 비필수 장식 레이블로 제한한다.
1440×900, 1366×768, 1024×768, 390×844, 320px 폭, 200% 확대와 Reduced Motion을 검증한다.
주요 터치 타깃은 제품 목표 44px 이상. WCAG 2.2 AA 2.5.8의 24px 및 예외/간격 조건과 혼동하지 않는다.
고정 하단 메뉴가 포커스된 조작을 가리지 않아야 한다. 모달 초기 초점·Escape·복귀를 확인한다.
테마 검사는 data-theme만 바꾸지 않고 theme store를 호출하여 data-design-theme와 계산 색상의 실제 차이를 확인한다.
모바일/데스크톱·두 테마의 자동 접근성 검사를 구분 기록한다. 자동 검사 통과는 전체 WCAG 인증이 아니다.
로그인 창 진입은 OAuth 성공이 아니며, FE 빌드는 DB·다자 통화·운영 배포 검증이 아니다.

## 9. 이어서 작업할 순서

S0 설계 기준선 → S1 홈 구조 정렬 → S2 작품/원고 연속성 → S3 주요 페이지 통일 → S4 실제 공간/집중 도구 통합 → S5 회귀 검증 → S6 승인 후 릴리스.
이번 재개는 같은 브랜치에서 S1의 상시 카드 제거·공간 라벨·가독성과 중단된 테마 QA를 우선 처리한다.
S4는 기존 live-space/세션/드로잉 작업과 변경 범위를 대조해야 한다. 모든 전문 도구를 이번 변경에서 재작성한 것으로 보고하지 않는다.
main 머지·배포는 이번 설계 작성의 완료 조건이 아니다. 운영은 별도 명시 승인과 검증된 SHA 기준 수동 배포만 허용한다.

## 10. 이번 재개에서 적용·검증한 범위

설계 작성 후 같은 브랜치에서 홈 구조를 조정했다. 좌측 96px 탐색, 상단 64px, 공간 홈의 상시 작업 카드 제거, 목록 보기에서만 최근 작품 노출, 명시적으로 여는 작업 상세, 기본 공간 라벨을 반영했다. 원본 아트와 기존 문서 처리·권한은 바꾸지 않았다.

- 관련 Vitest: 17개 파일, 141개 테스트 통과. 공간 홈의 상시 카드 부재와 작품을 유지한 작업 패널 열기를 추가 검증했다.
- 변경 코드 ESLint, 프런트엔드 TypeScript, 아키텍처·앱 경계 검증 통과.
- Vite 프로덕션 빌드: 종료 코드 0. 기존 리뷰 캡처 모듈의 동적 import 경고와 플러그인 시간 경고는 남아 있다.
- 브라우저: 홈/작품/팀/둘러보기 × 1440×900, 1366×768, 1024×768, 390×844, 320×740의 20개 조합에서 가로 넘침·런타임 오류 없음.
- 1440px 주요 4페이지에서 다크·라이트 각각 axe WCAG 2 A/AA 규칙 위반 없음. 테마 store를 변경하고 계산된 전경·배경색의 전환 완료까지 기다려 확인했다.
- 홈↔팀↔둘러보기 작품 문맥, 작품 선택기, Escape, 누락 작품, 이미지 실패 시 목록 복구, 로그인 창 진입 검증 통과.

결과 파일은 `/tmp/toonstudio-design-v2-final-matrix-20260921/browser-report.json`에 있다. 검증용 작품과 비로그인 응답은 폐기 가능한 브라우저 컨텍스트에만 사용했다.
200% 실제 브라우저 확대, 전 경로 탐색, 실제 OAuth·클라우드 저장·다자 통화·운영 백엔드 검증은 이번 결과에 포함하지 않는다. 전체 제품 또는 접근성 인증 완료로 해석하지 않는다.
PR은 설계·통합 검토용 Draft를 유지하며 main 병합과 운영 배포는 수행하지 않았다.

# 가상 스튜디오 메인 통합 릴리스 — 2026-09-21

승인: 사용자가 “완전 가상 스튜디오가 메인이되게 최대한 고도화 기능 확장 모두 구현하고 메인 배포”를 요청했다. 아래 코드 검증 후 main의 단일 SHA를 기존 Cloudflare 정적 웹과 Render Core API에 수동 반영한다. 실제 배포 ID는 운영 결과에 별도로 남긴다.

## 제품 변경

- `/`와 `/home`의 공간 보기는 정적 미리보기 대신 기존 Phaser 공간 런타임을 직접 실행한다. 이동·충돌·사물 조작·NPC·좌석·지도·가이드를 기존 구현과 공유한다.
- 새 기기는 모바일까지 가상 스튜디오로 시작한다. 기존에 저장한 목록 보기 선호는 유지하고, 상단에서 공간/목록을 직접 전환한다.
- 작품이 없는 개인 공간은 로컬 전용이며 서버 작품·멤버십·통화·입장 권한을 만들지 않는다. 작품 선택 시 동일한 정확한 ID로 기존 권한과 연결 경계를 사용한다.
- 현재 원고 이어하기와 방·팀원 검색, 검수·작업함, 공동 작업 세션을 공간 바로 위에 둔다. 입력 중에는 방향키가 월드로 전달되지 않는다.
- 사람 목록의 중복을 제거하고 전체/근처/대화 중 필터와 이름 검색을 연결했다. 사용자 캐릭터/활동별 이미지 호환 처리를 유지한다.
- 데스크톱 업무 패널은 비모달 inspector, 좁은 화면과 명령 검색은 모달로 표시한다. Escape·초점 복귀·한국어 조합 입력 처리를 유지한다.
- 실제 제작 작업·고정 검수본·인수인계 봉투를 같은 작품의 작업함에서 접근한다. 상태가 읽음/인수/완료/승인/게시로 혼합되지 않는다.

## 공유 공간과 대화

공간 초안→게시→정확한 버전 적용은 서버 권한·content hash·낙관적 버전 확인·중복 요청 receipt로 처리한다. 롤백은 과거 원본을 덮어쓰지 않고 새 게시 버전으로 남긴다. decode 실패 시 현재 정상 공간을 유지한다.
비공개 대화는 정확한 게시 공간과 Core 연결 lease, 방·문·참여자 epoch를 묶고, 2–4인의 명시적 동의를 확인한다. 이동·권한 회수·lease 만료·연결 종료 시 닫힌다. 실제 미디어를 자동 시작하지 않는다.

## 공동 작업 세션

유형: 수정 검수 / 콘티 검토 / 대본 리딩 / 소재 후보 검토 / 3D 렌더 검토 / 팀 멘토링.
모든 세션은 기존 고정 검수본을 입력으로 선택하고 목적·초대한 팀원·참여·메모·결정·미결·결과 참조를 남긴다. 초안→준비→진행↔일시정지→종료/취소 흐름을 서버 버전과 receipt로 보호한다.
리딩 차례 지정은 마이크를 시작하지 않는다. 세션 종료는 원고 승인·게시가 아니다. 소재/AI 메모는 사람의 검토 기록이며 별도의 AI 생성이나 라이선스 판정 기능으로 표시하지 않는다.
서버는 작품 접근과 현재 멤버십, 초대 범위, 원본/결과의 정확한 참조를 매번 검증한다. 결과 불명 요청은 같은 receipt를 먼저 조회하며 자동 재전송하지 않는다.

## 운영 범위

기존 graph/revision/operation/receipt/live-lock 테이블을 재사용한다. 새 DB migration, 도메인·권한 정책·운영 환경 변수·요금제 변경은 없다. 원본 아트와 브러시/원고 엔진은 교체하지 않았다.
기존 개편·공간·세션 워크트리는 보존하고 snapshot과 변경 파일 hash를 통해 통합했다. 다른 작업자가 진행 중인 드로잉·음악 등의 미병합 변경을 임의로 포함하지 않는다.

## 검증 기록

통합 프런트엔드/모델/서비스 회귀 84개 파일, 845개 테스트 통과. CI 실행 계약 31개 통과.
별도 새 loopback PostgreSQL에서 공간 원장 59개와 작업 세션 6개 테스트 통과. 운영 DB에는 검증 데이터를 쓰지 않았다.
개인 메인의 실제 Phaser는 1440×900, 1366×768, 1024×768, 390×844, 320×740에서 공간/목록/주 메뉴 탐색과 가로 넘침을 검사했다.
실제 방향키 이동 및 검색 중 이동키 차단을 확인했고, 개인 공간은 서버 입장·작업 세션 API를 호출하지 않았다.
공간 게시 브라우저 7개 시나리오, 비공개 대화 loopback RTCDataChannel 6개 시나리오가 통과했다.
프런트엔드와 API TypeScript, 변경 코드 ESLint, 아키텍처 경계 검사 통과.

브라우저 협업 검증의 인증/HTTP는 합성 응답이며 실제 WAN 사용자 두 계정의 카메라·마이크 통화를 인증한 것은 아니다.
전체 전문 도구의 모든 기능 또는 전체 접근성 인증 완료로 일반화하지 않는다.

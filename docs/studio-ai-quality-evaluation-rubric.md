# Studio AI 웹툰 품질 평가 루브릭

이 문서는 모델 이름이나 공급자 홍보 문구가 아니라 **연재 제작에 실제로 쓸 수 있는 결과**를 같은 기준으로 평가하기 위한 규칙이다. `scripts/verify-studio-ai-quality.mts`와 함께 사용한다.

## 평가 원칙

1. 후보와 기준 모델의 이름을 숨긴 블라인드 평가를 기본으로 한다.
2. 동일한 스토리·참조 팩·출력 규격·시간 제한을 사용한다.
3. 사람 평가자 3명 이상의 중앙값을 기록한다. 평가자 간 점수 차이가 15점을 넘으면 근거를 남기고 재판정한다.
4. 평균 점수가 높아도 정체성 붕괴, 텍스트 훼손, 원본 덮어쓰기, 출처 누락 같은 중대 실패가 하나라도 있으면 출시를 막는다.
5. “예쁜 한 장”이 아니라 연속 컷, 수정 시간, 재사용성, 부분 실패 복구까지 측정한다.

## 공통 점수 앵커

| 점수 | 판정 기준 |
|---:|---|
| 95–100 | 바로 연재 원고에 사용할 수 있다. 육안상 결함이 거의 없고 수정이 선택 사항이다. |
| 85–94 | 제작 가능. 컷당 2분 이내의 경미한 손질만 필요하다. |
| 70–84 | 초안으로는 유용하지만 컷당 2–10분의 수동 보정이 필요하다. |
| 50–69 | 상당한 재작업 또는 여러 번의 재생성이 필요하다. |
| 1–49 | 의도·연속성·편집성 중 하나가 무너져 실무 사용이 어렵다. |
| 0 | 생성 실패, 데이터 손실, 권리/출처 차단 실패 등으로 평가 불가 또는 즉시 차단 대상이다. |

## 평가 축

| 축 | 100점에 가까운 상태 | 대표 감점 사유 |
|---|---|---|
| `characterIdentity` | 얼굴, 체형, 헤어, 의상, 소품의 핵심 식별점이 각도·표정·조명·가림에도 유지된다. | 다른 인물처럼 보임, 의상/소품 교환, 다인 장면 특징 혼합 |
| `styleConsistency` | 선질, 채색, 명암, 재질, 팔레트가 컷과 에피소드 전체에서 의도한 범위 안에 있다. | 컷별 렌더러가 달라 보임, 갑작스러운 실사화/SD화 |
| `anatomyAndFaces` | 손·얼굴·관절·원근이 의도된 스타일 안에서 자연스럽다. | 손가락 수, 이목구비 비대칭, 관절/시선 붕괴 |
| `compositionReadability` | 시선 흐름, 인물 배치, 카메라, 말풍선 여백이 세로 스크롤 독해에 적합하다. | 주연 가림, 180도 규칙 혼란, 초점 부재 |
| `letteringAccuracy` | 한글 대사·효과음이 정확하고 편집 가능한 텍스트/말풍선으로 유지된다. | 글자 깨짐, 이미지에 구워진 텍스트, 꼬리 대상 오류 |
| `backgroundContinuity` | 장소 구조, 문/창 위치, 시간대와 소품 상태가 장면 전환에도 이어진다. | 방 구조 반전, 소품 순간 이동, 광원 불연속 |
| `editability` | 결과가 패널·인물·배경·말풍선 등 수정 가능한 단위로 남고 부분 수정이 주변을 훼손하지 않는다. | 단일 PNG만 제공, 전체 재생성 강요, 마스크 경계 파손 |
| `workflowEfficiency` | 초안→후보 비교→부분 수정→적용까지 클릭·대기·재입력이 적고 작업을 중단·재개할 수 있다. | 설정 재입력, 숨은 진입점, 취소 불가, 실패 후 처음부터 재시작 |
| `rightsAndProvenance` | 참조 권리, 공급자/모델/프롬프트 버전, 편집 이력이 보존되고 서명 여부를 사실대로 구분한다. | 출처 누락, 서명되지 않은 기록을 C2PA로 표시, 권리 제한 무시 |
| `reliability` | 반복 실행, 부분 실패, 네트워크 단절, 공급자 전환에도 결과·비용·상태가 예측 가능하다. | 중복 과금, 멈춘 작업, 결과 유실, 원본 덮어쓰기 |

## 중대 실패(Hard failure)

다음은 점수와 무관하게 `hardFailures`에 기록한다.

- 원본 레이어나 기존 컷을 사용자 확인 없이 덮어씀
- 동일 요청의 의도치 않은 중복 과금 또는 중복 삽입
- 캐릭터 A/B의 얼굴·의상·소품이 서로 섞여 서사 식별이 불가능함
- 한글 대사·효과음이 의미가 달라질 정도로 훼손됨
- 참조 이미지의 사용 금지/권리 메타데이터를 알고도 전송함
- 로컬 편집 이력을 공급자 서명 또는 C2PA 검증 완료로 오표시함
- 취소 후에도 작업이 계속 적용되거나 다른 페이지에 결과가 삽입됨
- 부분 실패 때문에 이미 승인한 컷까지 사라짐

## 기준 평가 세트

`studio-ai-quality-suite.template.json`의 모든 케이스를 최소 3개 시드로 실행한다. 후보 모델당 최소 54개 결과를 확보하고, 각 결과의 생성 시간과 실제 수정 완료 시간을 함께 기록한다.

출시 기준은 기본적으로 다음과 같다.

- 종합 점수 82 이상
- 최저 케이스 68 이상
- 캐릭터 정체성 85 이상
- 편집 가능성 80 이상
- 권리·출처 90 이상
- 신뢰성 80 이상
- 완료율 95% 이상
- p95 45초 이하(외부 공급자 장애 시간은 별도 표기하되 사용자 체감 시간에는 포함)
- 중대 실패 0건
- 기준 버전 대비 어느 축도 2점 초과 회귀하지 않음

## 기록 형식

각 케이스의 `notes`에는 다음을 짧게 남긴다.

- 가장 눈에 띈 결함과 수정 방법
- 재생성 횟수와 실제 수정 시간
- 사용한 참조 역할(캐릭터/방법/화풍)과 버전
- 공급자·모델·시드·프롬프트 버전
- 마스크/부분 수정/레이어화 사용 여부
- 출처 서명 여부와 검증 결과

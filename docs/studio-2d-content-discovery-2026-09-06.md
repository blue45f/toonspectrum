# 2D 장면 탐색 및 원본 교체 안전성 후속 개선

PR #783의 검수 카탈로그를 바탕으로 한다. 신규 이미지 생성·구매·원본 재배포 승인·해상도 승격은 하지 않는다. 기존 이미지 29개와 벡터 35개를 유지한다.

## 변경

- 접을 수 있는 장소·시간·문자 상세 조건: 실내/실외, 낮/노을/밤, 문자 형태 없는 이미지. 기존 장르·품질·비율·검색·인물 유무와 AND로 결합한다.
- 조건을 확인할 수 없는 벡터·미등록 원본·교체된 URL을 문자 없는/특정 장소 배경으로 추정하지 않는다.
- 상세 조건의 적용 수를 접힌 요약에도 표시하며, 상세 조건만 지우면 기존 검색어와 장르는 유지한다. 전체 초기화는 모든 조건을 해제한다. 상세 조건을 바꿀 때에도 목록 스크롤과 표시 수를 초기화한다.
- 카드에서 장소·시간대와 인물/문자 포함 여부를 먼저 확인할 수 있다. 문자 없음은 검수 기록 기준이며 법적 권리·이미지 완전성 보증과 무관하다.
- React 카드/미리보기의 키를 ID만이 아닌 실제 이미지 주소 또는 SVG 원문에 연결한다. 같은 ID의 벡터 내용이 바뀌어도 이전 로딩 완료 상태를 재사용하지 않는다.
- 현재 카탈로그에서 제거되거나 다른 원본으로 교체된 장면은 이미 열려 있던 미리보기에서도 삽입할 수 없다. 이전 원본이 다시 등장해도 미리보기가 자동으로 다시 열리지 않는다.

## 검증 범위

기존 검증 워크플로에 필터 회귀 4개와 UI/교체 원본 회귀 7개를 추가했다. 24개 장소·시간·문자 조합은 Vitest에서 원본 메타데이터와 대조한다. 로컬 독립 검사에서는 인물 여부까지 조합한 48개 조건을 대조했다. 기존 Node 원본 감사 14개는 별도 실행했으며 테스트 수에 중복 가산하지 않는다.

기존 Chromium 스모크에 새로운 조건 조합/부분 초기화를 추가하고 뷰포트를 1280×960, 390×844, 320×740으로 확장했다. 파일 존재는 통과 증거가 아니다. 최종 커밋의 실행 로그와 browser-smoke.json을 확인한다. 이 스모크는 실제 라이브러리 컴포넌트·원본·공통 배치 함수 대상이며 전체 스튜디오/운영 배포 검증을 뜻하지 않는다.

새 라이브러리, 서버 API, 인증 데이터, 외부 이미지 요청, 프로젝트 저장 형식, 기존 CI 보호 조건은 추가하거나 변경하지 않는다. PR #783과 후속 변경은 각각 최신 main 및 현재 head의 필수 core 검증 후 순서대로 병합해야 한다.

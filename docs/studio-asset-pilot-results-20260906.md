## 실제 발견한 품질·호환성 문제와 처리

음식 GLB 200개가 파일 외부의 `Textures/colormap.png`를 참조했다. 텍스처를 GLB 내부의 bufferView로 포함시키는 정규화 코드를 작성하고 실제 파일 전체에 실행했다.

GLB 340개 처리 성공, 오류 0. 이 중 200개의 외부 텍스처 의존성을 제거했다. 340개 모두 원래 바이너리 구간과 메시·노드·재질 등 기존 장면 메타데이터가 보존되는지 비교했다. 정규화 후 외부 이미지 URI는 0개다. 이는 GLB 구조·데이터 보존 검사이며 Khronos 전체 적합성 검사나 실제 스튜디오 렌더링 검증과는 다르다.

음식 모델별 미리보기 200개는 실제 64×64px였다. 이 파일을 작품용 2D 소품으로 편입하거나 업스케일만으로 고품질이라고 표시하지 않는다. 가구의 각도별 PNG 역시 다수가 작은 미리보기 수준이므로 독립 배경 에셋으로 집계하지 않는다.

파티클의 기본 투명 마스크는 실제 80개, 각각 512×512px다. 작은 연출 효과 후보로 한정하고 전체 컷을 채우는 고해상도 효과로 승인하지 않는다. 재질의 여러 맵과 DX/GL 노멀 변형은 하나의 원본에 묶는다.

미리보기를 직접 확인한 가구·음식은 단순화된 저폴리 스타일이다. 이를 사실적인 한국형 웹툰의 대표 배경이나 정교한 근접 소품 컬렉션으로 대체하지 않는다. 해당 스타일의 보조 소품 후보로 제한한다.

## 검증과 재현

로컬 오프라인 단위 테스트 46개 통과. 테스트 데이터는 합성 데이터이며, 검수된 에셋 수가 아니다.

```bash
python3 -m unittest discover -s scripts/tests -p 'test_studio_asset_*.py' -v
python3 scripts/acquire_studio_asset_pilot.py data/studio-assets/acquisition-plan.json --output /tmp/toon-quarantine-new
python3 scripts/normalize_studio_asset_glb.py /tmp/toon-quarantine-new --output /tmp/toon-normalized-new
```

정규화 결과마다 원본·변환 후 해시와 포함한 텍스처의 해시를 저장한다. 원본은 변경하지 않는다. 폰트·실행 파일·중첩 ZIP은 제공하지 않는다. GitHub 바이너리 저장소에는 팩을 커밋하지 않고 검수용 결과물로 분리했다.

## 남은 작업

한국형 학교·주거·회사·대중교통, 고품질 장르 배경, 편집 가능한 장면·말풍선·효과음·브러시·포즈·표지 템플릿의 확보·제작과 동일 작화 검수가 남아 있다. 이번 파일럿 2개 공급원만으로 최종 다양성 기준을 충족하지 않는다.

실제 스튜디오 삽입·저장·재열기·실행취소·내보내기, 전문 검수와 라이선스 승인, 공유 카탈로그 UI/API 연결, main 병합과 운영 배포는 완료하지 않았다. 수집기·정규화 코드·검수 증빙 검사기를 완성한 것과 고품질 라이브러리 전체를 완성한 것은 구분한다.

# ToonSpectrum Studio ↔ CLIP STUDIO PAINT EX 기능 벤치마크

기준일: 2026-07-22
비교 원칙: 제품의 명칭·UI·에셋을 복제하지 않고, 공식 사용자 가이드에 공개된 일반적인 작업 개념을 ToonSpectrum의 웹툰 제작 흐름에 맞게 독자 구현한다.

## 판정 기준

- **구현**: 실제 문서 상태에 저장되고 되돌리기·내보내기·모바일 경계까지 연결됨
- **부분 구현**: 핵심 작업은 가능하지만 CLIP STUDIO EX의 문서 모델이나 세부 조작 중 일부가 없음
- **진행 중**: 독립 엔진과 UI를 구현·검증 중
- **의도적 제외**: 독점 형식·서버 비용·브라우저 보안 경계 때문에 직접 호환하지 않음

## 범용 3D 모델 모드의 제품 경계

VRM은 휴머노이드 본·표정 규약이 있는 아바타에 적합하지만, 비인간형 캐릭터·갑옷·기계·괴물·스캔 모델·복잡한 소품에는 맞지 않는다. ToonSpectrum은 다음처럼 모드를 분리한다.

1. **VRM 포저**: 표정 셰이프, 휴머노이드 IK, 시선·손·얼굴 중심
2. **범용 3D 모델**: OBJ/MTL·GLB/glTF, static/skinned/rigged 능력 감지, 루트·본 프록시 변형, 표면 스냅
3. **3D 배경**: 건물·실내·소품 배치, 카메라·조명·물리·LT 변환 중심

일반 OBJ는 본·애니메이션을 담지 않으므로 “OBJ를 가져오면 자동으로 관절 포즈 가능”하다고 표시하지 않는다. 스켈레톤이 있는 GLB/glTF는 감지된 능력만 활성화하고, 정적 OBJ에는 루트/파츠 변형과 포즈 프록시만 제공한다.

## 의도적으로 직접 구현하지 않는 항목

- `.clip`, `.cmc`, `.cs3c`, `.cs3o`, `.cs3s` 등 타사 독점 형식의 비공식 파싱
- 타사 에셋, 브러시 데이터, 아이콘, 화면 구성의 복제
- 브라우저에서 안전하게 검증할 수 없는 네이티브 플러그인 실행
- 사용 가치에 비해 상시 서버 비용이 큰 기능의 서버 강제 의존

대신 PSD/SVG/PNG/WebP/PDF/OBJ/MTL/GLB/glTF/VRM 같은 공개·상호운용 형식과 로컬 Worker/WebGL/WebGPU 경계를 우선한다.

# Studio 삽입 허브 직접 드래그 고도화 벤치마크

- 기준일: 2026-09-09
- 연관 작업: PR #975 통합 삽입 허브, PR #1039/#1043 다중 이미지 프리플라이트

## 문제 정의

통합 삽입 허브는 텍스트, 말풍선, 이미지, 요소, 장면, 3D, 내 에셋을 한곳에서 검색하고 최근 사용·즐겨찾기·배치 모드를 제공한다. 다중 이미지 프리플라이트도 파일 선택, 드롭, 붙여넣기, 안전 검사, 배치 미리보기를 제공한다.

남은 반복 작업은 검색 결과를 클릭해 중앙 또는 선택 영역에 넣은 뒤 다시 원하는 위치로 이동하는 흐름이다. 개별 요소 패널에는 직접 드래그가 있지만 통합 삽입 허브 결과에서는 같은 직접 조작이 제공되지 않았다.

## 벤치마크 요약

| 서비스 | 관찰한 삽입 패턴 | ToonStudio 적용 판단 |
| --- | --- | --- |
| Figma | Place 대기열, 캔버스·프레임 위치 지정, 취소 가능한 배치 | 기존 다중 프리플라이트를 유지하고 단일 카드의 정확한 위치 드롭을 보완한다. |
| Canva | 사이드 패널 에셋을 캔버스·프레임으로 직접 드래그 | 일반 캔버스 삽입만 우선 연결한다. 프레임 Fill 교체는 별도 비파괴 계약으로 분리한다. |

## 구현 범위

직접 드래그 대상은 기존 캔버스 drop consumer가 이미 안전하게 처리할 수 있는 항목으로 제한한다.

- 텍스트: 기존 `application/json-insert`의 `text` payload
- 기본 말풍선: 기존 `application/json-insert`의 `bubble/speech` payload
- 내 에셋 이미지: 기존 data URL·크기·픽셀 예산 parser 검증
- 벡터 요소: SVG를 data URL로 변환한 뒤 동일 parser로 재검증
- 3D 오브젝트: 기존 카탈로그 ID와 배치 계획, 전용 3D MIME 재사용

다음 항목은 직접 드래그하지 않는다.

- 배경·장면·페이지 템플릿: 페이지 구조와 미리보기·교체 범위가 필요함
- 스톡·커뮤니티·AI 결과: 권리·출처·다운로드·생성 provenance 확인이 필요함
- 콜라주·효과·이메레스·클립: 전용 편집 표면에서 옵션 확정이 필요함
- 기기 업로드: 기존 단일/다중 파일 안전 가져오기 흐름을 유지함

## 안전성과 성능

- 새 drag MIME이나 별도 문서 mutation 경로를 만들지 않는다.
- 렌더 단계에서는 source kind, data URL 접두어, 유한한 크기, 명백히 위험한 SVG 패턴만 검사한다.
- 실제 `dragstart`에서 SVG 변환, 직렬화, 기존 parser 검증, 3D 배치 계획을 수행한다.
- 외부 URL, 위험 SVG, 비정상 크기, 픽셀 예산 초과, 카탈로그에 없는 3D ID는 fail-closed 처리한다.
- 실제 문서 변경은 캔버스의 기존 drop consumer가 수행하므로 mutation ticket, 페이지 고정, 검토 잠금, Undo/Redo 경계를 우회하지 않는다.
- dragstart만으로 최근 사용을 기록하지 않는다. 클릭 삽입의 기존 성공 판정과 MRU 계약을 유지한다.

## 접근성

- 클릭 삽입 버튼을 유지해 키보드와 터치 경로를 보존한다.
- 드래그 가능한 버튼에만 `draggable`, 제목과 스크린리더 도움말 연결을 노출한다.
- 검토 잠금 상태에서는 직접 드래그 속성과 도움말을 제거한다.
- payload 준비 실패 시 브라우저 기본 드래그를 취소한다.

## 테스트 계약

- 텍스트·말풍선·로컬 이미지·벡터·3D만 직접 드래그 대상으로 판정
- 기존 insert/asset/object MIME writer와 parser 재사용
- 외부 이미지 URL·위험 SVG·잘못된 캔버스 기하 거절
- dragstart 시 기존 클릭 handler 미호출
- 검토 잠금 시 `draggable`, 데이터 속성, 도움말 연결 제거
- 기존 lazy boundary를 유지해 초기 Studio 번들에 무거운 카탈로그를 추가하지 않음

## 후속 우선순위

1. 선택 프레임 drop 시 `새 삽입 / Fill 교체 / 마스크 안에 넣기` 프리플라이트
2. 레이어 패널 drop을 통한 정확한 z-order 지정
3. 컷·페이지 썸네일 drop과 대상 페이지 고정
4. 삽입 전 비파괴 crop·focal point·mask 편집
5. 팀 즐겨찾기·프로젝트 트레이 동기화
6. 시각 유사 검색과 라이선스·provenance 기반 추천

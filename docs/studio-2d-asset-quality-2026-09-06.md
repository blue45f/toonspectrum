# 2D 장면 에셋 품질 정비 — 2026-09-06

## 범위와 수량

이번 변경은 기존 배경 원본 29개의 검수·파일 형식 정비와 스튜디오 장면 선택 UI 개선이다. **신규 생성 원본은 0개**다. 앞선 홍보용 콜라주 3장은 개별 삽입 소재로 등록하지 않았으며, 잘라내기·업스케일·확장자 별칭을 신규 원본 수로 계산하지 않는다.

실제 파일 바이트를 조사한 결과:

| 구분 | 수량 |
| --- | ---: |
| 기존 독립 래스터 배경 | 29 |
| 큰 원본: 짧은 변 900px 이상, 긴 변 1024px 이상 | 9 |
| 627×940px 소형 원본 | 20 |
| 원본 확대 검수 후 시각적 추천 | 5 |

총 원본 용량은 17,559,263바이트다. 25개 JPEG에는 기존 바이트와 동일한 `.jpg` 경로를 추가했다. 이전 `.png` 주소는 삭제하지 않아 저장된 작업물의 이미지 참조를 유지한다. 별칭은 원본 수에 포함하지 않는다.

## 추천과 권리 검토는 별개

`studio-2d-asset-manifest.json`은 원본 크기, 매직 바이트로 확인한 MIME, 파일 크기, SHA-256, 구도·시간·인물·문자 태그, 검수 방식과 주의사항을 기록한다. 다섯 추천 장면(창작자 방, 달빛 숲길, 네온 골목, 왕실, 노을 옥상)은 전체 이미지를 확대하여 확인했다. 큰 원본 9개 모두 전체 이미지를 추가 확인했지만, 교실·카페·거리의 문자·인물·상표 등 주의사항이 있어 추천 수를 늘리지 않았다. 나머지 소형 원본은 전체 목록 미리보기 수준 검수이며 작은 원본을 고해상도 추천으로 올리지 않는다. 매니페스트의 검수 방식 기록은 최초 검수 기준이므로 후속 추가 검수 범위를 부풀리지 않는다.

기존 파일의 생성자·생성 작업·원본 이용 약관 증거가 저장소에 확보되어 있지 않으므로 `licenseStatus: unverified`를 유지한다. 기존 `(AI)` 표시는 `aiLabelInCatalog`로만 보존한다. 시각적 추천은 상업 이용 또는 원본 재배포 승인이 아니다.

경쟁사 벤치마킹은 소재 분류·검색·미리보기 UX 수준으로만 적용했다. 다음 공식 약관을 참고하되 경쟁사 파일을 수집하거나 재배포하지 않았다.

- CLIP STUDIO ASSETS terms: https://assets.clip-studio.com/en-us/information/terms/detail
- ACON EULA: https://www.acon3d.com/policy/eula

원본 도입 시에는 개별 출처, 생성/제작 기록, 이용 및 재배포 조건을 확보한 후 별도로 승인해야 한다. 구매·유료 생성 API 호출은 추가하지 않았다.

## UI와 삽입 동작

장르와 소재 품질 구분을 분리했다. 실제 추천/큰 원본/이미지/벡터, 가로/세로/정사각형, 인물 없는 배경, 원본 크기 정렬과 다중 키워드 검색을 조합한다. 기존 세션의 `추천` 장르 선택은 새 분류에서 빈 목록을 만들지 않는다.

기존 래스터 29개와 벡터 35개를 합한 실제 64개 장면 카탈로그를 사용한다. 한 번에 48개를 표시하며 더 보기를 눌러 나머지 장면을 탐색한다. 필터 변경 시 목록 스크롤과 표시 수를 초기화한다.

섬네일은 원본 비율을 보존한다. 클릭 시 미리보기만 열고, 명시적 삽입 버튼이 기존 `addBgScene`으로 원래 장면을 전달한다. 브라우저가 이미지를 디코딩하기 전, 로딩 실패, 검수된 크기 불일치, 마스터/삽입 작업 중에는 삽입을 차단한다. 모달은 원본 픽셀 보기, 오류 재시도, Tab 포커스 제한, Escape 닫기 및 실행 버튼 포커스 복원을 제공한다.

프레임이 없는 캔버스에 삽입할 때도 카탈로그의 실제 원본 크기를 전달한다. 가로 원본까지 720×1080으로 계산하던 문제를 수정했으며, 기존 벡터·크기 정보가 없는 구형 소재는 이전 크기 규칙을 유지한다.

배경 채우기·톤·3D 편집 및 기존 프로젝트 저장 형식은 변경하지 않았다. 새로운 UI 모듈은 2D 장면 메뉴에서 지연 로딩한다.

## 검증 방법과 한계

- `node scripts/studio-2d-asset-audit.mjs`: 원본·별칭·해상도·MIME·체크섬·경로·중복·검수/권리 메타데이터 검증.
- `node --test scripts/studio-2d-asset-quality.test.mjs`: 정상/오염/누락/경로 탈출/거짓 품질 승격 회귀 검사.
- Vitest: 순수 필터·카탈로그 및 실제 React 컴포넌트 회귀 검사.
- `node scripts/studio-2d-browser-smoke.mjs`: 실제 Chromium에서 기존 디자인 토큰과 원본 이미지를 사용한 데스크톱/모바일 컴포넌트 검증, 스크린샷과 JSON 증거 기록.
- 기본 CI의 lint/typecheck/build/전체 회귀 게이트는 변경하거나 우회하지 않는다.

CI 성공 여부는 해당 커밋의 실행 결과를 기준으로 판단한다. 컴포넌트 브라우저 검사는 전체 편집기·프로덕션 배포 검증의 대체가 아니다. 미확인 라이선스, 작은 원본 20개, 장면 내 인물·문자 형태, 신규 원본 대량 생성은 남은 과제다.

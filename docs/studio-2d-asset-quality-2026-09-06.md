# 2D 장면 에셋 품질 정비 — 2026-09-06

## 범위와 수량

이번 변경은 기존 배경 원본 29개의 검수·파일 형식 정비와 스튜디오 장면 선택 UI 개선이다. **신규 생성 원본은 0개**다. 앞선 홍보용 콜라주 3장은 개별 삽입 소재로 등록하지 않았으며, 잘라내기·업스케일·확장자 별칭을 신규 원본 수로 계산하지 않는다.

| 구분 | 수량 |

| 기존 독립 래스터 배경 | 29 |

총 원본 용량은 17,559,263바이트다. 25개 JPEG에는 기존 바이트와 동일한 `.jpg` 경로를 추가했다. 이전 `.png` 주소는 삭제하지 않아 저장된 작업물의 이미지 참조를 유지한다. 별칭은 원본 수에 포함하지 않는다.

## 실제 이미지 검수와 이용 권리

29개 원본 모두 전체 이미지를 원본 크기로 확인했다. 큰 원본 9개는 개별 확대 검수, 소형 원본 20개는 리사이즈하지 않은 627×940px 이미지 두 장씩을 나란히 놓고 확인했다. 다섯 추천 장면은 창작자 방, 달빛 숲길, 네온 골목, 왕실, 노을 옥상이다. 추천 수량을 늘리기 위해 작은 원본을 승격하거나 인물·간판·가구 형태의 주의사항을 숨기지 않았다.

`studio-2d-asset-manifest.json`은 원본 크기, 실제 MIME, 파일 크기, SHA-256, 장소·시간·인물·문자 태그, 검수 방식과 주의사항을 기록한다. 침실 벽 포스터와 연구실의 인물형 홀로그램도 인물 포함으로 구분한다. 병원 안내문, 작은 문자형 표식, 화면 글자 등은 문자 없는 원본으로 표시하지 않는다. 이는 시각적 관찰이며 이미지 속 글자의 정확성이나 작은 형태의 완전성을 보증하지 않는다.

기존 파일의 생성자·생성 작업·원본 이용 약관 증거가 저장소에 확보되어 있지 않으므로 `licenseStatus: unverified`를 유지한다. 기존 `(AI)` 표시는 `aiLabelInCatalog`로만 보존한다. 시각적 추천은 상업 이용 또는 원본 재배포 승인이 아니다. 경쟁사 소재를 구매·복제·스크래핑하거나 원본의 표식을 지우지 않았다.

벤치마킹은 소재 분류·검색·미리보기 UX 수준이며, 다음 공식 약관의 상업 작품 이용과 소재 자체 재배포 구분을 참고했다.

- CLIP STUDIO ASSETS: https://assets.clip-studio.com/en-us/information/terms/detail
- ACON EULA: https://www.acon3d.com/policy/eula

신규 원본 도입은 개별 출처, 생성/제작 기록, 이용 및 재배포 조건을 확보한 후 별도로 승인해야 한다. 구매·유료 생성 API 호출은 추가하지 않았다.

## UI와 삽입 동작

기존 래스터 29개와 벡터 35개를 합한 실제 64개 장면 카탈로그를 사용한다. 한 번에 48개를 표시하며 더 보기로 나머지를 탐색한다. 필터 변경 시 목록 스크롤과 표시 수를 초기화한다.

장르와 소재 품질을 분리했다. 추천/큰 원본/이미지/벡터, 가로/세로/정사각형, 인물 없는 배경, 원본 크기 정렬과 다중 키워드 검색을 조합한다. 기존 세션의 `추천` 장르 선택 때문에 빈 목록이 나타나지 않는다.

섬네일은 원본 비율을 보존한다. 미리보기 버튼은 이미지를 확인하는 동작이고, 명시적 삽입 버튼은 기존 `addBgScene` 경로로 원래 장면을 전달한다. 이미지 디코딩 전, 로딩 실패, 검수 크기 불일치, 마스터/삽입 작업 중에는 삽입을 차단한다. 모달은 원본 픽셀 보기와 키보드 스크롤, 오류 재시도, Tab 포커스 제한, Escape 닫기 및 실행 버튼 포커스 복원을 제공한다.

프레임이 없는 캔버스에도 실제 원본 크기를 전달한다. 가로 이미지까지 720×1080으로 계산하던 문제를 수정했으며, 검증 사례의 1672×941px 옥상 배경은 720px 폭에서 720×405px로 배치된다. 기존 벡터와 크기 정보가 없는 구형 소재는 이전 크기 규칙을 유지한다. 공통 배치 함수를 분리하여 편집기 호스트 크기 제한을 늘리지 않았다.

배경 채우기·톤·3D 편집 및 기존 프로젝트 저장 형식은 변경하지 않았다. 새로운 UI 모듈은 2D 장면 메뉴에서 지연 로딩한다.

## 검증과 한계

- `node scripts/studio-2d-asset-audit.mjs`: 원본·별칭·해상도·MIME·체크섬·경로·중복·검수/권리 메타데이터 검증.
- `node --test scripts/studio-2d-asset-quality.test.mjs`: 정상/오염/누락/경로 탈출/거짓 품질 승격 회귀 검사.
- Vitest: 필터·64개 카탈로그·페이지네이션·실제 React 컴포넌트·원본 비율 배치·콘텐츠 분류·호스트 구조 회귀 검사.
- `node scripts/studio-2d-browser-smoke.mjs`: 실제 Chromium과 원본 이미지로 데스크톱 1280×960 및 모바일 390×844 컴포넌트 검사, 스크린샷 및 JSON 증거 기록.
- 기존 CI의 lint/typecheck/build/전체 회귀 게이트는 변경하거나 우회하지 않는다.

최종 트리에는 임시 전송 파일과 쓰기 권한을 가진 준비 워크플로를 남기지 않는다. 유지되는 품질 워크플로는 저장소 읽기 권한만 사용하며 파이프 중간의 테스트 실패도 실패로 처리한다.

성공 여부는 해당 커밋의 실제 실행 로그와 결과 JSON을 기준으로 판단한다. 컴포넌트 브라우저 검사는 전체 편집기·프로덕션 배포 검증을 대체하지 않는다. 미확인 라이선스, 작은 원본 20개, 신규 원본 대량 생성은 남은 과제다.

# Studio 3D Production Workflow UX Wave — 2026-09-05

## 목표

3D 도구 수를 더 늘리는 대신 이미 존재하는 장면 편집, 캐릭터/포즈, 카메라 컷, LT 룩,
멀티패스, PSD/ZIP, AI 참조 기능을 하나의 실제 제작 흐름으로 연결한다.

핵심 작업 순서는 다음과 같다.

1. 장면 구성
2. 캐릭터·포즈 확인
3. 카메라·컷 저장 및 연속성 검수
4. 룩·선화 확인
5. 복구 가능한 멀티패스 출력과 2D 전달

## 제품 벤치마크에서 반영한 원칙

- Clip Studio Paint: 포즈 스캐너, 손 포즈 조작, 포즈 재사용처럼 캐릭터 작업을 현재 선택과
  소재 흐름 안에서 이어 주는 방식을 참고한다.
- Blender: 카메라 뷰, Safe Area, Pose Library처럼 샷 준비 상태와 재사용 자산을 명시적으로
  드러내는 방식을 참고한다.
- Spline: 카메라 전환의 지연, 애니메이션 여부, 곡선, 지속 시간을 한 작업 단위로 다루는
  방식을 참고한다.
- MediaPipe Tasks Vision: 이미지·비디오·라이브 스트림 입력을 분리하고 결과를 사용자가
  확인한 뒤 적용하는 로컬 포즈/손 참조 흐름을 다음 런타임 게이트로 유지한다.

## 이번 웨이브에서 실제 연결한 범위

### 1. canonical SceneDocument 기반 장면 요약

`studio-bg3d-production-workflow.ts`가 다음 정보를 런타임 객체나 바이너리 없이 계산한다.

- 전체/표시/잠금/선택 노드 수
- 프리미티브/모델/첨부 에셋 수
- 포즈·애니메이션·제약이 적용된 모델 수
- 활성 컷
- 선화 출력, 선화 미리보기, 톤, 투명 배경 상태

### 2. 결정론적 제작 단계 플래너

각 단계를 `ready`, `attention`, `blocked`, `working`, `optional` 중 하나로 분류한다.
다음 행동은 항상 같은 우선순위를 따른다.

1. 빈 장면 해소
2. 첫 컷 저장
3. 출력 컷 선택
4. 검증된 원고 패스 선택
5. 선화 미리보기 점검
6. 복구 가능한 실제 배치 출력

준비도 수치는 미완료 단계를 숨기지 않으며, 렌더러가 증명하지 않은 패스를 완료로 표시하지
않는다.

### 3. 컷 디렉터 제작 허브

컷 디렉터 상단에 실제 장면과 연결된 제작 허브를 추가했다.

- 5단계 상태와 현재 막힘을 한 화면에서 확인
- 다음 행동 CTA
- 현재 컷 저장
- 전체 컷 선택
- 원고용 멀티패스 선택
- 현재 컷 AI 참조 준비
- 선화 미리보기와 투명 배경 직접 전환
- 배치 진행률과 복구 요약 유지

모든 버튼은 기존 `StudioBg3dViewPanel` 명령을 사용하므로 별도 상태 저장소, 우회 캡처,
우회 AI 호출을 만들지 않는다.

### 4. 멀티패스 화면의 상류 준비도

프로덕션 멀티패스 화면에도 접힌 제작 허브를 배치했다. 출력 준비가 끝났을 때는 기존 상세
패널의 시작 버튼을 중복하지 않고, 준비가 덜 되었을 때만 상류 문제를 해결하는 행동을
제공한다.

### 5. 잠금·접근성·반응형

- 캡처, 장면 복원, 물리 배치, 배치 렌더 중에는 동일한 canonical lock을 상속한다.
- 단계 목록은 순서가 있는 목록과 `aria-current=step`을 사용한다.
- 펼침/접힘, 진행 상태, 오류, 비동기 busy 상태를 스크린리더에 전달한다.
- 주요 버튼은 최소 40px 높이를 유지하고 좁은 패널에서는 단계가 세로로 재배치된다.
- reduced-motion 환경에서는 기존 카메라 전환과 새 진행 UI 모두 불필요한 모션을 줄인다.

## 검증

- 순수 플래너 단위 테스트
  - 빈 장면 차단
  - 첫 컷 저장 우선순위
  - 컷 선택 → 원고 패스 선택 순서
  - 선화 점검
  - 출력 준비/진행 잠금
- UI 런타임 테스트
  - canonical 컷 선택
  - 검증된 5개 원고 패스 적용
  - 복구 가능한 export 시작
  - 선화/투명 배경/AI 참조 명령 전달
  - 멀티패스 화면의 중복 시작 버튼 방지

## 의도적으로 완료 처리하지 않은 런타임 게이트

다음 항목은 UI 문구만 추가하지 않고 실제 렌더·모델 검증과 함께 진행한다.

1. normal/object ID/material ID/shadow/AO/emission/velocity의 브라우저 golden capture,
   복구 저장, PNG/PSD, manifest 증명
2. Safe Frame, 전환, Hold, 썸네일을 영속 SceneDocument 컷 메타데이터로 승격
3. BVH/VRMA retarget 시각 검수와 additive bone-mask
4. 로컬 MediaPipe 손·전신 스캐너의 preview → freeze → correction → confirm 흐름

이 네 게이트가 통과하기 전에는 제작 허브가 해당 기능을 준비 완료로 표시하지 않는다.

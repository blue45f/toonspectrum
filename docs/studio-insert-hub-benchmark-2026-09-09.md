# ToonStudio 삽입 허브 벤치마크 및 구현 기록

- 기준일: 2026-09-09
- 대상: `https://www.toonstudio.cloud/studio`
- 구현 브랜치: `feat/studio-insert-hub-20260909`
- 범위: 텍스트, 말풍선, 이미지, 스톡, 템플릿, 콜라주, 장면, 요소, 효과, 클립, 이메레스, 3D, AI, 내 에셋의 탐색과 삽입 진입점

## 1. 문제 정의

기존 ToonStudio에는 삽입 가능한 콘텐츠와 편집 도구가 이미 풍부하다. 그러나 기능이 템플릿, 콜라주, 요소, 장면, 효과, 내 에셋, 스톡, AI, 3D 패널로 분산돼 있어 사용자는 다음 비용을 반복해서 부담했다.

1. 어떤 메뉴가 원하는 결과를 소유하는지 기억해야 한다.
2. 텍스트·말풍선 같은 작업과 에셋 탐색이 서로 다른 진입점에 있다.
3. 반복 사용한 항목을 다시 찾기 위한 최근 사용 흐름이 없다.
4. 자주 쓰는 항목을 사용자 수준에서 고정할 수 없다.
5. 내 에셋 이미지는 현재 페이지 또는 선택 레이어에 맞춰 넣기 전에 추가 변형이 필요하다.
6. 검색 결과가 없을 때 생성 도구로 자연스럽게 이어지는 흐름이 약하다.

이번 변경의 목표는 새로운 저장·렌더링 시스템을 만드는 것이 아니라, 기존의 검증된 삽입 소유권과 Undo/저장 경로를 유지한 채 발견성과 반복 작업 효율을 크게 높이는 것이다.

## 2. 벤치마크

### 2.1 Figma Design

공식 문서:

- Actions 메뉴: https://help.figma.com/hc/en-us/articles/23570416033943-Use-the-actions-menu-in-Figma-Design
- 이미지·비디오 일괄 배치: https://help.figma.com/hc/en-us/articles/360041089973-Add-images-and-videos-in-bulk

확인한 패턴:

- Actions가 AI, 일반 동작, 에셋 검색, 플러그인·위젯의 공통 검색 진입점 역할을 한다.
- 이름뿐 아니라 설명 기반으로 에셋을 찾는 흐름을 제공한다.
- Place image/video는 여러 파일을 선택한 뒤 캔버스 위치 또는 기존 오브젝트를 대상으로 배치한다.
- 검색과 실행이 분리된 설정 화면이 아니라 작업 문맥 안에서 바로 이어진다.

ToonStudio 적용:

- 흩어진 삽입 동작과 에셋을 하나의 검색 결과로 합쳤다.
- `/` 키로 허브 내부 검색에 즉시 포커스한다. 전역 `Cmd/Ctrl+K` 커맨드 팔레트와 충돌하지 않는다.
- 페이지 맞춤과 선택 영역 배치를 내 에셋 이미지에 제공한다.
- 배치가 지원되지 않는 항목에는 배치 기능이 적용되는 것처럼 표시하지 않는다.

### 2.2 Canva

공식 문서:

- Visual Suite: https://www.canva.com/visual-suite/
- 요소 도움말: https://www.canva.com/ko_kr/help/elements/

확인한 패턴:

- 템플릿, 이미지, 그래픽, 오디오, 3D 요소, 앱과 브랜드 에셋을 한 제작 환경 안에서 연결한다.
- 요소는 추가 후에도 이동, 그룹화, 잠금, 별표 표시, 크기·색상 변경이 가능하다.
- 드래그 앤 드롭과 템플릿 기반 시작으로 탐색 후 실행 단계를 짧게 만든다.
- 팀 에셋을 한곳에 모아 재사용하는 흐름을 강조한다.

ToonStudio 적용:

- 텍스트부터 3D·AI·내 에셋까지 같은 허브에서 탐색한다.
- 모든 빠른 동작과 에셋 카드에 즐겨찾기를 제공한다.
- 기존 보관함·마켓을 별도 시스템으로 대체하지 않고 같은 허브의 두 번째 작업 보기로 유지한다.
- 자주 쓰는 6개 동작을 상단 빠른 삽입으로 노출한다.

### 2.3 Adobe Express

공식 문서:

- 이미지 교체 및 Add content > Media: https://helpx.adobe.com/express/web/add-images-and-visuals/images-and-backgrounds/replace-background.html
- 영상 제작에서 미디어·스톡·텍스트·그래픽 추가: https://helpx.adobe.com/express/web/video-creation-and-editing/create-videos/video.html

확인한 패턴:

- 왼쪽 Add content 흐름에서 기기 업로드, Adobe Stock, 텍스트, 그래픽, 아이콘을 일관되게 추가한다.
- 기존 오브젝트를 선택한 상태에서 교체하는 문맥 동작을 제공한다.
- 스톡과 로컬 업로드를 같은 미디어 흐름에서 다룬다.

ToonStudio 적용:

- 기기 이미지와 스톡 이미지를 같은 미디어 범주에 배치했다.
- 검색 결과가 없어도 현재 질의를 AI 배경 생성 도구로 넘길 수 있다.
- 스톡 삽입은 기존 출처·라이선스 보존 경로로 라우팅한다.
- 로컬 파일 입력은 기존 이미지 디코딩·검증 핸들러를 그대로 사용한다.

### 2.4 CLIP STUDIO PAINT

공식 문서:

- 소재 불러오기: https://help.clip-studio.com/en-us/manual_en/630_material/How_to_load_materials.htm
- 3D 파일 가져오기: https://help.clip-studio.com/en-us/manual_en/660_3d/Importing_3D_Files.htm

확인한 패턴:

- 소재 팔레트에서 캔버스에 붙여넣거나 드래그 앤 드롭한다.
- 3D 오브젝트, 인체 모델, 머리 모델, 프리미티브와 파노라마를 공통 소재 체계에서 다룬다.
- 포즈 소재는 선택된 3D 모델에 적용하거나 새 모델로 삽입한다.
- 선택 영역 또는 프레임 테두리를 기준으로 3D 레이어를 만들 수 있다.

ToonStudio 적용:

- 2D와 3D를 분리된 제품처럼 보이지 않게 통합 검색 결과에 포함한다.
- 3D 빠른 동작은 기존 편집 가능한 3D 장면 편집기를 연다.
- 선택 레이어 경계를 내 에셋 이미지 배치 대상으로 사용할 수 있다.
- 실제 3D 오브젝트 카드는 기존 VRM/3D 전용 삽입 표면으로 라우팅한다.

공식 문서:

- 템플릿 가져오기: https://docs.toonboom.com/help/storyboard-pro-24/storyboard/library/import-template.html
- 이미지 라이브러리 가져오기: https://docs.toonboom.com/help/storyboard-pro-25/storyboard/library/import-image.html

확인한 패턴:

- 라이브러리 템플릿을 Stage, Camera, Layer, Thumbnail, Timeline의 목표 위치에 드롭할 수 있다.
- 한 번 가져온 이미지와 3D 모델을 프로젝트 라이브러리에서 반복 사용한다.
- 패널 템플릿을 장면 사이 또는 현재 패널의 특정 레이어 위치에 삽입한다.

ToonStudio 적용:

- 저장된 클립과 내 에셋을 반복 삽입의 일급 경로로 노출한다.
- 장면 템플릿은 즉시 확정했다고 오인시키지 않고 기존 미리보기·배치 표면을 연다.
- 현재 선택을 배치 목표로 사용할 수 있는 기반을 마련했다.
- 직접 캔버스 드롭과 다중 이미지 커서 배치는 후속 단계로 분리했다.

## 3. 벤치마크 결론

경쟁 제품의 공통 강점은 단순히 삽입 가능한 종류가 많다는 점이 아니다.

1. **단일 발견 표면**: 도구, 에셋, AI, 확장 기능을 검색 가능한 한곳에 모은다.
2. **작업 문맥 유지**: 현재 선택, 패널, 레이어, 타임라인 같은 목표를 보존한다.
3. **반복 사용 최적화**: 라이브러리, 컴포넌트, My List, 즐겨찾기, 최근 사용으로 재탐색을 줄인다.
4. **미리보기와 배치 제어**: 즉시 삽입, 선택 대상 적용, 크기 맞춤, 드래그 배치를 구분한다.
5. **실행 소유권 유지**: 통합 UI가 각 미디어의 실제 편집·저장·권한 경로를 우회하지 않는다.

이번 변경은 이 다섯 원칙 중 검색, 문맥 배치, 반복 사용, 실행 소유권을 우선 구현했다.

## 4. 구현 범위

### 4.1 통합 삽입 인덱스

추가한 빠른 동작:

- 텍스트
- 말풍선
- 기기 이미지
- 스톡 이미지
- 페이지 템플릿
- 이미지 콜라주
- 도형·장식 요소
- 장면 템플릿
- 저장된 클립
- 만화 효과·스티커
- 이메레스·밑그림
- 3D 배경·오브젝트
- AI 이미지·장면 만들기

기존 통합 에셋 카탈로그의 2D 배경, 장면 템플릿, 벡터 요소, 3D 오브젝트, 내 에셋, 네이티브 도구는 그대로 포함한다.

### 4.2 검색

- 한국어·영어 키워드와 제작 현장에서 쓰는 동의어를 정규화한다.
- 공백으로 나뉜 여러 검색어는 AND 조건으로 처리한다.
- 제목 일치, 제목 접두어, 키워드, 설명 순으로 점수를 부여한다.
- 즐겨찾기와 최근 사용 항목은 같은 검색 관련도 안에서 적절히 상승한다.
- 검색어는 120자로 제한하고 결과는 최대 160개로 제한한다.

### 4.3 즐겨찾기와 최근 사용

- 모든 빠른 동작과 에셋에 즐겨찾기를 제공한다.
- 최근 사용은 실제 라우팅이 성공한 뒤에만 기록한다.
- 최근 목록은 MRU 순서이며 최대 24개다.
- 즐겨찾기는 최대 160개다.
- 저장 데이터는 버전, 길이, 중복, 제어 문자를 검증한다.
- localStorage 접근 거부 또는 quota 오류가 편집을 막지 않는다.
- 현재 카탈로그에서 사라진 ID는 자동으로 정리한다.

### 4.4 문맥 배치

내 에셋 이미지에 세 가지 모드를 제공한다.

- 자동: 기존 중앙 삽입과 반복 삽입 오프셋 규칙을 유지한다.
- 페이지 맞춤: 페이지 경계 안에 비율을 유지해 맞춘다.
- 선택 영역: 현재 선택 레이어의 축 정렬 경계 안에 비율을 유지해 맞춘다.

배치 좌표를 새로 계산하지 않고 기존 `createCanvasImageElement`의 경계·인셋·비율 유지 규칙을 사용한다. 최종 삽입은 기존 `addRenderedImage`에 좌표·크기 패치를 전달하므로 저장, Undo, 이미지 검증 경로를 우회하지 않는다.

### 4.5 진입점

- 기존 템플릿·에셋 하위 메뉴의 첫 탭을 삽입 허브로 재정렬했다.
- 툴벨트의 삽입·대사 묶음에 직접 `삽입` 버튼을 추가했다.
- 기존 텍스트, 말풍선, 이미지 빠른 버튼은 유지해 숙련 사용자의 근육 기억을 깨지 않는다.

### 4.6 접근성

- 모든 주요 버튼은 최소 40~44px 상호작용 높이를 유지한다.
- 검색, 컬렉션, 종류, 배치 모드에 명시적 레이블과 `aria-pressed`를 제공한다.
- 즐겨찾기 상태를 보조 기술에 알린다.
- 성공과 실패를 `aria-live` 상태 영역으로 전달한다.
- 선택이 없을 때 선택 영역 배치를 비활성화하고 이유를 문장으로 설명한다.
- `/` 단축키는 텍스트 입력 중에는 가로채지 않는다.

## 5. 아키텍처 원칙

### 5.1 통합은 라우팅 계층에서만 수행

삽입 허브는 새로운 에셋 저장소나 캔버스 객체 모델을 만들지 않는다. 항목 종류별로 기존 소유자에게 라우팅한다.

- 배경 → `addBgScene`
- 벡터 요소 → `addCatalogElement`
- 로컬 이미지 → `addRenderedImage`
- 3D 오브젝트 → `openStudioObjectInsert`
- 장면 → 기존 장면 미리보기·배치 표면
- 스톡 → 기존 스톡 검색 표면
- AI → 기존 AI 제작 보조 표면
- 말풍선·텍스트 → 기존 네이티브 편집기

### 5.2 권리와 출처 메타데이터 보존

통합 검색 결과가 보이는 방식만 바꾸며 스톡, 커뮤니티, AI, 번들 에셋의 권리·출처 메타데이터를 제거하거나 재작성하지 않는다. 권리 확인이 필요한 항목은 카드에서 경고를 유지한다.

### 5.3 점진적 확장

검색·선호도·배치 계산을 순수 모델로 분리했다. 향후 캔버스 드래그, 다중 이미지 배치, 팀별 라이브러리, 서버 동기화가 추가돼도 현재 라우팅 계약을 재사용할 수 있다.

## 6. 검증 계획

- 빠른 동작과 기존 카탈로그 결합

- 한국어·영어 동의어 검색
- 범주와 컬렉션의 독립 필터링
- 즐겨찾기·최근 사용 순위

## 7. 의도적으로 제외한 후속 과제

다음 항목은 이번 MR에 포함하지 않았다. 기존 캔버스 제스처·Undo·다중 페이지 계약과 함께 별도 수직 기능으로 구현해야 한다.

1. 여러 이미지를 선택한 뒤 커서로 순차 배치하는 Figma식 일괄 Place 모드
2. 에셋 카드를 캔버스·레이어·컷 썸네일에 직접 드롭하는 목표 인식
3. 선택한 프레임의 마스크 또는 이미지 Fill로 교체하는 문맥 동작
4. 다중 선택 레이어에 항목을 반복 적용하는 배치 삽입
5. 팀 계정 간 즐겨찾기·최근 사용 동기화
6. 이미지·선택 영역 기반 시각 유사 검색
7. 삽입 전에 회전·크롭·마스크·블렌드 모드를 미리 조정하는 프리플라이트
8. 장면 템플릿의 레이어별 선택 삽입과 충돌 미리보기

## 8. 성공 지표 제안

배포 후 다음 이벤트를 계측하면 삽입 허브의 실효성을 검증할 수 있다.

- 허브 열기 → 첫 삽입까지 걸린 시간
- 검색 없이 빠른 삽입으로 완료한 비율
- 검색 무결과율
- 즐겨찾기 사용률과 재사용 간격
- 최근 사용을 통한 삽입 비율
- 페이지 맞춤·선택 영역 배치 사용률
- 삽입 직후 크기·위치 수정 횟수
- 기존 개별 메뉴 대비 허브 경유 삽입 성공률

계측을 추가할 때 검색어 원문이나 로컬 파일명은 기본 수집 대상에서 제외하고, 항목 범주·동작 ID·결과 코드처럼 비식별 이벤트만 사용해야 한다.

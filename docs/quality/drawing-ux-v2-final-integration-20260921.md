# 드로잉 UX v2 후속 통합 · 2026-09-21

## 범위

PR #1920의 사용자 도구 구성·색상 작업실·모바일 공통 편집기 구현은 메인에 병합되었다.
이 후속 변경은 중단된 로컬 수정과 후속 CI/브라우저 검증에서 발견한 문제를 별도 작업 트리에서 통합한다.
기존 작업 트리의 변경은 삭제하거나 덮어쓰지 않았다. 배포·DB·환경 변수·브랜치 보호는 변경하지 않는다.

## 수정 내용

- 모바일 도크의 실제 높이를 측정하여 브러시 시트와 캔버스 하단 여백에 반영한다. 확장/접힘, 창 크기·가상 뷰포트 변화, 언마운트 정리를 지원한다.
- 브러시 시트의 헤더와 스크롤 본문을 분리한다. 버튼을 스크롤해도 헤더나 도크가 클릭 영역을 덮지 않도록 한다.
- 활성 브러시 시트의 높이도 측정하여 오프라인 준비 안내가 도구 위를 덮지 않도록 한다.
- 넓은 Inspector에서 속성과 레이어를 함께 표시할 때 스크롤을 막지 않고 속성 영역이 0 높이로 축소되지 않도록 한다. 좁은 패널·모바일은 기존 탭 동작을 유지한다.
- 닫힌 고정 색상 패널 때문에 전체 색상 편집기 청크가 먼저 로드되지 않도록, 가벼운 컨텍스트 검사 뒤에 지연 로딩한다.
- 작업 배치 복원/되돌리기를 문서·브러시 기록과 분리된 기존 권위의 작은 모듈로 옮기고 소유자 일치·백업 실패·되돌리기를 검사한다. 호스트 크기와 번들 기준을 늘리지 않는다.
- 베타 안내 모달의 진입 효과에서 투명도를 제거하여 첫 프레임부터 텍스트 대비를 유지한다. 접근성 검사는 모션을 일시 정지한 상태에서도 이를 확인한다.
- 실제 브러시 라이브러리 진입 및 저장 목록/표시 목록의 새 계약에 맞게 기존 회귀 검증을 보완한다. 테스트를 생략하거나 성공으로 위장하지 않는다.
- 제작 복구 시나리오의 되돌리기는 파생 위험 링크만 새로 계산된 경우에도 유지한다. 사용자가 편집한 필드는 안정적인 비교로 잠금을 유지하고, 서버에는 전체 최신 expectedTasks를 보내 비교 후 변경(CAS) 보호를 유지한다.

## 확인한 검증

- 관련 첫 회귀 실행: 24개 파일, 253개 테스트 통과.
- 호스트 경계·실제 메뉴·배치 복원 추가 실행: 4개 파일, 26개 테스트 통과(일부 중복).
- 전체 프론트엔드 및 API 타입 검사 통과.
- Chromium 151과 Firefox 153에서 각 6개 시나리오 묶음, 총 12개 통과. 브라우저 pageerror 0건.
- 브라우저 검증에는 27개 고정 후 실제 SQLite/OPFS 재진입, 모드 변경, 35개 확장 순서, 실행/고정 분리, 색상 확정/취소/대상 변경, 고정 색상 패널, 390×700·360×640 실제 모바일 도크와 브러시 시트가 포함된다.
- 도크 재측정·시트 표시 상태 변경·관찰자 정리에 대한 회귀 테스트를 추가했다. 최종 추가 검사 및 필수 CI 결과는 PR의 정확한 head SHA 기록을 따른다.

## 재현

```sh
pnpm run typecheck
pnpm exec vitest run apps/web/src/domains/creator/useStudioMobileDockMetrics.test.tsx
pnpm exec vitest run apps/web/src/domains/creator/production-hub/ProductionRecoveryScenarioPanel.test.tsx
pnpm exec vite --host 127.0.0.1 --port 5238 --strictPort
# 별도 터미널
node scripts/verify-studio-drawing-ux-v2.mjs http://127.0.0.1:5238 chromium,firefox
```

로컬 작업 트리는 의존성 바이트를 기존 설치와 공유한다. 공유된 SQLite WASM 경로를 Vite가 읽을 수 있도록 로컬 QA 서버에서 해당 node_modules/.pnpm 경로만 추가 허용했다. 이 개발 서버 설정은 저장소나 운영에 반영하지 않는다. 일반 설치 및 CI는 표준 Vite 구성을 사용한다.

실기기 펜/가상 키보드·전체 스크린리더 인증, WebKit의 이전 OPFS 환경 오류, 실제 대형 원고의 성능 P95는 하네스 통과로 보장하지 않는다. 운영 배포는 이번 메인 병합 범위와 별개다.

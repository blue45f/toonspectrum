# PSD 교환 보존 계약 — 2026-09-26

상태: `current` 구현, 브라우저 시각 비교는 `target` 검증.

## 현재 동작

- 가져오기는 원본 해상도 PNG 레이어와 래스터 마스크를 유지한다. 아래 레이어 클리핑을 연결하며, 원본 중첩 폴더 경로를 요소 메타데이터로 보존한다. Studio의 평면 폴더 패널에서는 전체 경로를 표시하고, PSD로 다시 내보내면 원래 중첩 경로를 재구성한다. 편집 중 그룹을 이동하거나 해제하면 오래된 경로를 강제로 복원하지 않는다.
- 적용 전 손실 확인 창에서 개별 레이어 방식과 PSD에 저장된 합성본 방식을 고른다. 합성본은 원본 저장 시점의 조정·효과·그룹 합성을 한 이미지로 보존하며 개별 레이어를 편집할 수 없다. 합성 이미지가 없는 PSD에는 이 선택을 제공하지 않는다.
- 단일 서식·수평·회전/왜곡 없는 RGB 텍스트는 숨겨진 문자 편집본을 함께 만든다. 처음 보이는 결과는 원본 픽셀이며, 편집본을 켜면 글꼴 가용성과 브라우저 줄바꿈 차이를 확인해야 한다. 복잡한 문자·스마트 오브젝트의 완전한 편집 구조는 원본 PSD에 보존한다.
- 적용할 때 원본 PSD 바이트를 기존 OPFS 내용주소 저장소에 보관한다. 문서와 협업 메타데이터에는 SHA-256·이름·바이트 수만 저장한다. 프로젝트 메뉴의 `PSD 원본 받기`로 원본을 다시 내려받을 수 있다.
- 프로젝트 아카이브는 PSD 원본을 `psd-source` attachment로 포함하고 해시·크기·파일 서명·참조를 검증한다. 원본을 찾을 수 없으면 완전한 아카이브 내보내기를 중단한다. 다른 기기에서는 프로젝트 아카이브로 원본을 복구한다. 일반 JSON이나 협업 참조만으로 원본 바이트가 다른 기기에 전달되지는 않는다.
- PSD 내보내기는 활성 레이어 마스크가 적용된 캡처 경계를 사용한다. 마스크의 현재 외관은 픽셀에 합성되며 별도 PSD 마스크 채널은 만들지 않는다. 해당 경계를 찾지 못하면 가려진 픽셀을 드러내는 파일을 만들지 않고 중단한다.
- 준비 상태는 `PSD 준비 완료`로 표시하고, 취소·문서 변경·커밋 실패 시 적용 성공을 표시하지 않는다. 원본 보관 실패도 문서 적용을 중단한다.

## 보존 제한

- 격리 그룹 혼합·그룹 불투명도·그룹 마스크·조정 레이어·Photoshop 레이어 효과의 전용 편집 엔진은 구현하지 않는다. 개별 레이어 방식에서 발생하는 차이를 구체적으로 안내하고 합성본과 원본 PSD를 제공한다.
- 빈 폴더처럼 가져올 픽셀이 없는 구조는 Studio 폴더로 만들지 않고 원본 PSD에 남긴다. Studio의 폴더 UI 자체는 평면 구조이며, 원본 중첩 경로와 폴더 표시를 구분한다.
- 저장된 PSD 합성본은 원본 앱에서 마지막으로 저장한 결과다. 저장하지 않은 변경이나 잘못된 원본 합성 캐시를 추정해 복원하지 않는다.
- 기존 파일 크기·디코딩 메모리·프로젝트 아카이브 한도를 유지한다. 원본 픽셀을 자동 축소하거나 손실 재인코딩하지 않는다.
- 원본 보존 참조는 임의 회수하지 않는다. 따라서 취소된 적용이나 사용자가 레이어를 삭제한 뒤에도 보존한 원본은 기기에 남을 수 있다.

## 검증

관련 단위 검사는 원본 바이트의 CAS 중복 제거와 별도 저장소 복구, 아카이브 원본 누락 거부, 중첩 폴더 순서, 클리핑, 텍스트 편집본, 합성본 선택, 취소·보관 실패, 마스크를 포함한 PSD 픽셀 인코딩/디코딩을 확인한다. API 검사는 허용된 참조 및 원본 바이트 주입·위조 해시·과도한 폴더 깊이 거부를 확인한다.

실행 결과는 최종 작업 보고와 전체 검증 기록에 남긴다. 실제 Photoshop 파일 모음의 화면 대조, 다른 브라우저 기기의 OPFS 복구, 모바일 대형 PSD 메모리 검사는 이 문서만으로 완료를 주장하지 않는다. 운영 배포는 실행하지 않았다.

## 검증 증거

- 관련 로컬 테스트는 실행 로그와 최종 PR에 파일·테스트 수를 기록한다. 정적인 JSX 표현 검사는 명령/잠금 조건을 유지하는 정의 객체 표현에 맞게 옮겼다.
- `scripts/verify-studio-drawing-ux-v2.mjs`는 loopback만 허용한다. Chromium 151 및 Firefox 153에서 각 6개 시나리오 묶음(총 12개), pageerror 0건을 확인했다.
- 브라우저 검증은 실컴포넌트와 실제 SQLite WASM/OPFS 저장소를 사용하는 격리 하네스다. 계정·운영 원고·서버 API·마이그레이션을 변경하지 않는다.
- 27개 저장 후 실제 재진입, 밀도 변경 유지, 35개 추가 순서, 실행/고정 분리, 무효 HEX/취소/한 번 확정, 주·보조 분리, 이력 재로드, 객체 Undo 콜백 1건, 문서 전환 취소, 캔버스 클릭 통과 방지, 도킹, 390×700·360×640 실제 모바일 도크 경로를 검증한다.
- 저장은 Chromium/Firefox에서 `saved`를 필수 조건으로 검사한다. localStorage나 메모리 저장을 영속 성공으로 대체하지 않는다.
- WebKit 26.5 하네스는 SQLite SAH-pool 초기화에서 플랫폼의 일시적 OPFS 오류를 반환했다. UI가 `session-only`를 안내하는 것은 확인했지만 WebKit 영속 재진입 통과로 집계하지 않았다. 이 실패 때문에 다른 저장 권위로 우회하지 않는다.

## 재현

```sh
pnpm exec vite --host 127.0.0.1 --port 5219 --strictPort
node scripts/verify-studio-drawing-ux-v2.mjs http://127.0.0.1:5219 chromium,firefox
```

실행 보고서/스크린샷은 `artifacts/drawing-ux-v2/`에 생성하며 소스로 커밋하지 않는다.
기존 `scripts/studio-drawing-menu-color-ux-browser.mjs`도 같은 검증을 호출하며 기존 기본 포트 5197을 유지한다.

## 인수 기준의 검증 범위

T01–T09: 순수 모델, 구성 컴포넌트, 실제 레일 브라우저 검증.
T10–T19: 세션/이력/팝오버 컴포넌트와 실저장소 브라우저 검증. 문서 Undo는 하네스의 문서 콜백 횟수와 기존 Inspector 회귀 테스트로 확인했다.
T20: Chromium 및 Firefox의 390/360px 터치 에뮬레이션. Firefox는 엔진 특성상 isMobile 없이 viewport+hasTouch를 사용한다.
T21: visualViewport 위치 단위 테스트와 에뮬레이션. 실물 iOS/Android 가상 키보드·회전·펜은 이번 환경에서 직접 검증하지 않았다.
T22–T24: 기존 브러시·Inspector·잠금 회귀 및 새 세션/키보드 계약. 전체 스크린리더·IME·필압 하드웨어 인증을 뜻하지 않는다.
T25: Chromium/Firefox의 실제 OPFS 재진입 통과. WebKit 영속 오류는 위와 같이 남아 있다.

## 의도적으로 변경하지 않은 사항

브러시 렌더러의 새 투명색 합성 기능은 추가하지 않았다. 기존 버튼 동작을 정확히 `지우개로 전환`으로 표시한다.
전체 운영 계정/복잡한 원고/실기기/성능 P95 목표를 이번 로컬 하네스 통과로 일반화하지 않는다.
메인 병합은 운영 배포 승인이 아니다. Cloudflare/Render 배포, DB·도메인·환경 변수는 이번 작업에 포함하지 않는다.

## 2026-09-22 저장 호환성 후속

이전 WebKit 오류는 당시 임시 컨텍스트의 결과입니다. 후속 검증은 임시/디스크 프로필과 새로고침 Worker 잠금 인계를 분리합니다. 지원 범위와 정확한 head 검증은 `drawing-storage-acceptance-20260922.md` 및 PR을 따릅니다. 과거 오류를 모든 Safari의 저장 미지원으로 일반화하지 않습니다.

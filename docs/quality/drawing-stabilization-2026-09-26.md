## 이미지 생성과 품질 증거

생성은 사용 가능한 내장 `image_gen` 도구로 진행한다. 도구가 모델 버전 선택/확인 정보를 제공하지 않으므로 신규 자원을 특정 모델 버전 2.5로 생성했다고 단정하지 않는다. 원본 실제 크기를 기록하며 요청 프롬프트의 목표 해상도를 실제 결과로 대신 기록하지 않는다.

생성 이미지의 외관 검사와 alpha·크기·해시 검증은 구분한다. 생성 소품/장식은 배경 투명도와 테두리를 확인하고, 말풍선 대사는 독립 텍스트로 편집 가능하게 한다. 일반 UI 아이콘과 편집 가능한 기본 도형은 기존 네이티브 표현을 유지한다.

## 검증 증거의 범위

원본 로그와 스크린샷은 로컬 `artifacts/drawing-stabilization-20260926/`에 저장한다. 각 빌드와 테스트 실행을 구분하며 진행 중 변경을 이전 빌드에서 검증했다고 보고하지 않는다.

장시간 보고서에는 시작 준비를 제외한 세션 시간, 실제 조작 시간, 예약된 대기 시간, 브러시별 수행 여부, 오류, 메모리, 캡처가 포함된다. SwiftShader와 합성 펜/터치 입력은 실제 기기의 GPU·펜 테스트를 대체하지 않으며 별도 표시한다. 여러 실행의 동시 시간을 단순 합산해 300분 요건을 충족했다고 계산하지 않는다.

커밋·PR·운영 배포 상태와 최종 검증 결과는 실제 수행 후 기록한다. 운영 배포는 이 작업 범위에 포함하지 않는다.

### 병합 전 집중 검증

- PSD 웹 계약 14파일 253개와 API 계약 2개, 선택·PSD·이미지 경계 14파일 171개 검사를 통과했다. 서로 겹치는 검사는 총합으로 중복 집계하지 않는다.
- 저장 선택의 16MiB 재열기 제한을 저장 전에 동일하게 적용했다. 기존 선택 8개를 유지하고 9번째 초과 입력을 거절하는 UI·프로젝트 아카이브 회귀 3파일 22개 검사를 통과했다.
- 입력 준비 큐의 완성 획을 즉시 복구 저널에 기록하고, 수락 후에도 실제 자동저장이 확인될 때까지 원본을 유지한다. 관련 6파일 54개 회귀 검사를 통과했다.
- 대형 출력 품질 3파일 63개, 출력 메뉴·규격 2파일 68개, 협업 이력과 구조 공유 관련 5파일 91개 검사를 통과했다. 실제 대형 문서 유지 메모리와 외부 Photoshop 화면 대조는 별도 미실행 항목이다.

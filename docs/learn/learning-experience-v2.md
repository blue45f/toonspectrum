## 정보 구조

1. **오늘의 다음 행동**: 진행 중 수업을 최우선으로 재개하고, 없으면 첫 미완료 수업을 추천한다.
2. **내 학습 현황**: 완료 수업, 진행 중 수업, 저장한 용어, 남은 예상 시간을 한 줄에서 확인한다.
3. **목적별 학습 경로**: 빠른 학습, 제작 기초, 툰스튜디오 실습, 용어 사전으로 진입한다.
4. **추천 흐름**: 진행 중 → 미시작 → 완료 순으로 세 개 수업을 제안한다.
5. **전체 커리큘럼**: 검색·과정·상태·시간·정렬을 조합하고 URL로 상태를 보존한다.
6. **수업 상세**: 결과 목표 → 개념 → 조작형 예제 → 직접 실습 → 퀴즈 → 메모 → 완료 순으로 진행한다.

## 구현 세부사항

- 기존 `LearningProgress` 저장 포맷과 방어적 파싱을 변경하지 않는다.
- 추천·필터·진도 계산은 `learning-dashboard.ts`의 순수 함수로 분리한다.
- 완료 상태는 기존과 동일하게 모든 체크리스트와 정답 조건을 만족한 기록만 신뢰한다.
- 강좌 카드에는 과정, 예상 시간, 예제 유형, 진행률, 상태별 CTA를 표시한다.
- 수업 상세에는 학습 목표, 앵커 목차, 진행률, 완료 요구사항, 이전/다음 수업 탐색을 추가한다.
- 용어 사전은 검색·분류·저장 필터와 결과 수를 한 패널에 통합한다.
- 스튜디오 실습은 목표 읽기 → 예제 비교 → 직접 만들기 → 기록의 네 단계 루프를 명시한다.
- 모든 스타일은 `.learn-page` 아래로 범위를 제한해 편집기 캔버스와 전역 테마에 영향을 주지 않는다.

## 접근성·반응형

- 본문 바로가기 링크와 일관된 `:focus-visible` 포커스 링을 제공한다.
- 진행률 원형 그래프는 장식 SVG를 숨기고 텍스트 기반 접근성 이름을 제공한다.
- 검색·필터·강좌 목차·이전/다음 탐색에는 명시적 레이블과 랜드마크를 사용한다.
- 44px 이상의 주요 터치 타깃, 375px 폭 단일 열 레이아웃, 가로 넘침 방지를 유지한다.
- `prefers-reduced-motion`에서는 이동·전환 효과를 제거하고, `prefers-contrast: more`에서는 경계를 강화한다.

## 검증 범위

- 단위 테스트: 미시작/진행 중/완료 판정, 요구사항 기반 진도, 복합 필터, 추천 순서, 시간·완료율 요약
- E2E: 개인화 홈, 전체 강좌 노출, URL 필터 조합, 빈 상태 초기화, 진행 중 수업 재개, 상세 수업 목표·목차·완료 요구사항
- 기존 E2E 보존: 전체 강좌 수, 용어 검색/북마크, 강좌 완료 조건, 메모 지속, 저장 장애, 초기화, 모바일 가로 넘침

## 후속 확장 후보

- 계정 기반 기기 간 동기화와 서버 추천은 별도 개인정보·충돌 정책 설계 후 도입한다.
- 편집기 도구 하이라이트, 예제 프로젝트 복제, 실제 캔버스 결과 자동 판정은 Studio 런타임과의 버전 계약이 준비된 뒤 추가한다.
- 수료증이나 공인 인증 표시는 실제 평가·발급 체계가 생기기 전에는 제공하지 않는다.

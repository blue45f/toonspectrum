# 배우기 페이지 벤치마킹 및 학습 허브 설계

기준일: 2026-09-09

## 목표

기존 `/learn`은 열 개 강좌, 여섯 종류의 조작형 예제, 용어 사전, 체크리스트·퀴즈·메모, 로컬 진행 기록과 백업/복원을 이미 제공합니다. 이번 변경은 콘텐츠를 무작정 늘리기보다 사용자가 **무엇을 어떤 순서로 배우고, 오늘 무엇을 완성할지** 결정하기 어려운 문제를 해결합니다.

핵심 제품 지표는 강좌 노출량이 아니라 다음으로 정의합니다.

- 첫 방문자가 자신의 목표에 맞는 첫 강좌를 선택할 수 있는가
- 한 번의 학습 세션이 확인 가능한 작은 결과물로 끝나는가
- 중단한 사용자가 다음 행동을 바로 찾을 수 있는가
- 전체 강좌를 목표·난이도·시간·상태·역량으로 다시 찾을 수 있는가
- 완료율을 숙련도나 공인 인증처럼 과장하지 않는가

## 설계 원칙

### 1. 목록보다 결과물

강좌 카드의 첫 질문을 “무엇을 설명하는가”에서 “끝나면 무엇이 남는가”로 바꿉니다. 모든 강좌에 콘티, 비교 시트, 레이어 구조, 게시 검수 기록처럼 사용자가 직접 확인할 수 있는 결과물을 부여합니다.

### 2. 경로는 권장 순서이지 잠금 장치가 아님

선행 강좌를 강제하거나 콘텐츠를 잠그지 않습니다. 사용자는 경로 중간부터 시작할 수 있고, 기존의 개별 강좌 URL과 완료 조건도 그대로 유지합니다.

### 3. 계정 없는 개인화

목표, 경험 수준, 한 번에 집중할 시간을 별도 로컬 프로필 `toonstudio:learning-profile:v1`에 저장합니다. 기존 학습 기록 `toonstudio:learning:v1`의 스키마와 백업 포맷은 변경하지 않습니다.

### 4. 정직한 진행률

역량 지도는 관련 강좌의 완료 비율일 뿐 실력 점수나 숙련도 판정이 아닙니다. 완료 기록 역시 체크리스트와 확인 퀴즈를 통과한 자기주도 기록이며 공인 수료증이나 작품 품질 인증으로 표현하지 않습니다.

### 5. 접근성과 작은 화면 우선

- 모든 주요 조작부는 기존 44px 최소 터치 영역 계약을 유지합니다.
- 선택 필드는 명시적 label과 id를 사용합니다.
- 진행 막대마다 접근성 이름을 제공합니다.
- 상태는 색뿐 아니라 `시작 전`, `학습 중`, `완료` 텍스트로 표시합니다.
- 모바일에서는 모든 그리드를 한 열로 축소하고 문서 가로 넘침이 생기지 않도록 `min-width: 0`을 적용합니다.
- 모션 감소 환경에서 필수 정보를 애니메이션에 의존하지 않습니다.

## 구현 범위

### 학습 홈

- 개인화된 다음 강좌와 추천 경로 CTA
- 전체 완료, 저장한 용어, 다음 세션 시간 요약
- 목표·경험·집중 시간 설정
- 다섯 개 목표별 학습 경로
- 15·30·45분 시간 예산에 맞춘 다음 세션
- 여섯 개 제작 역량별 관련 강좌 완료 현황
- 검색, 과정, 난이도, 소요 시간, 상태, 역량, 정렬 필터
- 강좌별 수준, 형식, 결과물, 관련 역량, 자가 점검 진행
- 용어 사전, 툰스튜디오 실습, 기록 관리 진입점

### 학습 경로 상세

- 경로의 목표 결과물, 총 시간, 남은 시간과 완료율
- 단계별 강좌 상태와 결과물
- 다음 미완료 강좌 CTA
- 경로가 다루는 역량 요약
- 자유로운 건너뛰기와 복습 안내

### 제공 경로

1. **첫 3컷 완성**: 아이디어 → 스크롤 호흡 → 말풍선 → 툰스튜디오 러프
2. **스토리·연출 강화**: 장면 목표 → 호흡 → 투시·카메라 → 대사 흐름
3. **그림 완성도 올리기**: 실루엣·명도 → 선화 → 레이어 채색 → 실제 수정
4. **툰스튜디오 빠른 시작**: 기획 원리 → 첫 작업 → 레이어 원리 → 안전한 내보내기
5. **첫 회차 게시 준비**: 콘티 → 대사 → 채색 구조 → 게시본 검수

## 기술 구조

- `LearningHome.tsx`: 강화된 홈과 경로 상세 화면
- `learning-paths.ts`: 강좌 메타데이터, 경로, 추천·진행·세션·역량 계산
- `learning-profile.ts`: 제한된 로컬 개인화 프로필 파싱과 저장
- `learning-hub.css`: `/learn` 범위에만 적용되는 반응형 스타일
- 기존 `LearnContent.tsx`, `learning-model.ts`, `learning-content.ts`, 백업/복원 모듈은 변경하지 않음
- `LearnPage.tsx`에서 정확한 `/learn`과 `/learn/paths/:pathId`만 새 화면으로 분기하고 기존 상세 강좌·용어·실습 라우트는 그대로 전달

## 회귀 방지 계약

- 홈의 실제 강좌 카드만 기존 `.learn-card` 선택자를 사용해 기존 E2E의 열 개 카드 계약을 유지합니다.
- 경로와 리소스 카드는 별도 선택자를 사용합니다.
- 기존 강좌 완료 조건, 메모 길이, 용어 저장, 진행 기록 버전, 초기화와 백업/복원 동작을 변경하지 않습니다.
- 경로·메타데이터의 모든 강좌 ID가 실제 콘텐츠에 존재하는지 단위 테스트로 검증합니다.
- 추천 결과, 시간 예산 세션, 진행 상태, 저장소 오류 복구를 단위 테스트로 고정합니다.

## 이번 범위에서 의도적으로 제외한 항목

- 공인 인증서, 배지, 연속 출석 수치
- 작품 이미지를 서버로 전송하는 자동 채점
- 스튜디오 문서를 몰래 읽거나 기존 작업을 자동 변경하는 기능
- 계정 간 진행 기록 동기화
- 커뮤니티 업로드와 다른 사용자의 작품 평가
- 존재하지 않는 영상·라이브 수업을 제공하는 것처럼 보이는 카드

이 항목들은 신뢰·개인정보·서버 저장·콘텐츠 운영 계약이 먼저 준비되어야 하므로 이번 클라이언트 학습 허브에서 가장하지 않습니다.

# 배우기 상세 수업 경험 고도화

- 기준일: 2026-09-09
- 대상: `/learn/lessons/:lessonId` 및 학습 허브의 다음 세션 추천
- 선행 기반: `docs/learn/learning-hub-benchmark.md`의 개인화 허브·학습 경로·강좌 탐색 기능

## 문제 정의

개인화 학습 허브는 목표, 경험 수준, 집중 시간, 학습 경로와 강좌 필터를 제공하지만 사용자가 강좌를 연 다음에는 다음 문제가 남아 있었습니다.

1. 수업 시작 전에 결과물과 완료 조건을 한눈에 알기 어렵다.
2. 긴 상세 페이지에서 개념, 조작형 예제, 실습, 퀴즈, 메모 사이를 빠르게 이동하기 어렵다.
3. 체크리스트와 퀴즈가 완료 상태에 어떤 영향을 주는지 진행 중에 확인하기 어렵다.
4. 수업을 마친 뒤 이전·다음 강좌나 목표별 학습 경로로 이어지는 탐색이 약하다.
5. 추천 경로에서 앞 강좌를 건너뛰고 뒤 강좌를 일부 진행하면, 홈이 실제 진행 중 수업보다 앞의 미시작 수업을 먼저 제안할 수 있다.

이번 변경은 기존 저장 포맷, 강좌 URL, 조작형 예제, 체크리스트, 퀴즈, 메모와 완료 조건을 유지하면서 이 단절을 해소합니다.

## 구현 범위

### 결과물 중심 수업 시작

- 강좌 번호, 제작 과정, 경험 수준, 예상 시간, 조작형 예제 종류와 진행 상태를 표시합니다.
- 강좌 메타데이터의 `outcome`을 “이 수업을 마치면” 영역에서 가장 먼저 보여 줍니다.
- 관련 제작 역량을 함께 표시해 강좌가 전체 학습 경로에서 어떤 역할을 하는지 설명합니다.

### 긴 페이지 탐색

- 개념 섹션, 조작형 예제, 직접 실습, 확인 퀴즈, 메모로 이동하는 강좌 목차를 제공합니다.
- 앵커 대상에는 키보드 포커스 스타일과 스크롤 여백을 적용합니다.
- 수업 하단에 이전·다음 강좌 카드를 제공하고 첫 강좌에서는 학습 경로로 연결합니다.

### 완료 요구사항 가시화

- 체크리스트 완료 수, 퀴즈 정답, 완료 기록 저장을 세 단계로 나눠 표시합니다.
- 상단과 사이드바에서 동일한 자가 점검 진행률을 확인할 수 있습니다.
- 진행률은 유효하고 중복되지 않은 체크 인덱스와 정답만 계산하며 100%를 넘지 않습니다.
- 기존과 동일하게 체크리스트 전체와 정답을 만족해야 완료 버튼이 활성화됩니다.

### 진행 중 수업 재개

- 추천 경로 안에 진행 중 강좌가 있으면 미시작 강좌보다 먼저 다음 세션에 배치합니다.
- 진행 중 강좌가 여러 개면 경로 순서를 유지합니다.
- 진행 중 강좌가 없을 때만 미시작 강좌를 커리큘럼 순으로 제안합니다.
- 모든 강좌를 완료한 경우 기존처럼 첫 강좌부터 복습 세션을 구성합니다.

### 접근성·반응형·출력

- 상세 경로에 본문 바로가기 링크와 `<main>` 랜드마크를 추가합니다.
- 목차, 이전·다음 강좌, 진행 요구사항에 명시적인 접근성 이름과 텍스트 상태를 사용합니다.
- 상태를 색상만으로 전달하지 않습니다.
- 375px 화면에서는 모든 상세 영역을 한 열로 정렬하고 문서 가로 넘침을 방지합니다.
- `prefers-reduced-motion`, `prefers-contrast: more`, 인쇄용 레이아웃을 지원합니다.
- 모든 신규 스타일은 `.learn-page`와 상세 수업 클래스 아래로 제한합니다.

## 호환성 계약

- `toonstudio:learning:v1` 저장 스키마와 백업 포맷을 변경하지 않습니다.
- 기존 강좌 URL과 용어 사전·스튜디오 실습·기록 관리 URL을 유지합니다.
- 기존 조작형 예제의 슬라이더, 저감 모션 동작과 캡션을 변경하지 않습니다.
- 완료 버튼의 접근성 이름과 완료 취소 규칙을 유지합니다.
- 손상된 로컬 저장소와 저장 실패에 대한 기존 방어 동작을 유지합니다.

## 검증

### 단위 테스트

- 진행 중, 미시작, 완료 상태 구분
- 비정상·중복 체크 인덱스를 포함한 진행률 상한과 정확성
- 진행 중 수업 우선 재개
- 시간 예산 안의 세션 구성과 전체 완료 후 복습 폴백
- 학습 경로, 역량, 메타데이터 무결성

### Playwright E2E

- 결과물·강좌 목차·진행 요구사항·이전/다음 탐색 노출
- 체크리스트와 정답에 따른 실시간 진행률 및 완료 버튼 활성화
- 완료 기록 저장 후 요구사항 상태 전환
- 뒤쪽 진행 중 수업이 홈과 다음 세션에서 우선 노출
- 375px 화면의 랜드마크와 문서 폭
- 기존 강좌, 용어 사전, 저장 장애, 초기화, 저감 모션 회귀 시나리오와 병행 실행

## 의도적으로 제외한 범위

- 서버 기반 개인화, 계정 간 진도 동기화
- 작품 파일 업로드와 자동 품질 판정
- 편집기 화면 자동 조작 또는 기존 작업 자동 변경
- 공인 수료증, 숙련도 점수, 출석 연속 기록

이 기능들은 개인정보, 충돌 처리, 평가 기준과 콘텐츠 운영 계약이 준비된 뒤 별도 범위로 설계합니다.

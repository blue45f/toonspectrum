# 웹툰 제작 과정·직무·교육기관 안내

## 공개 경로

| 경로 | 목적 |
| --- | --- |
| `/learn/process` | 아이디어부터 연재 운영까지 9단계 제작 과정과 산출물·참여 직무·Studio 이동 경로 안내 |
| `/learn/careers` | 웹툰 제작 8개 역할의 업무·역량·포트폴리오 증거와 관련 제작 단계 안내 |
| `/learn/education` | 대학·학원·공공·온라인 교육기관 검색, 목적·지역·방식 필터, 최대 3곳 비교 |

기존 `/learn`, `/learn/lessons/*`, `/learn/paths/*`, `/learn/glossary`, `/learn/studio`, `/learn/records`의 학습 기록과 강좌 계약은 변경하지 않는다. 새 안내 페이지는 `LearnPage`의 정확한 경로 분기에서만 렌더링한다.

## 교육기관 정보 정책

- `apps/web/src/domains/learn/learning-reference-data.ts`의 정적·타입 지정 레지스트리만 사용한다.
- 자동 크롤링, 순위, 별점, 후기, 제휴 우선 노출을 사용하지 않는다.
- 기관명·유형·지역·수업 방식·교육 목적·공식 URL·확인일을 함께 기록한다.
- 학과 전형, 모집 일정, 수강료, 환불 조건은 바뀔 수 있으므로 UI에서 공식 홈페이지 재확인을 요구한다.
- 기관 설명은 공식 페이지의 문장을 복제하지 않고 탐색 목적에 맞게 자체 요약한다.
- 새 기관을 추가할 때 `verifiedAt`을 실제 확인일로 갱신하고 `learning-reference-data.test.ts`의 URL·중복·필터 계약을 통과시킨다.

## 정보 수정 절차

1. 기관의 공식 홈페이지에서 현재 명칭과 운영 여부를 확인한다.
2. 루트 또는 장기간 유지되는 공식 URL을 우선 사용한다.
3. 지역·수업 방식·목적은 공개된 정보로 확인 가능한 범위만 기록한다.
4. 등록금·수강료 숫자를 복제하지 않고 `공식 안내 확인` 문구를 기본값으로 사용한다.
5. 삭제보다 운영 종료 또는 확인 필요 상태를 별도 모델로 확장하는 방식을 우선 검토한다.

## 접근성과 사용성

- 검색 조건은 URL 파라미터로 유지되어 뒤로 가기와 링크 공유가 가능하다.
- 결과 수를 `aria-live` 상태로 안내한다.
- 기관 비교는 체크박스로 최대 3곳까지 선택하고 표의 `caption`과 행 머리글을 제공한다.
- 외부 공식 링크는 새 창임을 접근 가능한 이름으로 알린다.
- 빈 결과, 비교 미완료, 비교 한도 상태를 각각 명시적으로 안내한다.

## 회귀 검증

- 제작 단계 순서·산출물·Studio 링크 계약
- 직무와 실제 제작 단계 연결 계약
- 기관 ID·공식 HTTPS URL·확인일·필수 분류 계약
- 검색어·유형·지역·방식·목적 복합 필터 계약
- 새 경로의 공개 사이트 크롬 분류 계약

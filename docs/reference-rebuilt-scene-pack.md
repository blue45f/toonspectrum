# 미리보기 참고 재제작: 교실 · 복층 도서관

## 실제 범위

판매 원본 파일을 확보하지 못한 상태에서 공개 미리보기의 공간 유형과 가구 구성을 참고해 새 메시를 제작했다. **2개 장면과 그 안에서 재사용하는 4개 모듈, 총 6개 GLB 출력**이다. ACON 전체 카탈로그 복제, 원래 SKP 메시/치수/리깅 복원, 기존 상품보다 높은 품질을 증명한 결과가 아니다. 모듈을 포함한 장면을 다시 독립 원본 개수로 부풀리지 않는다.

- 채광 교실: 24개 책걸상, 창문, 칠판, 수납장, 분리형 천장.
- 복층 아카이브: 상하층 서가, 계단/계단참, 난간 통로, 독서 가구, 분리형 천장.
- 재사용 모듈: 책걸상 세트, 몰딩 책장, 독서 테이블, 패브릭 독서 의자.

참고: https://www.acon3d.com/ko/product/1000046396 ; https://www.acon3d.com/ko/product/2000000735 ; https://www.acon3d.com/en/product/1000008256 . 공개 상품 이미지를 텍스처로 추출하지 않았으며, 보이지 않는 구조는 새로 설계했다. 사용자에게 별도 허락이 있다는 전제로 출처를 기록했고, 그 사실을 CC0나 모든 사용자에 대한 무제한 재허락으로 바꾸지 않았다.

## 이용 경로

배포 후 `/assets/reference-rebuild/index.html`에서 실제 GLB 메시를 회전/확대/후면 검토하고 파일로 저장할 수 있다. 검토실에서 기본으로 숨긴 천장은 파일 안에 별도 노드로 포함된다. GLB를 다른 편집기로 열면 천장이 표시될 수 있다.

Studio 3D 모델 패널 하단의 **미리보기 참고 재제작**에서 모델을 선택하면 Module Worker가 GLB를 생성한다. 결과의 크기/헤더/버전을 확인한 뒤 기존 패널의 실제 file input으로 전달한다. 현재 이용 권리 선택, 기존 정규화/검증/저장 소유자는 그대로 유지한다. 권리 입력이 미완성이거나 다른 작업이 진행 중이면 전달하지 않는다. 생성 성공 메시지는 저장 성공을 뜻하지 않는다. 기존 모델 목록의 검사 결과를 확인해야 한다.

기존 패널은 `StudioBg3dAssetLibraryPanelBase.tsx`에 **동일한 blob**으로 보존했다. 원래 import 경로에는 작은 래퍼만 놓았고, 기존 경계 테스트는 동일한 Base 구현을 계속 검사하며 래퍼 경계 검사도 추가했다. 기존 CI/보호 규칙/CC0 번들 카탈로그는 변경하지 않았다.

```sh
# Node만 사용. 생성 결과는 소스가 아니라 실제 자체 포함 GLB 파일이다.
node scripts/export-reference-rebuild.mjs ./reference-rebuild-output
node --test scripts/verify-reference-rebuild.mjs
```

출력 명령은 지정 폴더에 동일 파일명을 다시 쓴다. 원본이나 기존 작업 파일이 없는 별도 출력 폴더를 사용한다. 서버/API/유료 생성 서비스는 호출하지 않는다. 저장소에는 재현 가능한 생성기를 넣고, GitHub 전용 검사는 생성한 실제 파일을 Actions artifact로 보관한다.

## 기술과 실제 검증

GLB 2.0, 미터 단위, 이름 있는 조립체, 반복 가구의 메시 공유, 둥근 모서리, 선반 가공 형상의 다리, UV/노멀, PBR 재질 및 내장 목재/직물 PNG를 사용한다. 책장 한 모듈의 책들은 재질별 메시로 묶이므로 모든 책이 개별 장면 노드인 것은 아니다. 128×128 반복 텍스처를 사용하며 4K 텍스처라고 표시하지 않는다.

실행한 로컬 검증(2026-09-06): Node 22.16.0에서 25개 테스트 통과, 6개 GLB를 trimesh/Pillow로 독립 디코딩, 실제 출력의 3개 시점씩 총 18개 이미지 확인, 1440px/390px 검토실 UI 확인. 파일 구조/인덱스/노멀/범위/PNG CRC와 압축 해제/출처/결정성/Worker 프로토콜을 검사했다. TSX는 문법 변환 검사만 실행했다.

**검증 제한:** 현재 실행 환경은 WebGL 2를 제공하지 않아 CPU 렌더러로 형상을 확인했다. 검토실에는 검증하지 못한 별도 WebGL 렌더러를 넣지 않았다. CPU 미리보기는 투영·가림·UV와 기본 조명만 표현하며 그림자/금속 반사 등 GPU 결과의 증빙이 아니다. Studio의 실제 GPU 렌더링, React 통합의 업로드/저장/재열기 E2E, 전체 저장소 typecheck/build/CI, 모바일 기기별 GLB 예산은 아직 검증 완료로 기록하지 않는다. 런타임 안전 검사는 기존 가져오기 경로에서 다시 수행한다. 검토실의 파일 생성/이미지 출력과 main 병합/운영 배포는 별개다.

추가 확인: 브라우저의 실제 GLB 저장 6건은 Node 출력과 SHA-256이 일치했다. 선형 색상 계수를 float32로 고정해 런타임별 부동소수점 직렬화 차이를 제거했다. 별도 about:blank 환경의 최소 Module Worker 로딩 점검은 실패했으므로 배포된 동일 출처 Worker의 로딩 성공을 주장하지 않는다. Worker 메시지 프로토콜은 Node 테스트, 실제 File/DataTransfer/change 이벤트는 브라우저에서 따로 확인했다.

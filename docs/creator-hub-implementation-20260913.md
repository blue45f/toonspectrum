2026-09-13 요청: 웹툰 용역·어시/팀원 모집·신작/작가 홍보 커뮤니티.

## 통합

독립 브랜치에서 PR #1388 원격 커밋 c3e94fdde9c920fc93db60020a471c6f73a0bed0과 기존 협업 게시판 미커밋 작업을 통합했다. 원본 worktree는 수정하지 않았다. 공통 메뉴·라우트·API 모듈 충돌을 해소했다. 기존 0045 스튜디오 미디어 마이그레이션을 보존하고 홍보는 0046, 협업은 0047로 등록했다. 기존 운영 데이터는 변경하지 않았다.

## 주요 기능

`/community`에서 `/collaborate`와 `/community/promote`를 연결했다. 모집/홍보 간 상호 이동과 작가 프로필 연결을 제공한다.

협업: 팀원 모집·작업 의뢰·작업자 홍보, 역할·보수·원격/대면/혼합·상태 필터, 검색, 내 공고/지원/저장 목록, 작성 예시, 계정별 기기 초안, 상세·수정·삭제·마감, 비공개 지원과 작성자 전용 지원 관리.

홍보: 작품·트레일러·제작 과정·피드백, 아마추어/첫 작품/연재 단계, 장르·검색·태그, 표지 업로드와 기기 내 압축, 작품 링크·작가 프로필, 댓글·북마크·편집·보관·신고·운영자 관리.

## 안전장치와 한도

기존 서명 세션/CSRF 보호를 재사용하고 개인화 응답은 private/no-store로 처리한다. 저장소 장애를 빈 목록이나 성공으로 위장하지 않는다. 수정 버전 충돌은 거부한다. 지원 철회/공고 삭제 시 지원 메시지·연락처·포트폴리오를 제거한다.

협업 생성은 DB advisory lock 안에서 24시간 5개·계정당 보관 공고 100개를 제한한다. 삭제로 일일 한도를 초기화할 수 없다. 공고 행 잠금 안에서 활성 지원 정원 200명을 확인하며, 작성자 목록에서는 활성 지원을 우선한다. 북마크와 삭제/비공개 전환도 직렬화한다.

수익배분·무급은 팀원 모집에서만 허용하고 유료 의뢰와 구분한다. 마감은 한국 시간 해당 날짜 23:59:59.999까지다. 지원 승인 자체가 계약 체결이나 스튜디오 접근 허가는 아니다.

표지는 최대 640×800px, JPEG 128KB로 제한한다. 영상은 YouTube/Shorts/Vimeo 링크만 지원한다. 클릭 전 외부 플레이어를 로드하지 않고 영상 변경 후에는 다시 동의를 받는다.

## 검증 기록

홍보 Node 계약 테스트 84개, Vitest 103개(협업 계약 69, 저장소/서비스 19, 영상 3, 세션/CSRF 각 6), Chromium 데스크톱/모바일 8개가 통과했다. 웹 전체 타입 검사는 기본 4GB heap에서 중단되어 8GB로 재실행 후 통과했다. API 타입 검사도 통과했다. 최종 lint/build/CI 결과는 PR 본문에 기록한다.

브라우저 테스트는 실제 Chromium과 명시적 API fixture를 사용한다. 저장소 트랜잭션 테스트는 mock PostgreSQL 기반이다. 실제 운영 API E2E나 실제 PostgreSQL 동시성 검증으로 표현하지 않는다.

## 제외 및 병합 전 조건

원본 영상 파일 업로드/변환, 결제·에스크로, 법률 판단·계약 보증, 팔로우 알림·AI 자동 심사는 포함하지 않는다. 새 유료 서비스·API 키·스토리지를 생성하지 않았다. 기존 DB의 저장량·전송량까지 무료 한도 이내라고 보장하는 것은 아니다.

실제 PostgreSQL 0046/0047 신규 적용·재실행, 계정 권한 교차 검증, CI 성공, 기존 인프라 무료 한도 확인이 병합 전 조건이다. 로컬 Docker 데몬과 PostgreSQL 실행 환경이 없어 실제 DB 검증은 아직 미완료다. 이 기록은 운영 반영 완료 선언이 아니다.

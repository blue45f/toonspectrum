# Studio 원본 품질·가져오기 신뢰성 개선 — 2026-09-14

## 사용자 결정과 범위

비용을 낮추기 위해 기능·품질·사용성·편의성을 낮추지 않는다. 공통 기준은
`operations/quality-preserving-cost-policy.md`에 기록했다.
이 변경은 전체 스튜디오 로드맵 중 원본 보존·가져오기 성능·취소·오류 회복·손실 안내 경로를 구현한다.
전체 브러시·테마·3D·AI·협업을 이 PR 하나로 모두 완료했다는 기록이 아니다.
기준 커밋: `f5253816416488d4e4b66c589223e861b4e8d7b2`.

## 구현

- PSD 레이어를 1280px WebP로 재인코딩하던 경로를 제거했다.
- 표시 배치 크기와 저장 픽셀 크기를 분리한다. 원본 래스터는 원래 크기의 무손실 PNG다.
- 지원하는 브라우저에서는 `toBlob` 기반 비동기 PNG 인코딩을 한 번 수행한다.
  Canvas 어댑터에 `toBlob`이 없을 때만 기존 PNG `toDataURL`을 사용한다.
- 래스터 마스크도 레이어 원본 픽셀과 같은 해상도로 준비하여 경계를 보존한다.
- 읽기·디코딩·레이어 준비·완료 진행 상태를 표시하고 레이어 배치 사이에 입력 기회를 돌려준다.
- PSD 검사 중 취소 버튼을 제공한다. 편집 권한을 잃은 뒤에도 자신의 검사 취소는 가능하다.
- 취소된 작업의 늦은 진행률·결과는 반영하지 않는다. 이전 작업의 finally가 새 작업의
  컨트롤러·busy 상태를 지우지 않도록 소유권을 확인한다.
- 결과는 기존 손실 미리보기와 배치 확인을 거친다. 디코딩 완료만으로 문서를 변경하지 않는다.
- 진행 상태를 스크린리더가 읽을 수 있게 하고 긴 상태 문구는 줄바꿈한다.
- 새 결과에 `native-png` 표시를 추가하여 레거시 프록시 결과와 구분한다.
  원본 픽셀 보존을 원본 PSD의 모든 편집 구조 보존으로 오인하지 않게 안내한다.

## 검증

단위·컴포넌트·가져오기 통합: 10개 파일, 203개 테스트 통과.
기존 축소 기대 4건은 원본 보존 계약으로 바꾸었으며 기존 파일 검증·손실 검사·적용 확인은 유지했다.
새 검사는 취소 전/중/후, 늦은 콜백, 새 작업과의 경쟁, 권한 변경, FileReader 생성 실패,
원본 크기·마스크 보존·UI 진행 상태를 포함한다.
변경 소스 ESLint `--max-warnings=0`, 웹/API 타입 검사, 아키텍처 검사 및 diff 공백 검사 통과.

실제 브라우저 검증은 다음 명령으로 재현한다.

```sh
node scripts/verify-studio-psd-original-quality.mjs
```

외부 API 없이 로컬 합성 원고를 실제 Canvas와 ag-psd로 생성·인코딩·가져오기·PNG 재인코딩한다.
2560×128 가로 원고, 96×2560 세로 원고, 128×64 작은 원고를 비교했다.
앞의 두 원고는 전체 래스터 마스크도 비교한다. 픽셀 채널 및 마스크 알파 차이는 모두 0이었다.
실제 브라우저 PNG 인코딩 취소도 통과했다. 기본 결과 위치는 `/tmp/toonspectrum-psd-original-quality`이며
`TOONSPECTRUM_VERIFY_DIR`로 바꿀 수 있다. 검사 스크립트는 자기 서버·브라우저를 종료한다.
검사 보고서에는 소스 해시를 기록한다. 결과는 `validation/studio-psd-original-quality-2026-09-14.json`에도 보관한다. 소요 시간은 참고 관측값이며 경쟁 제품과의 성능 비교가 아니다.

## 유지한 경계

- PSB·미지원 비트 깊이/색 공간·파일/디코딩 메모리·프로젝트 포함 예산의 기존 안전 검사를 유지한다.
- 원본 PNG는 종전 축소 WebP보다 크므로 큰 파일에서는 기존 저장 예산에 더 빨리 도달할 수 있다.
  이때 원본을 몰래 축소하지 않고 기존 안전 검사가 안내한다. 초대형 문서 전체 지원은 별도 검증 대상이다.
- readPsd 자체는 여전히 동기 디코딩이다. 디코더 실행 도중 즉시 선점 취소된다고 주장하지 않는다.
- 그룹 격리 합성·조정 레이어·스마트 오브젝트·텍스트 편집 구조의 완전한 왕복을 보증하지 않는다.
- 이 브라우저 검사는 실제 코덱/픽셀 검사다. 전체 운영 화면 E2E, 실기기 펜 지연,
  경쟁 제품 우위, 전체 저장소 테스트 또는 운영 배포 검증을 대신하지 않는다.
- 배포·DB 변경·키 변경·유료 추론·외부 모델 다운로드는 실행하지 않는다.

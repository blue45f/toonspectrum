# ToonStudio 메뉴 정보구조 최적화 — 2026-09-05

## 목표

기능 수를 줄이지 않고 메뉴를 사용자의 작업 목적에 맞춰 재배치한다. 상단 메뉴는 문서와 앱 전체에
적용되는 명령, 왼쪽 레일은 현재 도구 선택, 툴벨트는 제작 흐름의 빠른 진입, 오른쪽 인스펙터는
선택 대상과 활성 도구의 속성, 프로젝트·검수 패널은 문서 구조와 승인 흐름을 담당한다.

## 메뉴 표면 역할

- 상단 메뉴: 전역 명령과 문서 수명주기. 정본 command id와 실행 핸들러는 이동하지 않는다.
- 왼쪽 도구 레일: 선택·펜·지우개·채우기·변형처럼 포인터 행동을 바꾸는 도구만 둔다.
- 제작 툴벨트: 에셋 → 컷 → 그리기 → 삽입 → 3D·참고 → 장면 → 스타일 → AI 순으로 스캔한다.
- 오른쪽 인스펙터: 현재 선택 또는 활성 도구에 필요한 속성만 보여 준다.
- 프로젝트·검수 패널: 페이지 구조, 버전, 댓글, 승인, 게시 사전검사를 담당한다.

## 중복과 확장 규칙

1. 모든 기능은 하나의 정본 command id와 하나의 정본 소유 그룹을 가진다.
2. 중복 진입점은 저장·실행취소·내보내기처럼 빈도가 높거나 모바일 도달성을 보장할 때만 허용한다.
3. 합성 메뉴 안에서도 원래 그룹 캡션을 유지해 위치 기억과 접근성을 보존한다.
4. 새 카탈로그 그룹은 누락시키지 않고 도움말 직전에 임시 노출한다. 이후 IA 소유자를 지정한다.
5. AI는 효과 아래로 숨기지 않는다. 기능이 늘어나도 AI 메뉴 안에서 생성·보정·글쓰기·관리 구획으로 확장한다.
6. 필터는 기본, 레이어 보정, 픽셀화, 블러, 렌즈·화면, 스타일화, 선화·복원, 노이즈, 왜곡, 질감·변환 캡션을 유지한다.

## 회귀 방지

- 표시 제목 10개의 개수·순서·표기를 독립적으로 고정한다.
- 모든 정본 그룹의 행이 합성 뒤에도 누락·재정렬되지 않는지 단위 테스트한다.
- 합성 구획은 role=group과 캡션 연결을 유지하고, 키보드 행 순서는 평면으로 보존한다.
- 브라우저 검증 스크립트의 진입 메뉴를 새 소유 메뉴에 맞춰 갱신한다.

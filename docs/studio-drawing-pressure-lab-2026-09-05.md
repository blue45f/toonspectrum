# Studio 그리기 입력 품질 고도화 — 필압 랩 마감 기록 (2026-09-05)

## 목표

이번 변경은 기존 획·브러시 저장 형식을 바꾸지 않으면서, 작가가 가장 자주 반복하는 필압 설정
루프를 짧고 검증 가능하게 만드는 데 집중한다.

1. 필압 곡선을 그래프에서 직접 조절한다.
2. 실제 스타일러스 입력으로 현재 반응을 즉시 시험한다.
3. 수집된 압력 분포에서 안전한 권장값을 계산한다.
4. 데스크톱과 터치 UI 모두에서 조작성을 유지한다.
5. 기존 `pressureCurve: number` 계약을 끝까지 보존한다.

## 제품 벤치마크

- Procreate는 전역 필압 곡선 그래프를 직접 조절할 수 있으며, 가로축을 입력 압력, 세로축을
  브러시 출력으로 설명한다.
  <https://help.procreate.com/procreate/handbook/actions/actions-preferences>
- Adobe Fresco는 필압 곡선의 노드를 조절한 뒤 옆 시험 영역에 러프 스케치를 그려 결과를
  확인하도록 제공한다.
  <https://helpx.adobe.com/fresco/desktop/draw-paint-animate-and-share/pressure-curve.html>

Studio에는 이미 필압 프리셋, 연속 감마 슬라이더, 최소 굵기, 하드웨어 필압 우선권,
coalesced pointer 수집, 라이브/커밋 렌더 일치 경로가 존재했다. 남은 제품 흐름의 핵심 공백은
그래프 직접 조작과 작품에 영향을 주지 않는 실입력 검증 공간이었다.

## 이번 변경에서 제공하는 기능

### 1. 필압 곡선 직접 조작

- 기존 스칼라 파워 곡선 위에 큰 투명 SVG 히트 영역을 배치했다.
- 제어점을 세로로 드래그하면 그래프 출력이 기존 호환 감마 지수로 역변환된다.
- 방향키, Home, End로도 조작할 수 있는 `slider` 접근성 의미를 제공한다.
- 기존 프리셋 칩과 연속 범위 입력을 그대로 유지해 대체 조작 경로를 보장한다.
- 터치 밀도에서는 제어점 히트 영역을 더 크게 제공한다.

### 2. 작품과 격리된 실시간 필압 시험선

- `필압 테스트 · 자동 보정`을 접힌 disclosure로 배치해 기본 인스펙터 높이를 늘리지 않는다.
- 시험 영역은 실제 PointerEvent를 사용하고, 지원 브라우저에서는 `getCoalescedEvents()`의
  하드웨어 샘플을 소비한다.
- 시험선 굵기와 농도는 그래프에 표시되는 동일한 파워 곡선으로 계산한다.
- 인접한 `최소 굵기` 설정도 시험선에 반영한다.
- 입력·적용 출력 미터와 최신 백분율을 동시에 표시한다.
- 시험선 샘플은 컴포넌트 로컬 상태에만 존재한다. 페이지 문서, 실행 취소, 자동 저장,
  협업 스트림, 렌더 영수증, 내보내기에는 들어가지 않는다.
- React/SVG 작업량을 제한하기 위해 유지 샘플을 최근 180개로 제한한다.

### 3. 안전한 자동 보정

- 압력 0인 시작·종료 센티널은 통계에서 제외한다.
- 유효 샘플 8개 이상, 동적 범위 0.08 이상일 때만 권장값을 제공한다.
- 마우스의 고정 50% 필압 스트림은 동적 범위가 없으므로 자동 보정을 활성화하지 않는다.
- 관측된 중앙값이 출력 50%에 대응하도록 감마를 계산한 뒤 기존 허용 범위로 제한한다.
- 권장값 적용은 프리셋·슬라이더와 동일한 `onPressureCurveChange` 경로를 사용한다.

### 4. 터치·접근성

- 터치 밀도의 프리셋 및 보정 동작은 44px급 높이를 사용한다.
- 직접 조작 제어점은 키보드 포커스, 현재값, 최소·최대값, 세로 방향 의미를 노출한다.
- 보정 결과 요약은 샘플 수, 관측 범위, 중앙값을 `aria-live`로 알린다.
- 시험선 자체를 사용할 수 없는 입력 환경에서도 기존 프리셋과 range 입력은 그대로 동작한다.

## 호환 경계

다음 데이터에는 새 필드를 기록하지 않는다.

- `DrawEl`
- 브러시 카탈로그/사용자 프리셋
- CRDT 연산
- 자동 저장 페이로드
- 프로젝트 모델 스키마
- 내보내기 형식

따라서 기존 숫자형 필압 곡선은 마이그레이션 없이 그대로 동작한다. 미래 브러시 플랫폼 IR에
존재하는 다중 제어점 장치 보정 LUT와 dead-zone은 문서 버전·렌더러 일치 검증을 동반하는 별도
엔진 변경으로 연결해야 한다.

## 자동화 검증

대상 테스트:

```bash
pnpm exec vitest run \
  src/domains/creator/studio-pressure-curve-graph.test.ts \
  src/domains/creator/StudioPressureCurveGraph.test.tsx
pnpm run lint:quick
pnpm run typecheck
```

검증 항목:

- 그래프 제어점과 기존 감마 지수의 왕복 변환
- 감마 범위 상·하한 제한
- 단조 증가 SVG 곡선 생성
- 0 압력 센티널 제외
- 샘플 중앙값·범위 계산
- 다양한 스타일러스 압력에서 권장값 생성
- 고정 마우스 압력 및 부족한 샘플에서 권장값 거절
- 최소 굵기를 포함한 시험선 지름 계산
- 직접 편집기, 프리셋, 시험 패드, 자동 보정 UI의 정적 렌더 계약

## 수동 인수 기준

- 제어점 드래그 중 곡선과 감마가 연속적으로 갱신된다.
- 키보드 조작으로 허용 감마 범위를 벗어나지 않는다.
- 약한 압력부터 강한 압력까지 그리면 자동 보정이 활성화된다.
- 마우스로 그린 고정 필압 스트림에서는 자동 보정이 비활성 상태를 유지한다.
- 시험선 삭제는 현재 필압 설정을 변경하지 않는다.
- 시험선 흔적이 캔버스와 실행 취소 이력에 나타나지 않는다.
- compact UI는 사용자가 펼치기 전까지 보정 영역을 숨긴다.
- touch UI의 주요 동작은 44px급 목표 크기를 유지한다.

## 다음 그리기 엔진 고도화 순서

1. 장치별 다중 제어점 필압 LUT와 dead-zone을 주 Studio 잉크 경로에 버전형 직렬화로 연결한다.
2. 펜 뒤집기 지우개와 barrel/squeeze 버튼의 순간 도구 전환을 추가한다.
3. 초장문 획을 chunk 단위로 확정해 하나의 요소가 무한히 커지지 않도록 한다.
4. pointer-to-visible 지연과 coalesced gap 진단을 사용자용 입력 건강 패널로 승격한다.
5. 압력·틸트·회전·텍스처·대칭·지우개·1,000px 브러시 parity gate를 통과한 뒤 GPU 권한
   이전을 확대한다.

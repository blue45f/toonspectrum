# Studio 마감 품질 검사

기준일: 2026-09-05

## 목적

최종 원고를 사람이 처음부터 끝까지 다시 훑기 전에, 문서가 확정적으로 설명할 수 있는 구조적 결함과 제작 마감 위험을 한 번에 찾는다. 검사는 원고를 변경하지 않으며, 창작 의도나 외부 플랫폼의 변경 가능한 정책을 추측하지 않는다.

## 검사 범위

- 문서·페이지·요소·그룹 식별자와 페이지 기하
- 페이지 승인 상태, 수정 요청, 승인 후 편집 잠금
- 레이어 그룹 참조와 z-order 연속성
- 최종 원고에 노출될 수 있는 가이드·러프·메모 레이어
- 빈 대사, 임시 치환 문구, 제어 문자, 작은 글자, 루비·부분 서식 범위
- 말풍선 텍스트 넘침과 WCAG 명도 대비
- 이미지 원본, 임시 Blob URL, 외부 URL, 레이어·필터 마스크 연결
- 셀 애니메이션 프레임 ID·원본·타이밍·활성 프레임 일치
- 획 좌표 쌍, 유한 좌표, 굵기, 필압·기울기·시간 샘플 개수
- 열린 검수 댓글과 삭제된 페이지·컷·요소를 가리키는 댓글 앵커

## 심각도와 출고 판단

| 심각도 | 의미 | 출고 |
| --- | --- | --- |
| `blocker` | 문서·기하·획 데이터가 안정적으로 해석되지 않는 구조 손상 | 차단 |
| `error` | 수정·연결·승인 상태를 바로잡아야 하는 확정 문제 | 내보내기 자체는 가능하나 최종 검토 준비 미완료 |
| `warning` | 독자 화면이나 제작 의도를 사람이 확인해야 하는 위험 | 허용 |
| `info` | 책임자·픽셀·외부 정책 확인이 필요한 보조 정보 | 허용 |

`canExport`는 구조 손상 여부만 반영한다. 외부 플랫폼의 폭·높이·용량·페이지 수 제한은 자주 변경되므로 기존 `studio-publish-preflight.ts`의 목적지 프리셋이 계속 소유한다.

## UI 흐름

기존 「이야기 연속성 검사」 표면을 마감 검수 작업공간으로 확장한다.

1. 상단에서 0–100 품질 점수와 차단·오류·경고·확인 수를 본다.
2. 검색, 심각도, 검사 영역으로 결과를 좁힌다.
3. 페이지·요소가 있는 문제를 누르면 해당 원고 위치로 이동한다.
4. JSON 보고서를 내려받아 외부 검수·보관에 사용한다.
5. 아래의 기존 이야기 연속성 결과에서 인물·장소·시간·의상·소품 설정을 이어서 확인한다.

## 신뢰 경계

- 검사 엔진은 순수 함수이며 페이지·요소·댓글을 변경하지 않는다.
- 자동 수정을 실행하지 않는다. 수정은 기존 편집기 트랜잭션과 Undo 권한 아래에서만 수행해야 한다.
- 반투명·그라데이션 말풍선은 단색 대비로 거짓 통과시키지 않고 `확인`으로 남긴다.
- 회전 요소는 저장된 축 정렬 경계를 기준으로 보수적으로 검사한다.
- 숨김 요소는 구조 검사는 수행하지만 대사·이미지·획 콘텐츠 검사는 기본적으로 건너뛴다.
- 최대 500개 결과만 보관하고 초과 사실을 명시해 비정상 문서가 UI를 고갈시키지 못하게 한다.

# 문서 작업 규칙

이 디렉터리에서는 루트 `AGENTS.md`와 이 규칙을 함께 적용한다.

- 신규·수정 문서는 한글을 기본으로 하며 코드·명령·고유명사·표준 용어는 원문을 유지한다.
- 문서가 설명하는 상태를 `current`, `migration`, `target`, `legacy exception` 중 하나로 분명히 한다.
- 구현되지 않은 계획을 현재 기능처럼 쓰지 않는다.
- source/tests 또는 accepted ADR로 확인할 수 없는 수치와 완료 주장은 근거를 남긴다.
- 상대 날짜 대신 `YYYY-MM-DD`를 사용하고, 역사 문서와 현재 운영 문서를 구분한다.
- 명령 예시는 복사 가능한 형태로 작성하고 실행 위치, 전제 조건, 위험한 부작용을 함께 적는다.
- 운영 절차에는 승인 주체, 입력, 성공 기준, 실패·롤백 경로를 포함한다.
- 링크·파일 경로를 변경하면 참조하는 문서를 함께 검색한다.
- 문서만 변경해도 `pnpm harness:check`와 변경 파일 Secretlint를 실행한다.

# ADR 0010 — 차세대 엔진 리스크 수용과 품질 우선 선정 정책

## 상태

승인 (2026-08-07, 제품 오너 구두 지시 2건 반영)

## 맥락

제품 오너 지시(2026-08-07):
1. "성능보다 오히려 더 중요한 건 품질·손맛·필압 정밀함이다."
2. "Vello 등 차세대 엔진을 최대한 활용하라. 성능 면에서 검증받지 못했더라도 클립 스튜디오를
   이기려면 좀 더 모험을 해야 한다."

V11.1 §8은 이미 "Vello의 알파 상태 때문에 기능을 숨기지 않는다 — CapabilityRegistry가 불안정
구간만 다른 Provider로 보낸다"고 규정하고, §3.2는 브러시류에 가중치가 아닌 **최소 통과 조건**을
요구한다. 리포 기존 엔진 선정 벤치도 "성능은 veto only, never bonus"를 명문화하고 있어 세 규범이
일치한다.

## 결정

1. **품질 우선 선정**: EffectGraph 컴파일러와 플래너 계열 선정에는 `minVisualQuality` 품질
   바닥선을 지원한다. 측정된 품질이 바닥선 미달인 후보는 속도와 무관하게 탈락하고, 미측정 후보는
   측정 통과 후보가 없을 때만 폴백으로 남는다(증거 우선). 손맛·필압 정밀함은
   tests/visual/pressure-fidelity.test.ts(압력 램프 상관·양자화 점프·역행 게이트)가 회귀를 막는다.
2. **차세대 엔진 리스크 수용**: 성숙도(maturity)가 'candidate'라는 이유만으로 Vello 계열을
   프로덕션 레인 후보에서 배제하지 않는다. 채용 조건은 성숙도 라벨이 아니라 (a) 품질 게이트 통과,
   (b) 폴백 체인 존재, (c) capability probe로 불안정 구간 라우팅 — 세 가지다.
3. **Vello CPU 승격**: reference 전용에서 벡터 island의 preview 생산 레인 후보로 승격한다
   (previewQuality production). 결정적 출력 특성은 그대로 export/복구 레인의 기준선이다.
4. **Vello GPU(Classic/Hybrid) 검증 최우선**: 다음 반복에서 네이티브(wgpu Metal) 실렌더 검증과
   WebGPU wasm 어댑터 PoC를 진행한다. 실패해도 기능을 숨기지 않고 CPU/CanvasKit 폴백이 받는다.

## 결과

- 빠르지만 품질 미달인 후보가 심미 레인을 차지할 수 없다(테스트로 고정).
- Vello 계열 도입이 성숙도 라벨에 블로킹되지 않고 게이트·폴백 구조로 관리된다.

## 재검토 조건

- Vello GPU 검증에서 품질/안정성 게이트를 반복적으로 통과하지 못할 때(폴백 고정 재검토).
- 상류 Vello가 안정 릴리스를 선언할 때(성숙도 재평가).

# 2D 이미지 로딩 복구와 문자 없는 배경 필터 — 2026-09-06

PR #783 후속 변경이다. 신규 이미지 원본은 0개이며 기존 원본 수·추천 수·권리 상태를 변경하지 않는다.

## 변경

- 목록 카드와 확대 미리보기에서 같은 이미지 준비 상태 관찰자를 사용한다. `decoding="async"` 힌트와 실제 `decode()` 성공을 구분하여 디코딩이 완료되기 전 삽입을 차단한다. decode 미지원 환경에서는 정상적인 자연 크기를 검증한다.
- 로드 또는 디코딩이 20초 동안 완료되지 않으면 재시도 가능한 오류로 전환한다. 화면 밖의 lazy 이미지는 사용자 스크롤 전까지 시간 초과로 처리하지 않는다.
- 원본 URL/검수 크기/재시도 번호로 준비 상태를 구분한다. 같은 ID의 벡터 교체, 이전 요청의 지연 성공·실패, 컴포넌트 해제 후 결과가 새 이미지 삽입을 승인하지 못한다.
- 캐시에서 이미 로딩된 이미지와 `complete=true`인 손상 이미지도 구분한다. 타이머, 이벤트 수신기, 가시성 관찰자를 해제한다.
- 원본 크기 불일치도 미리보기에서 다시 불러올 수 있다. 재시도 시 실제 픽셀 정보와 확대 보기 상태를 초기화하되, 불일치가 계속되면 삽입 차단을 유지한다.
- `문자·간판 없는 이미지 배경만`을 인물 유무·장르·해상도 필터와 조합한다. 검수 메타데이터가 없는 원본과 벡터를 문자 없는 이미지라고 추정하지 않는다. 필터 초기화 및 스크롤 초기화에도 포함한다.

## 검증

로컬에서 실제 TypeScript 컨트롤러의 타입을 제거해 실행한 Node 테스트 13개가 통과했다. 이는 실제 브라우저 또는 React 컴포넌트 테스트를 대신하지 않는다. 6개 변경 TS/TSX 모듈의 변환 구문 검사도 통과했지만 프로젝트 전체 타입 검사가 아니다.

추가 React 회귀 테스트 7개는 디코딩 대기·실패, 미리보기 시간 초과·재시도, 크기 불일치 복구, 동일 ID 벡터 교체, 문자 필터·초기화·미확인 원본 제외를 검사한다. CI는 기존 컴포넌트/배치/원본 검사와 이 테스트들을 함께 실행하며, 결과 artifact를 확인해야 최종 통과로 판단할 수 있다.

기존 Chromium smoke는 64개 장면·페이지네이션·원본 디코딩·모달·포커스·삽입 비율을 다시 검증한다. 운영 배포 또는 모든 편집기 기능 전수 검증으로 주장하지 않는다.

# 웹툰 캐릭터 운세 · 창작 놀이터 · 모션 컷

## 구현

기존 오리지널 캐릭터 아라·단우·레오나·가온을 공통 진행자로 재사용한다. 29종 운세의 기본 읽기를 웹툰 컷으로 통일하고, 캐릭터의 도입/해설과 동료의 리액션을 원래 계산 결과 주변에 배치한다. 해석 원문, 타로 카드, 상세 리포트, 보관함은 유지한다. 캐릭터 변경은 계산 결과를 바꾸지 않는다.

리액션 끄기, 글자 확대, 기기의 동작 줄이기, 기존 키보드/터치 이동을 지원한다. 오늘의 운세가 첫 진입 버튼이며 캐릭터 선택은 URL의 허용된 cast 값으로 운세와 놀이터 사이에서 유지된다.

놀이터에는 게임별 캐릭터 도움말, 운세→모션 컷→스튜디오 이동, 새 모션 컷 실험실을 추가했다. 스튜디오 링크는 화면 이동이며 이미지/대사를 스튜디오 문서로 가져오는 기능은 아니다.

모션 컷은 클로즈업/가로 이동/반전 공개/호흡 연출 4종, 5초 단발 재생, 일시정지/재시작/슬라이더 탐색, 60자 말풍선, 효과음 문자 표시, PNG 정지 장면 저장(960×600)을 제공한다. AI 동영상 생성, 캐릭터 관절 애니메이션, MP4/GIF 내보내기는 포함하지 않는다.

PNG/JPEG/WebP 파일만 받으며 8MB 제한과 파일 시그니처를 확인한다. 디코딩 후 1600만 화소 제한을 확인하고 긴 변을 최대1600px로 축소해 PNG로 다시 인코딩한다. 원본 파일을 수정하지 않는다. 취소/시간초과/디코딩 오류 및 object URL 해제를 처리한다.

## 개인정보와 비용

새 캐릭터 연출과 모션 기능은 외부 AI/유료 API를 호출하지 않는다. 기존 레거시 캐릭터 운세 API 화면의 동작/비용 정책은 변경하지 않았다. 새 패키지 의존성이나 배포 설정 변경이 없다.

운세에서 놀이터로 보내는 값은 game, cast, mood 세 가지이며 입력/해석 원문을 보내지 않는다. 모션 이미지와 대사는 메모리에만 유지되고 화면을 나가면 초기화된다. PNG 저장과 완성 기록은 사용자가 직접 누른 경우에만 실행한다. 완성 기록에는 이미지나 대사를 넣지 않는다. 기존 놀이터 방문 이력 정책은 유지한다.

자동 재생/반복 재생을 하지 않는다. 숨겨진 탭과 동작 줄이기 설정에서 정지하고 자동 재개하지 않는다. 동작 줄이기 상태에서도 수동 슬라이더로 정지 장면을 선택할 수 있다.

## 재현

정상 설치된 워크스페이스에서 pnpm run typecheck, pnpm run validate:architecture, pnpm run build:bundle을 실행한다. pnpm11이 공유 node_modules 링크를 재설치하려는 로컬 환경에서는 설치된 바이너리를 직접 사용하거나 pnpm_config_verify_deps_before_run=false 환경 변수를 해당 명령에만 지정했다. Git commit/push 검증 훅은 유지한다.

개발 서버 실행 후 CHARACTER_BASE_URL=http://127.0.0.1:5347 node e2e/webtoon-character-experience-smoke.mjs, FORTUNE_BASE_URL=http://127.0.0.1:5347 node e2e/fortune-cinematic-smoke.mjs로 재현한다. 증거 파일은 임시 폴더 toon-character-evidence / toon-character-existing-regression에 저장한다. 배포를 실행하지 않는다.

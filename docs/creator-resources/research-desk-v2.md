# ToonStudio Research Desk V2

작성일: 2026-09-09  
대상: `/research`

## 문제 정의

기존 리서치 데스크는 목적형 검색, 로컬 저장 보드, 출처·조회일 점검, Story Lab/Publishing/Studio 전환을 이미 제공한다. 하지만 실제 창작 리서치에서는 다음 문제가 남는다.

1. 여러 검색을 반복하면 처음 세운 핵심 질문과 제약이 흐려진다.
2. 한 검색 경로의 결과만 보고 조사를 끝내기 쉽다.
3. 자료 수는 보여도 어떤 종류의 근거가 비어 있는지 바로 알기 어렵다.
4. 최근 사용한 검색어와 경로를 다시 조합하기 어렵다.
5. 키보드 중심의 빠른 재탐색과 긴 페이지 내 이동 비용이 크다.

V2는 새로운 통합 검색 API나 자동 사실 판정을 만들지 않고, 기존 권위 경계 위에 **질문 고정 → 경로 선택 → 교차 확인 → 공백 진단 → 기획·제작 전환**을 강화한다.

## 벤치마크에서 채택한 패턴

- Perplexity Spaces 계열의 `주제·지침·검색 기록을 한 작업 맥락에 묶는 방식`은 리서치 이름, 핵심 질문, 제약, 최근 검색으로 축소 적용한다.
- Milanote와 Are.na의 `수집 전에 맥락을 만들고, 저장한 자료를 다시 연결하는 방식`은 조사 렌즈와 교차 탐색 계획으로 적용한다.
- Raindrop.io 계열의 `컬렉션 상태와 정리 필요 항목을 드러내는 방식`은 근거 공백 지도와 조회일·이용조건 신호로 적용한다.
- 명령 팔레트와 전문 편집기의 키보드 패턴은 `⌘/Ctrl+K`, `/`, 검색 경로 화살표 이동, `Esc` 초기화로 적용한다.

추천 피드, 참여도 순위, 자동 품질 점수, 무제한 캔버스는 ToonStudio 리서치의 출처·권리·제작 전환 목적과 맞지 않아 도입하지 않는다.

## 사용자 경험

### 1. 버전이 분리된 로컬 리서치 세션

새 저장 키 `toonstudio:research-desk:v1`은 기존 `CreatorWorkspace`와 분리된다.

- 리서치 이름: 최대 80자
- 핵심 질문: 최대 180자
- 시대·장소·제약: 최대 240자
- 조사 렌즈: 장면·공간, 인물·복식, 소품·기술, 작품·판본, 공모·지원
- 최근 검색: 최대 8개, 동일 경로·동일 정규화 검색어는 최신 1개만 유지
- 전체 JSON: 32 KiB 상한, 버전과 열거형 검증, 잘못된 항목 제거

계정 동기화나 공동 편집을 지원하는 것처럼 표시하지 않는다. `storage` 이벤트로 같은 브라우저의 다른 탭 변경만 반영한다.

### 2. 조사 렌즈

조사 렌즈는 사용자의 목표를 명시하고 해당 목표에 적합한 기본 검색 경로, 질문 예시, 제약 예시, 검색어 예시를 제공한다. 렌즈는 추천 알고리즘이 아니라 고정된 편집 템플릿이다.

### 3. 교차 탐색 계획

유효한 검색어가 입력되면 다음 세 경로를 동시에 보여준다.

- 시각 레퍼런스
- 글로벌 판본
- 작가 기회

버튼을 누르기 전에는 네트워크 요청을 하지 않는다. 선택한 전용 페이지로 기존 공유 가능한 `q`와 `page=1` URL을 전달한다.

### 4. 근거 공백 지도

저장된 로컬 자료와 사용자가 직접 작성한 항목에서만 다음 여섯 축을 계산한다.

- 시각 레퍼런스
- 작품·판본 맥락
- 제공처 다양성
- 이용조건·조회일
- 이야기 전환
- 제작·제출 점검

각 축은 `근거 확보`, `보완 필요`, `아직 없음` 중 하나로 표시한다. 이 분류는 작품 품질, 사실 정확성, 저작권 허가를 판정하지 않는다.

### 5. 재탐색과 페이지 이동

- `⌘/Ctrl+K`: 어느 위치에서든 검색 입력으로 이동
- `/`: 입력 요소 밖에서 검색 입력으로 이동
- 검색 경로 버튼의 `←/→`, `Home`, `End`: 경로 이동
- `Esc`: 현재 검색어 초기화
- 최근 검색 버튼: 검색 경로와 검색어 복원
- 빠른 이동 내비게이션: 질문, 작업 상태, 근거 공백, 목적별 도구, 저장 보드, 내보내기

모든 조작은 버튼·링크·라벨이 있는 기본 HTML 인터랙션을 사용하며 포인터 전용 동작을 추가하지 않는다.

### 6. 리서치 브리프

기존 Markdown 브리프에 선택적으로 다음 내용을 추가한다.

- 리서치 이름
- 조사 렌즈
- 핵심 질문
- 시대·장소·제약
- 최근 검색 경로 최대 8개

기존 호출자는 컨텍스트를 전달하지 않아도 동일하게 동작한다. 기존 자료·기획서 JSON 백업 스키마는 변경하지 않으며, UI에 세션 메모가 JSON 백업에는 포함되지 않는다고 명시한다.

## Authority / schema

- 외부 데이터 권위: 기존 Met, Open Library, openBD, Kakao, BizInfo 전용 검색 페이지와 원문
- 창작 자료 권위: 기존 `CreatorWorkspace` 버전 1
- 새 UI 세션 권위: 브라우저 `localStorage`의 `toonstudio:research-desk:v1`
- 세션은 자료, 권리, 마감, 사실 관계를 덮어쓰지 않는다.
- 데이터베이스, API, 인증, 계정 스키마 변경 없음
- 기존 저장 보드 200개 상한, 백업 파서, 동시 저장 로직 변경 없음

## Failure and recovery

- 세션 JSON이 손상되거나 버전이 다르면 기본 세션으로 시작하고 오류를 표시한다.
- 저장소 접근이 거부되면 현재 탭 상태는 유지하고 저장 불가 상태를 표시한다.
- 다른 탭에서 유효한 세션이 변경되면 `storage` 이벤트로 반영한다.
- 검색어가 2~80자 범위를 벗어나면 이동하지 않고 오류를 표시한다.
- 세션 초기화는 창작 보드와 Story Lab/Publishing 상태를 삭제하지 않는다.
- 기존 자료·기획서 복원은 기존 확인 절차와 1 MB 입력 제한을 유지한다.

## 성능 경계

- 세션은 최대 32 KiB, 기록은 8개로 제한한다.
- 근거 공백 지도는 이미 메모된 작업공간 요약만 사용한다.
- 교차 탐색은 링크 계획만 계산하며 사전 요청을 발생시키지 않는다.
- 제공처 상태는 기존과 동일하게 상세 영역을 열 때만 마운트한다.
- 저장 보드는 기존 12개 점진 렌더링을 유지한다.

## 검증

- 세션 JSON 버전·크기·문자열·열거형·기록 상한 검증
- 동일 검색 중복 제거와 최신 순서
- 조사 렌즈의 기본 경로
- 근거 공백 여섯 축의 빈 상태·확보·보완 분류
- 기존 다음 행동과 검색 URL 회귀
- 컨텍스트가 없는 기존 브리프와 컨텍스트가 있는 확장 브리프
- 리서치 초점 저장, 키보드 검색 포커스, 교차 경로 이동, 최근 검색 복원
- 기존 빈 상태, 저장 보드 필터·삭제, 내보내기, 백업 합치기, 제공처 지연 마운트

## Rollback

V2는 새 파일과 `/research` 조립 변경에 한정된다. 문제가 발생하면 `CreatorHubPage`에서 V2 컴포넌트를 제거하고 기존 명령 영역으로 되돌린 뒤, 새 `toonstudio:research-desk:v1` 키는 읽지 않으면 된다. 기존 `CreatorWorkspace`와 서버 계약에는 마이그레이션이나 롤백 작업이 없다.

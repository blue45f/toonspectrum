# Studio Asset OS 기반 1차 구현 — 2026-09-07

## 목적

이 변경은 흩어진 Studio 소재를 한 화면에서 찾고 기존의 검증된 삽입 경로로 연결하는 첫 vertical slice다. 장기 Asset OS의 전체 범위(스마트 변형, 연결 인스턴스, 세계관 팩 제작, AI 후보·부분 편집, 유료 마켓)를 한 번에 완료한 것으로 해석하지 않는다.

## 실제 제품 배선

`StudioAssetToolPopoverWorkspace`가 에셋 그룹의 지연 로딩 진입점이다. 기존 메뉴는 그대로 보존하고 `menu === "asset"`일 때만 새 통합 작업 공간을 렌더한다. 나머지 템플릿·콜라주·요소·이메레스·장면·클립·효과 탭은 기존 `StudioAssetToolPopoverBody`가 계속 소유한다.

통합 탐색은 다음 카탈로그를 읽기 전용 어댑터로 합친다.

- 2D 래스터·벡터 배경
- 장면 템플릿
- Studio 벡터 요소
- BG3D 프리미티브·VRM 소품·3D 장면 템플릿
- 사용자의 로컬 에셋

검색 결과는 별도의 가짜 삽입기를 만들지 않고 기존 핸들러를 호출한다.

| 결과 종류 | 실제 경로 |
| --- | --- |
| 2D 배경 | `addBgScene` |
| 장면 템플릿 | `addSceneTemplate` |
| 벡터 요소 | `addCatalogElement` |
| 3D 오브젝트 | `openStudioObjectInsert` |
| 내 에셋 | `addRenderedImage` |

기존 업로드·AI 생성·CC0·오리지널 무료 몰·Creator Pack·커뮤니티 마켓은 `보관함 · 마켓` 보기에서 그대로 사용할 수 있다.

## 검색·큐레이션

- 한국어 NFKC 정규화와 다중 토큰 AND 검색
- 학교/교실, 회사/오피스, 소품/오브젝트, 3D/입체, 밤/야간 등 기본 동의어 확장
- 범위 필터: 전체, Studio, 내 에셋
- 종류 필터: 전체, 장면, 요소, 3D, 내 에셋
- 검색하지 않을 때 장면·내 에셋·요소·3D를 라운드 로빈 방식으로 추천
- 정확한 제목, 제목 시작, 제목 포함, 키워드, 설명 순으로 가중치 부여
- 같은 안정 ID가 여러 섹션에 존재하면 최초 항목만 유지

## 권리·품질 정책

기존 2D manifest에서 `licenseStatus: unverified`인 래스터 배경은 삭제하지 않는다. 기존 문서 호환성을 유지하되 통합 추천에서는 `caution`으로 낮추고 `권리 미확인` 배지를 표시한다. 사용자가 명시적으로 검색하면 찾을 수 있다. 충분한 검증 에셋이 있는 기본 추천에서는 경고 항목을 우선 제외한다.

이는 권리 승인을 대신하지 않는다. 해당 원본은 증빙 확보 또는 신규 공식 에셋 교체 전까지 Featured로 승격할 수 없다.

## 접근성과 실패 처리

- 검색·범위·종류·보기 전환을 키보드 버튼으로 제공
- 거친 포인터에서 44px 조작 영역 유지
- 결과 수와 처리 결과를 live region으로 알림
- 결과 사용 중 중복 실행 차단
- 기존 핸들러가 실패하거나 `false`를 반환하면 오류 상태 표시
- 결과 없음에서 조건 완화 또는 동일 검색어를 AI 작업 공간으로 전달

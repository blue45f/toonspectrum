# 유사 브러시 정리 — 2026-09-02 적대적 검토 기록

오너 지시: "브러시 종류도 너무 비슷한 게 많다. 특징·엔진·질감을 고려해 비슷한 브러시를 정리·축소·병합."

이 문서는 그 지시에 대해 **무엇을 병합하지 않았고 왜인지**를 남긴다. 병합은 되돌리기 어렵고
(저장 문서의 id 별칭, CRDT 허용 목록, 변형 그룹 매니페스트가 모두 id 를 참조), 검토 결과가
"이름이 메커니즘을 숨기고 있었다"로 수렴했기 때문이다.

## 절차

1. 카탈로그 인벤토리(330 등록 / 191 노출 = 189 채색 + 2 지우개 / 139 격리)를 미디어 패밀리별로
   나누고, 패밀리마다 같은 엔진 레인·캐리어·수치(간격·산란·경도·타원비·그레인·flow·필압 곡선)를
   공유하는 후보를 찾았다. 톤 프로브(`tests/benchmarks/harness/brush-interior-tone-probe.ts`)로
   실측했다.
2. 후보 10개 클러스터마다 **별도의 검토자가 삭제 대상 브러시를 변호**했다: 다른 렌더 분기가 있는가,
   필압·기울기·속도 응답이 다른가, 상류(MyPaint/Krita) 검증 임포트인가, 저장 문서·별칭·테스트가
   id 를 참조하는가, 노출 유일성 게이트를 깨는가.
3. 병합 승인 0건. 대안(이름 변경·재그룹·격리)을 실행했다.

기존 메커니즘을 그대로 썼다: 노출 유일성은 `studio-brush-listed-uniqueness.ts`(실행 서명 +
팩 팁 풋프린트), 숨김은 `studio-brush-quarantine.ts`(사유 원장, 노출만 제거·id 보존).
이미 두 차례 축소(234 → 189 채색)가 끝난 상태였다.

## 남은 관찰 → 같은 날 후속 판정

- `pencil--side-shade`: 평평한 무질감 획(distinctTones 1)의 원인은 렌더러가 선언된 변형으로 분기하지 않아
  기본 연필의 단일 패스를 폭 10 으로 칠한 것. 별칭 프로필(넓은 치마 + 옅고 거친 코어)을 주어 해소.
- `velvet-charcoal`: "단일 톤 27.3" 은 팩 프리셋을 핀하지 못하는 톤 프로브의 오측. 브라우저 장획 프레임은
  부드러운 목탄 질감을 보여 결함 아님으로 재판정.
- `dry-rake`: 간격비 0.3555 는 형제 레이크(0.11~0.12)의 3배 — 강모 열 스탬프가 낱개 막대로 떨어져 울타리로
  보였다. 형제 레이크 케이던스(0.11)로 조정.
- 팩 노출 유일성 키는 spacing·scatter·hardness·grain·flow 를 보지 않는다(팁 풋프린트만). 49개 프로
  텍스처/패턴 id 가 ink-particle + dry-media 두 런타임에 몰려 있어 "비슷하다"는 인상의 원천이다.
  다음 축소 회차는 이 키에 수치 버킷을 더하는 쪽이 맞다.
- 유화 리본 격자(6행)와 형광펜 3종은 피커에서 **한 패밀리 행 + 하위 선택기**로 접는 것이 실제 해법이다
  (변형 그룹 매니페스트는 이미 있다). id 는 그대로 둔다.

# ToonStudio 메뉴 정보 구조 최적화

- 기준일: 2026-09-05
- 범위: 데스크톱 애플리케이션 메뉴, 생성 모드 ToolBelt, 키보드·접근성 계약
- 원칙: 기능 삭제 없이 명령 소유권과 노출 순서만 재구성

## 1. 발견한 문제

기존 카탈로그 18개 그룹은 기능 인벤토리로는 정확했지만, 12개 상단 제목으로 접는 과정에서 작업 목적과 제품 내부 분류가 충돌했다.

- `선택`과 `변형`이 `편집`에서 떨어져 있었다.
- `캔버스`와 `창`이 `보기`에서 떨어져 있었다.
- `애니메이션`이 페이지·스토리 제작을 담당하는 `만화`와 떨어져 있었다.
- `도구`가 캔버스, 변형, 애니메이션, 3D, 협업, AI를 함께 담아 가장 큰 혼합 메뉴가 됐다.
- 52개 필터는 내부 패밀리 캡션이 있었지만 AI와의 상위 관계가 명확하지 않았다.
- 생성 ToolBelt에서 텍스트·말풍선·이미지 삽입이 AI와 3D 뒤에 있어, 수평 스크롤 환경에서 기본 제작 동작이 늦게 나타났다.

## 2. 최종 상단 메뉴

| 순서 | 제목 | 소유하는 카탈로그 그룹 | 사용자 목적 |
|---:|---|---|---|
| 1 | 파일 | 파일, 협업 | 저장·가져오기·내보내기·공유·검토 |
| 2 | 편집 | 편집, 선택, 변형 | 되돌리기·클립보드·선택·변형 |
| 3 | 보기 | 보기, 캔버스, 창 | 배율·가이드·문서 화면·작업공간 |
| 4 | 삽입 | 텍스트, 벡터, 3D | 말풍선·문자·도형·3D 참조/콘텐츠 |
| 5 | 레이어 | 레이어 | 구조·순서·마스크·비파괴 편집 |
| 6 | 그리기 | 그리기 | 펜·지우개·채우기·브러시·톤 |
| 7 | 만화 | 만화, 애니메이션 | 페이지·스토리·스크롤·프레임 |
| 8 | 효과 | 필터, AI | 보정·필터·생성 보조·연동 |
| 9 | 도움말 | 도움말 | 검색·용어·튜토리얼·진단·복구 |

상단 제목은 12개에서 9개로 줄지만 명령 행은 하나도 삭제하지 않는다. 각 원본 그룹은 드롭다운 안에서 독립된 캡션과 `role="group"`을 유지한다.

## 3. 메뉴 표면별 소유권

### 애플리케이션 메뉴

문서 전체나 선택 대상에 적용되는 범용 명령, 설정, 패널 열기, 가져오기·내보내기를 소유한다. 도구 선택을 중복 제공할 수는 있지만, 직접 조작의 주 진입점은 아니다.

### 좌측 Tool Rail

선택, 펜, 지우개, 채우기, 도형, 텍스트처럼 캔버스에서 바로 사용하는 도구를 소유한다. 상단 메뉴보다 빠른 1클릭 진입점이다.

### 생성 ToolBelt

작업 흐름 순서로 노출한다.

1. 에셋
2. 컷 배치
3. 모바일 그리기 도구
4. 텍스트·말풍선·이미지 삽입
5. 3D·참조
6. 배경·톤
7. 스타일
8. AI
9. 보조 유틸리티

삽입을 AI 뒤에서 그리기 바로 뒤로 이동해 기본 제작 동작이 전문 도구보다 먼저 보이게 한다.

### 인스펙터

현재 선택한 페이지, 프레임, 레이어, 벡터, 텍스트, 3D 객체의 속성만 소유한다. 문서 전역 명령이나 패널 열기는 인스펙터에 새로 중복하지 않는다.

### 명령 검색·Quick Deck

물리적 메뉴 위치와 무관한 두 번째 탐색 축이다. 기존 command id를 유지하므로 재배치 후에도 검색, 단축키, 최근 사용, 도움말 링크가 깨지지 않는다.

## 4. 명명 규칙

- 제목은 명사형 한 단어를 우선한다.
- 행은 `대상 · 동작` 또는 익숙한 제품 용어를 사용한다.
- 메뉴 제목과 같은 첫 섹션도 생략하지 않는다. 뒤따르는 섹션과 경계를 만들고 스크린리더가 출처 그룹을 알 수 있기 때문이다.
- `효과` 내부에는 `필터`, `AI` 캡션을 별도로 표시해 자동 효과와 전통 필터를 혼동하지 않게 한다.
- 새 기능은 구현 모듈이 아니라 사용자의 목표에 따라 소유 메뉴를 정한다.

## 5. 안정성 계약

- 기존 command id, menu item id, 핸들러와 로컬라이제이션 키를 변경하지 않는다.
- 흡수된 모든 그룹의 행 수와 순서를 보존한다.
- 그룹 경계에만 구분선을 추가하고 그룹 내부 구분선은 유지한다.
- 알려지지 않은 미래 그룹은 버리지 않고 `도움말` 직전에 임시 노출한다.
- 메뉴바는 WAI-ARIA `menubar`와 단일 roving tab stop을 유지한다.
- 합성 메뉴의 캡션은 장식 텍스트가 아니라 접근 가능한 `role="group"` 이름이다.
- 화살표 키는 섹션 경계를 넘어 하나의 평면 명령 목록처럼 이동한다.
- 브라우저 검증은 9개 제목, 모든 대표 명령, 섹션 캡션, 참고 창 토글, 메뉴 연동 팝오버를 검사한다.

## 6. 후속 기능 배치 기준

- 저장·공유·승인·버전: `파일`
- 선택 범위와 기하 변형: `편집`
- 화면 표시·가이드·패널·작업공간: `보기`
- 캔버스에 새 객체를 만드는 기능: `삽입`
- 객체 스택과 비파괴 속성: `레이어`
- 획·채색·브러시: `그리기`
- 페이지·대본·연속성·타임라인: `만화`
- 픽셀/색상 처리와 생성형 보조: `효과`
- 진단·학습·명령 검색: `도움말`

이 기준으로 분류되지 않는 기능은 상단 제목을 새로 만들기 전에 명령 검색과 상황별 인스펙터 배치를 먼저 검토한다.

# 창작 레퍼런스 아틀라스

`/research/assets`는 The Metropolitan Museum of Art Collection API의 공개 미술 자료를 웹툰 장면 설계에 맞게 탐색하는 작업 화면이다.

## 사용자 흐름

1. 장면 목적 프리셋 또는 직접 검색으로 시작한다.
2. 작품명, 주제 태그, 제작자·문화권 검색 범위를 고른다.
3. Met 부서, 재료·유형, 지역, 제작 연대, 대표작 여부를 서버 검색 조건으로 적용한다.
4. 현재 페이지의 검증된 결과를 부서·문화권·분류로 다시 좁히고 제목·연대로 정렬한다.
5. 상세 보기에서 고해상도 이미지, 치수, 재료, 태그와 출처를 확인한다.
6. 최대 네 작품을 비교한 뒤 연구 보드에 저장하고 Markdown 또는 JSON으로 내보낸다.

검색 조건과 결과 보기 상태는 URL 쿼리에 보존되므로 새로고침과 링크 공유 후에도 동일한 탐색 맥락을 복원한다. 최근 검색은 브라우저 로컬 저장소에 최대 여섯 개만 보관한다.

## 데이터·권리 경계

- 검색은 `/public/collection/v1.1/search`의 페이지네이션을 사용한다.
- 상세 데이터의 `isPublicDomain`이 명시적으로 `true`이고 `rightsAndReproduction`이 비어 있는 작품만 후보가 된다.
- 미리보기·고해상도·추가 이미지는 `images.metmuseum.org` HTTPS 주소만 보존한다.
- 브라우저 계약 파서는 API 응답과 로컬 저장 데이터를 동일하게 재검증한다.
- CC0 표시는 작품 이미지 이용 조건의 근거이며 인물, 상표, 문화재 맥락 등 별도 권리 검토를 대체하지 않는다.

## 검색 파라미터

| 화면 | API | 규칙 |
| --- | --- | --- |
| 검색 범위 | `field` | `all`, `title`, `tags`, `artistCulture` |
| 큐레이터 부서 | `departmentId` | 공식 부서 ID만 허용 |
| 재료·유형 | `medium` | 2~80자 |
| 지역 | `geoLocation` | 2~80자 |
| 제작 연대 | `dateBegin`, `dateEnd` | 두 값을 함께 전달, -10000~3000 정수 |
| 대표작 | `isHighlight` | `true` 또는 `false` |

서버는 잘못된 검색 범위, 배열형 쿼리, 미등록 부서, 한쪽만 있는 연대, 역전된 연대를 외부 요청 전에 거부한다.

## 회귀 검증

`tests/reference-assets.test.ts`는 다음 계약을 검증한다.

- URL 검색·보기 상태 왕복
- 연대·부서·검색 범위 입력 검증
- 장면 목적 프리셋의 독립성
- 결과 내 검색, 패싯, 정렬, 비교 상한
- Met 메타데이터와 이미지 호스트 정제
- v1.1 검색 필터 전달 및 풍부한 상세 응답
- 잘못된 필터가 업스트림 호출 전에 차단되는지 여부

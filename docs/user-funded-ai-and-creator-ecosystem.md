# 무료 우선 AI와 창작 생태계 작업대

작성일: 2026-09-14
최종 갱신: 2026-09-16

## 제품 원칙

- 텍스트 AI는 결제가 비활성화된 공용 무료 풀을 먼저 사용하고, 무료 한도 또는 요청 제한이 추론 전에 확인된 경우에만 다음 무료 경로로 이동한다.
- 공용 풀 다음에는 사용자가 등록한 무료 티어 API 키 또는 로컬·직접 운영 AI를 사용한다. 유료 모델이나 운영측 유료 폴백은 선택하지 않는다.
- 공용 키는 서버 비밀로만 보관하며 브라우저 번들, API 응답, 로그, 작품 파일에 포함하지 않는다.
- 개인 텍스트 키는 기본적으로 현재 문서 메모리에만 두고, 사용자가 선택할 때만 암호화된 로컬 보관함에 저장한다.
- Hyper3D/Rodin 키와 개인 Creator Runtime 토큰은 통합 설정의 현재 탭 저장소에서 관리하며 서버 DB·작품 파일·로그에 저장하지 않는다.
- 영상·2D↔3D 변환은 사용자가 운영하는 Creator Runtime에 브라우저가 직접 연결한다.
- AI 미설정 또는 전체 무료 한도 소진 상태에서도 샘플, 장면 팩, 학습, 검수, 연속성, 수동 번역 입력, 베타 독자, 과정 갤러리는 동작한다.

## 통합 설정

`/settings/ai`가 AI 연결의 정본 사용자 표면이다. 기존 `/studio/ai-settings` 경로와 Studio 내부 진입점도 같은 `UnifiedAiSettings` 소유자를 렌더링하므로 별도의 키 입력 상태를 만들지 않는다.

한 화면에서 다음을 관리한다.

1. 공용 무료 텍스트 AI 풀의 활성 상태와 공급자 순서
2. 개인 무료 티어·OpenRouter 무료 모델·로컬·직접 운영 AI 연결
3. 텍스트·이미지·추론·3D 기능별 개인 폴백 연결
4. Hyper3D/Rodin 사용자 키
5. 개인 Creator Runtime 주소, 토큰, 작업 소유자 ID
6. 선택형 암호화 로컬 보관함

개별 생성·번역·3D 화면은 키 입력 폼을 소유하지 않고 통합 설정의 현재 연결만 참조한다.

## 텍스트 AI 라우팅

기본 순서는 다음과 같다.

1. 공용 Gemini 무료 티어
2. 공용 Groq 무료 티어
3. 공용 SambaNova Free Tier
4. 공용 Cloudflare Workers AI의 Workers Free 일일 할당량
5. 공용 Mistral Free mode
6. 공용 OpenRouter 무료 라우터
7. 사용자가 명시적으로 선택한 개인 무료 연결
8. 나머지 유효한 개인 연결: Gemini → Groq → SambaNova → Cloudflare Workers AI → Mistral → OpenRouter → 로컬·직접 운영 서버

외부 제공자의 `402` 또는 `429`, 또는 브라우저의 로컬 무료 안전 한도 소진처럼 추론 전 무료 용량 거절이 명확할 때만 다음 경로를 시도한다. 네트워크 오류, 타임아웃, `5xx`, 인증 실패, 잘못된 응답에는 같은 프롬프트를 다른 공급자로 자동 재전송하지 않는다.

모든 무료 경로가 소진되면 개인 무료 키·로컬 AI 연결 또는 제한 해제 후 재시도를 안내한다. 대체 경로가 없으면 해당 AI 기능은 사용할 수 없는 상태로 남는다.

## 비용·보안 경계

- 공용 무료 풀은 `STUDIO_AI_FREE_POOL_ENABLED=true`, 서버 전용 키, 공급자별 `STUDIO_AI_FREE_*_CONFIRMED=true`가 모두 있어야 활성화된다.
- `CONFIRMED` 값은 운영자가 결제 비활성 또는 공급자 측 무료 전용 경계를 직접 확인했다는 배포 승인이다.
- SambaNova는 결제수단이 연결되지 않은 Free Tier, Mistral은 카드 없는 Free mode에서만 승인한다.
- Cloudflare는 Workers Free 계정, 32자리 16진수 Account ID, 해당 경로에서 AI Gateway 통합 결제·선불 크레딧 미사용, 유료 전용 차단 목록에 없는 `@cf/` 모델 조건을 모두 만족해야 승인한다.
- OpenRouter 공용·개인 연결은 `openrouter/free` 또는 `:free` 모델만 허용한다.
- 공용 텍스트 호출은 로그인 사용자별·서비스 전체 PostgreSQL UTC 일일 한도로 제한하며 저장소 장애 시 호출 전에 닫힌다.
- 개인 관리형 무료 연결에는 브라우저 로컬 요청·예약 토큰 한도와 회로 차단기를 적용한다.
- 이미지·영상·3D는 공용 텍스트 풀을 사용하지 않는다. 로컬·직접 운영 서버 또는 사용자가 명시적으로 연결한 개인 통합만 허용한다.
- 연결 테스트와 개인 공급자 생성 비용은 사용자 계정에 발생할 수 있으므로 결제수단과 유료 폴백이 비활성화됐는지 사용자가 확인해야 한다.

## 서버 API 경계

- `POST /api/studio-ai/chat`은 공용 무료 풀이 배포 승인된 경우에만 로그인 사용자에게 열린다. 풀이 비활성·미구성·소진 상태이면 구조화된 오류와 `/settings/ai` 안내를 반환한다.
- `/api/studio-ai/inference/*`, `/api/studio-ai/media/*`, 서버 이미지 에셋 생성 경로는 운영측 유료 자격 증명으로 자동 실행하지 않는다.
- 3D 생성 API는 `X-Studio-3D-Provider-Key`가 없는 생성·진행·취소 요청을 거부한다. 서비스 환경변수의 공급자 키가 있어도 운영 환경에서는 사용자 키 없는 작업을 허용하지 않는다.
- 운세는 로컬 규칙과 직접 작성한 웹툰 콘티 폴백을 사용하며 운영측 Gemini 키에 의존하지 않는다.

이 경계는 AI 공급자·GPU 비용의 조용한 발생을 막기 위한 것이다. 웹 호스팅, DB, 트래픽, 파일 저장 등 일반 서비스 비용까지 0원을 보장하지는 않는다.

## 개인 Creator Runtime

브라우저 연결용 실행 예시:

```bash
cd services/creator-inference
export CREATOR_INFERENCE_TOKEN='32자 이상의 무작위 토큰'
export CREATOR_BROWSER_ORIGINS='https://www.toonstudio.cloud,http://localhost:5173'
uvicorn browser_app:app --host 0.0.0.0 --port 8000
```

- 와일드카드 CORS는 허용하지 않는다.
- 운영 도메인은 HTTPS exact origin으로 등록한다.
- 토큰은 URL이나 쿼리 문자열에 넣지 않는다.
- Runtime은 한 `CREATOR_DATA_DIR`당 단일 worker만 소유한다.
- 모델·GPU smoke test 성공은 작품 품질 보장이 아니므로 결과 파일을 검토한다.

## 창작 생태계 작업대

`/studio/ecosystem`은 기능 목록이 아니라 완결된 제작 흐름을 제공한다.

- 자체 샘플 작품 4종과 장면 팩 6종
- 저장·내보내기까지 확인하는 안내형 실습
- 원고 JSON preflight, 안전한 공백·중복 수정, 오류 재검사
- 회차별 캐릭터·의상·소품·장소 연속성 검사
- 원문 revision에 묶인 번역 초안·승인·stale 판정
- 텍스트 중심 베타 독자 패키지와 응답 가져오기
- 콘티·선화·채색·완성 과정 패키지
- 감상 장르를 자체 창작 과제로 바꾸는 연결

브라우저 저장 데이터는 버전·개수·문자열 길이·파일 크기를 제한하고, 손상된 항목은 신뢰하지 않는다. 작품 원본을 자동 수정하는 기능은 제목 공백과 중복 태그처럼 의미가 변하지 않는 항목에만 적용한다.

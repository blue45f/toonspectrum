# 무료 우선 클라우드 AI와 창작 생태계 작업대

작성일: 2026-09-14
최종 갱신: 2026-09-16

## 제품 원칙

- AI 추론은 관리형 공개 HTTPS 클라우드 API에서만 실행한다.
- localhost, 사설망, 로컬 LLM, 브라우저 모델 다운로드, 자체 GPU, 직접 운영 추론 서버를 AI 실행 경로로 사용하지 않는다.
- 텍스트 AI는 결제가 비활성화된 공용 무료 풀을 기본 자동 경로로 사용한다.
- 사용자는 공급자 하나에 여러 API 키와 여러 모델을 등록할 수 있다.
- 자동·내 우선순위·수동 고정 모드를 제공한다.
- 사용자 결제 BYOK는 기본 자동 폴백에 참여하지 않으며 사용자가 명시적으로 켠 경우에만 사용한다.
- 키는 메모리에 두고, 선택한 경우에만 암호화된 브라우저 보관함에 저장한다.
- 네트워크 오류·타임아웃·5xx처럼 결과가 모호한 실패는 다른 공급자에 재전송하지 않는다.

세부 라우팅·비용·보안 계약은 `docs/operations/free-ai-runtime.md`와 `docs/operations/cloud-ai-routing-benchmark-2026-09-16.md`를 따른다.

## 통합 설정

`/settings/ai`가 AI 연결의 정본 사용자 표면이다. Studio와 계정 설정의 모든 진입점은 같은 `UnifiedAiSettings`를 렌더링한다.

한 화면에서 관리하는 항목:

1. 공용 무료 텍스트 AI 풀 상태와 공급자 순서
2. 자동·내 우선순위·수동 고정 라우팅 모드
3. 연결별 우선순위와 활성 상태
4. 연결별 여러 API 키, 키별 우선순위와 활성 상태
5. 연결별 여러 모델, 모델별 기능·우선순위와 활성 상태
6. 텍스트·이미지·영상 추론·2D↔3D 기능별 정확한 수동 경로
7. 무료 경로 소진 뒤 사용자 결제 BYOK를 허용할지 여부
8. Hyper3D/Rodin 및 관리형 Creator Runtime 키
9. 선택형 암호화 브라우저 보관함

개별 생성·번역·3D 화면은 별도 키 입력 상태를 소유하지 않는다.

## 자동 무료 텍스트 경로

기본 순서는 Gemini → Qwen Beijing Free Quota Only → Groq → SambaNova → Z.AI Flash → Mistral → Cloudflare Workers AI → OpenRouter free → SiliconFlow free이다.

사용자는 이 순서를 바꿀 수 있다. 서버는 요청의 중복·알 수 없는 공급자를 거부하고, 누락된 기본 공급자는 뒤에 보완한다.

다음 조건에서만 다음 경로로 이동한다.

- `401`/`403`: 개인 키 인증이 추론 전에 거절됨
- `402`/`429`: 무료·결제·요청 한도가 추론 전에 거절됨
- 공급자별 allowlist에 등록된 무료 할당량 코드
- 앱의 무료 안전 한도 소진

네트워크 오류, 타임아웃, `5xx`, 응답 파싱 실패, 잘못된 성공 응답에는 재전송하지 않는다.

## 비용·보안 경계

- 공용 키는 서버 전용 비밀이다.
- 공용 무료 계정은 공급자별 `CONFIRMED=true` 승인이 필요하다.
- OpenRouter 무료 연결은 `openrouter/free` 또는 `:free` 모델만 사용한다.
- 개인 유료 BYOK는 별도 동의가 없으면 자동 경로에서 제외된다.
- 브라우저 무료 경로는 연결+모델+키 조합별 요청/토큰 한도와 회로 차단기를 가진다.
- 프롬프트·응답·API 키는 사용량 원장에 저장하지 않는다.
- 브라우저 요청은 쿠키를 보내지 않고 리다이렉트를 거부한다.
- 외부 공급자의 데이터 보존·학습 정책은 사용자가 확인해야 한다.

## 관리형 미디어·2D↔3D 런타임

영상·이미지·2D↔3D 서버 작업은 `STUDIO_MEDIA_CLOUD_API_URL`의 관리형 클라우드 런타임을 사용한다. URL은 공개 HTTPS origin이어야 하며 localhost, 사설망, URL 사용자정보, 경로, 쿼리, fragment를 거부한다.

브라우저 직접 연결 기능은 통합 설정의 관리형 Creator Runtime HTTPS 주소와 토큰을 사용한다. 파일 업로드·작업 생성·결과 다운로드는 같은 클라우드 런타임으로 제한하며 모호한 실패 뒤 다른 런타임으로 자동 재전송하지 않는다.

## 서버 API 경계

- `POST /api/studio-ai/chat`은 승인된 공용 무료 풀 또는 사용자가 등록한 클라우드 경로만 사용한다.
- `providerOrder`는 무료 공급자 allowlist, 길이, 중복 여부를 검증한다.
- 서버 사용량 원장은 사용자별·서비스 전체 UTC 일일 한도를 원자적으로 적용한다.
- 미디어 런타임 설정이 없거나 비공개 origin이면 요청 전에 닫힌다.
- 3D 외부 공급자 작업은 사용자 제공 키가 없는 경우 실행하지 않는다.

웹 호스팅, 데이터베이스, 트래픽, 파일 저장 등 일반 서비스 비용까지 0원을 보장하지는 않는다.

## 창작 생태계 작업대

`/studio/ecosystem`은 AI가 없어도 다음 핵심 제작 흐름을 유지한다.

- 자체 샘플 작품과 장면 팩
- 저장·내보내기 안내형 실습
- 원고 JSON preflight와 안전한 무의미 변경 수정
- 캐릭터·의상·소품·장소 연속성 검사
- revision에 묶인 번역 초안·승인·stale 판정
- 텍스트 중심 베타 독자 패키지와 응답 가져오기
- 콘티·선화·채색·완성 과정 패키지

AI 경로가 모두 unavailable이면 기능은 명확히 중지되며 로컬 모델 설치를 요구하거나 숨은 유료 경로를 호출하지 않는다.

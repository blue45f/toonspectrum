# Studio Smart Layout Auto Fix — 기능 갭과 구현 경계

작성일: 2026-07-28

## 결론

기존 ToonSpectrum에는 `studio-selection.ts`의 기본 정렬/중심 분포 계산과
`StudioPage`의 즉시 적용 명령이 있으나, 여러 편집 동작을 하나의 미리보기와
원자적 커밋으로 묶는 자동 레이아웃 계약은 없었다.

이번에 `studio-smart-layout-auto-fix.ts`를 별도 순수 모듈로 추가했다. 이 모듈은
UI나 렌더러를 직접 변경하지 않으며 다음을 하나의 결정적 계획으로 만든다.

- 선택 영역, 아트보드, 키 오브젝트를 기준으로 한 정렬
- 가로/세로 흐름 자동 판정과 가장자리 간 등간격 분포
- 대표 오브젝트 또는 명시한 오브젝트를 기준으로 한 동일 너비/높이
- 겹치지 않는 선택 노드 사이 커넥터의 직선·경계 접점 보정
- 미리보기, 정방향 패치, 역방향 패치를 동일 결과에서 제공
- 입력 순서와 무관한 정렬 및 동률 해소
- 잠금, 비정상 좌표, 누락된 연결점, 상충하는 작업, stale snapshot의 전체 거부
- 노드/선택/커넥터/포인트/패치/쌍 비교에 대한 사전 예산 제한

## 공식 제품 동작과의 대조

- [CLIP STUDIO PAINT 정렬/분포 공식 매뉴얼](https://help.clip-studio.com/ko-kr/manual_kr/360_transform/%EC%A0%95%EB%A0%AC__47_%EB%B6%84%ED%8F%AC___91_PRO__47_EX__93_.htm)은
  가장자리·중심 정렬, 분포, 등간격 분포와 오브젝트·캔버스·선택 영역·가이드를
  기준으로 삼는 동작을 설명한다. 이번 코어는 익숙한 가장자리/중심과
  오브젝트/캔버스 계열 기준을 수용하되, 아직 가이드 기준과 레이어 종류별
  픽셀/벡터 경계 선택은 포함하지 않는다.
- [Adobe Illustrator 정렬 및 분포 공식 문서](https://helpx.adobe.com/uk/illustrator/desktop/manage-objects/arrange-objects/align-and-distribute-objects.html)는
  선택 경계, 키 오브젝트, 아트보드를 기준으로 정렬하고 간격을 균등하게
  분포하는 동작을 제공한다. 이번 코어의 세 가지 기준 모델은 이 사용 습관을
  흡수할 수 있는 명시적 계약이다.
- [PowerPoint Auto Fix 공식 문서](https://support.microsoft.com/en-US/PowerPoint/align-your-content-quickly-and-easily-with-auto-fix)는
  선택 항목을 한 번에 정렬·동일 크기화·분포하고 커넥터를 곧게 만들며,
  겹치지 않는 두 개 이상의 요소에서 동작한다고 설명한다. 이번 코어는 같은
  조합 작업을 원자적 계획으로 만들고, 겹침 시 커넥터 보정만 안전하게
  생략한다.
- [Figma 정렬·위치·치수 공식 문서](https://help.figma.com/hc/en-us/articles/360039956914-Adjust-alignment-rotation-position-and-dimensions)는
  단일 레이어는 부모를, 복수 레이어는 서로 또는 부모/인스턴스 선택을
  기준으로 정렬하는 모델을 설명한다. 이번 코어는 문서 모델과 독립된
  reference 계약을 두어 이후 프레임/컴포넌트 부모 기준으로 확장할 수 있게
  했다.

위 동작은 공개 매뉴얼을 행동 명세로만 참고해 독립 구현했다. 경쟁 제품의
코드, 아이콘, 에셋, 비공개 형식은 복제하지 않았다.

## 기존 기능과 중복되지 않는 부분

| 항목 | 기존 `studio-selection.ts` | 신규 Smart Layout 코어 |
|---|---|---|
| 기준 | 선택 합집합 또는 단일 target | 선택/아트보드/키 오브젝트 명시 |
| 분포 | 3개 이상 중심점 분포 | 2개 이상 실제 가장자리 간격 분포 |
| 동일 크기 | 없음 | 너비/높이/둘 다, 결정적 대표 선택 |
| 복합 실행 | 명령별 계산 | 크기→정렬→분포→커넥터의 한 계획 |
| 미리보기/Undo | 호출부가 직접 처리 | 정방향·역방향 원자 패치 |
| 커넥터 | 없음 | 겹침 검사 후 경계-경계 직선화 |
| 방어 한계 | 별도 예산 없음 | 수량·포인트·패치·쌍 비교 예산 |
| 동시 편집 충돌 | 없음 | `before` 검증을 통한 stale 전체 거부 |

## 의도적으로 남긴 경계

- 축 정렬 사각형만 처리한다. 회전 OBB, 원근 변형, 벡터 경로 실제 외곽선,
  텍스트 픽셀 경계는 후속 geometry adapter가 필요하다.
- 커넥터는 선택된 두 노드를 잇는 단순 직선만 보정한다. 장애물 회피,
  직교 라우팅, 포트 우선순위는 별도 라우터의 책임이다.
- 그룹/프레임/컴포넌트 인스턴스의 살아 있는 제약, CLIP STUDIO의 가이드
  기준, Figma Auto Layout과 같은 지속 레이아웃은 아직 연결하지 않았다.
- UI는 이번 변경 범위에 포함하지 않았다. 후속 UI에서는 CLIP STUDIO
  사용자에게 익숙한 `정렬 기준` 명칭과 가장자리/중심 아이콘 순서를 유지하고,
  선택 직후 한 번에 미리보기할 수 있는 선택 런처 또는 Inspector 섹션으로
  연결하는 것이 적합하다.
- 현재 문서 모델과 연결하려면 각 레이어/말풍선/벡터/이미지의 실제 경계를
  `StudioSmartLayoutNode`로 변환하는 adapter와 단일 history transaction
  integration이 추가로 필요하다.

## 검증 범위

- 입력 순열에 무관한 동일 계획 및 ID 기반 동률 해소
- 선택/아트보드/키 오브젝트 기준
- 동일 크기, 교차축 정렬, 가장자리 등간격
- 커넥터 경계 접점, 겹침/잠금 시 생략
- 잠금·누락 endpoint·상충 축·부족한 기준 공간의 fail-closed 처리
- 쌍 비교/패치 예산 사전 거부
- 정방향 적용 후 역방향 패치로 원본 정밀 복구
- stale snapshot과 hostile getter의 원자적 거부

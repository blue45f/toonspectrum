## 다른 페이지와 하위 화면

공개 공통 히어로를 사용하는 11개 페이지에 각자 역할에 맞는 이미지를 전달했다. 소개·기술·워크플로·제품 원칙·도움말·커뮤니티 등의 기존 명도/구도 관찰 모드와 설명은 유지했다. 마켓·소재 검색·학습 홈도 반복 배경 대신 역할 설명 이미지를 사용한다.

`WorkspaceTaskFrame`의 일반 작업 안내와 `SiteCreationCompass`의 펼친 설명, `RoutePurposeScene`의 소개 이미지에 경로별 의미를 연결했다. 기존 경로 분류 권위를 재사용하고 AI·복구·커뮤니티는 더 구체적인 설명 이미지를 사용한다. 깊은 프로젝트의 대본·소재·검수·내보내기와 학습·커뮤니티 하위 경로도 함께 지원한다.

집중 편집기와 캔버스, 3D 장면, 검수 원고, 실제 사용자가 편집 중인 이미지 위에 소개 이미지를 삽입하지 않는다. 작업 안내의 작은 그림과 도구 자체의 사용자 콘텐츠를 구분한다. 인증·DB·환경변수·저장·게시·배포 동작은 수정하지 않았다.

## 제작 방식과 전송량

초기 도형 합성 시안을 보존하고, 역할별 **AI 생성 독립 아트 12종·36개 WebP**, 총 **1,372,398바이트**로 정본을 고도화했다. 3072×1280 시트 2장을 생성한 뒤 320×200/640×400/960×600으로 분리·최적화했다. 실제 모델은 `gpt-image-2`, 생성 2건의 총 비용은 USD 0.2571002919708029다. ImageGen 2.5 출력이라고 표시하지 않는다. 기존 개별 130KB·전체 1.5MB 전송 예산을 유지했다.

[이미지 출처와 재생성 방법](../../apps/web/public/brand/workflow-20260928/README.md), `manifest.json`, 재생성 스크립트와 검증 테스트를 함께 제공한다. 이미지가 실패해도 문구·작업 버튼을 유지하고 기존 아트로 한 번 복구하며 재요청 루프를 만들지 않는다.

## 이미지에서 실제 행동으로

여섯 제작 단계는 설명 이미지 자체를 클릭해도 해당 단계의 시작 링크와 같은 목적지로 이동한다. 현재 작업과 다음 작업의 링크를 모두 보존하고 한영 접근성 이름·44px 조작·키보드 초점을 검증한다. 공개 페이지 하단의 다음 작업 카드에도 목적지별 새 설명 이미지를 연결했다. 작품 갤러리와 홍보 영상 제작의 그림은 서로 구분한다. 이미지가 실패해도 제목·링크는 보존하고 1회 fallback만 시도한다.

집중 편집기·계정·관리자·개인정보 페이지에는 이 다음 작업 이미지를 추가하지 않는다. 새 이미지 때문에 사용자 원고, 일정 상태, 검수 승인 또는 게시가 변경되지 않는다.

# ToonStudio Creator Continuity & PWA v1

작성일: 2026-09-09  
대상: `/`, 공통 AppShell, Web App Manifest

## 1. 목표

사이트 경험 v3가 툰스튜디오의 전체 창작 흐름을 설명했다면, 이번 단계는 사용자가 실제로 **시작하고 다시 돌아오는 과정**을 연결한다.

1. 무엇을 만들지 선택한다.
2. 작업 호흡을 선택한다.
3. 실제 존재하는 가장 알맞은 작업 공간으로 이동한다.
4. 최근 방문한 창작 흐름을 다시 연다.
5. 지원되는 환경에서는 앱으로 설치하고 연결·오프라인 준비 상태를 확인한다.

작품 원문이나 문서 식별자를 별도 수집하지 않으며, 이 기능은 서버 계정 상태와 독립적인 기기 로컬 편의 기능이다.

## 2. Creator Launchpad

### 입력

- 목표: 자유 드로잉 / 컷툰 / 캐릭터·포즈 / 자료·재료
- 호흡: 빠른 시작 / 프로젝트

### 추천 매트릭스

| 목표 | 빠른 시작 | 프로젝트 |
| --- | --- | --- |
| 드로잉 | 2048 정사각 일러스트 프리셋 | 세로 웹툰 프리셋 |
| 컷툰 | 4컷 프리셋 | 컷툰 작업 공간 |
| 캐릭터 | 캐릭터 셰이퍼 | 캐릭터 셰이퍼 |
| 자료·재료 | 에셋 마켓 | 레퍼런스 아틀라스 |

각 조합은 설명만 제공하지 않고 실제 라우트로 연결한다. 추천 카드에는 시작 전 준비 순서 세 단계를 제공하며, Web Share API를 우선 사용하고 지원되지 않으면 클립보드 복사를 사용한다.

## 3. 최근 창작 흐름

AppShell이 라우트 전환을 관찰하되 다음 허용 목록에 해당하는 목적지만 저장한다.

- 스튜디오, 컷툰, 캐릭터 셰이퍼, 에셋 마켓
- 오늘의 영감, 리서치 데스크, 레퍼런스 아틀라스, 작가 기회센터
- 창작 갤러리, 작품 탐색, 랭킹, 연재 캘린더, 커뮤니티

정책은 다음과 같다.

- 최대 4개 목적지
- 목적지 ID 기준 중복 제거
- 최근 방문 순 정렬
- 180일이 지난 항목 제거
- 브라우저 탭 간 `storage` 이벤트 동기화
- 최근 기록과 시작 계획을 독립적으로 초기화

홈에는 최근 3개를 노출한다. 목적지 이름, 다음 행동 설명, 상대 시간을 함께 표시해 아이콘만으로 의미를 추측하지 않게 한다.

## 4. 개인정보 보호 경계

저장 키는 `toonstudio:creator-continuity:v1` 하나다.

저장하는 값:

- 허용된 목적지 ID
- 허용된 내부 경로
- 방문 시각
- 목표와 작업 호흡

저장하지 않는 값:

- 작품 내용과 캔버스 데이터
- Studio 작업 ID 또는 문서 ID
- 인증 토큰
- 임의 검색어와 쿼리 문자열
- 외부 URL

Studio 경로는 `preset=webtoon`, `preset=4cut`, `preset=illustration`만 보존한다. 그 외 쿼리와 중첩 작업 식별자는 제거한다. 저장값이 변조됐거나 구버전·만료 상태면 첫 초기화에서 파싱한 안전한 상태로 즉시 다시 기록한다.

## 5. PWA 설치와 준비 상태

### 설치 이벤트

`beforeinstallprompt`는 UI가 지연 로드되기 전에 발생할 수 있으므로 앱 엔트리에서 React 렌더보다 먼저 캡처한다.

상태:

- 설치 가능
- 프롬프트 진행 중
- 수락 / 미룸
- 설치 완료
- iOS 수동 설치
- 설치 불가

설치 가능 상태에서만 전역 설치 안내를 노출한다. 설치가 불가능하거나 이미 설치된 환경에서 강제 팝업을 만들지 않는다.

### 연결과 서비스 워커

Launchpad는 다음 상태를 텍스트와 아이콘으로 함께 표시한다.

- 온라인 / 오프라인
- 서비스 워커 활성화
- 새 버전 대기
- 설치 가능 / 설치 완료

기존 `toonspectrum:service-worker` 이벤트와 `data-studio-sw-update` 상태를 재사용하며, 서비스 워커 구현과 캐시 정책은 변경하지 않는다.

### Manifest

Web App Manifest의 카테고리를 생산성·그래픽 디자인·엔터테인먼트로 정리하고 다음 단축 실행을 제공한다.

- 창작 스튜디오
- 컷툰
- 캐릭터 셰이퍼
- 리서치 데스크

기존 검색·랭킹 중심 스크린샷 설명은 새 창작 홈 역할에 맞게 갱신한다.

## 6. 접근성

- 목표와 호흡 선택에 `aria-pressed`
- 상태 변화에 `aria-live`/`role=status`
- 모든 핵심 버튼과 링크 44px 이상
- 텍스트 레이블과 설명을 아이콘과 함께 제공
- 다크 모드 전용 대비
- 430px / 720px / 1040px 반응형 재배치
- `prefers-reduced-motion`에서 변위 애니메이션 제거
- 강제 색상 모드에서 선택·주요 액션 테두리 유지

## 7. 실패 안전성

- localStorage 접근 실패는 탐색을 막지 않는다.
- 설치 프롬프트 오류는 브라우저 메뉴 안내로 전환한다.
- Web Share 취소는 오류로 알리지 않는다.
- 클립보드 API가 없으면 선택 기반 복사 폴백을 시도한다.
- 알 수 없는 서비스 워커 이벤트 값은 무시한다.
- 오래된 MediaQueryList 환경은 `addListener`로 폴백한다.

## 8. 검증

### 단위·DOM

- 허용 경로 매칭과 중첩 경로 우선순위
- 민감 쿼리 제거
- 최근 목록 최대 개수·중복 제거·TTL
- 시작 추천 매트릭스
- 파싱 실패와 변조 데이터 폐기
- 설치 프롬프트 수락
- 온라인·오프라인 및 서비스 워커 상태 전이

### 실제 브라우저

`verify-creator-continuity.mjs`가 Chromium 데스크톱·모바일에서 다음을 검증한다.

- 저장된 계획과 선택 상태 복원
- 최근 링크의 정규화
- 민감 데이터의 초기화 시점 제거
- 선택 변경 후 새로고침 유지
- 설치 이벤트와 전역 안내
- 오프라인 상태 표시
- 수평 오버플로와 런타임 오류 없음

기존 Creator homepage quality의 브랜드 필름, 프래그먼트 포커스, 키보드 단계 선택, 반응형 스크린샷, 모바일 메뉴 포커스 복원 검증도 그대로 유지한다.

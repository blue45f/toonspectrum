## 홈 및 독립 아트

홈은 실제 DOM으로 구성한다. 검색·다섯 시작 링크·여덟 도구 이동을 보존하며 예시 컷, 대사, 캐릭터, 배경, 발행 체크와 갤러리 필터는 로컬 예시 상태만 변경한다. 예시 작품을 실제 사용자 최근 작업이나 생성된 프로젝트로 표시하지 않는다. 전체 UI 스크린샷을 기능 대신 덮지 않는다.

독립 아트 **12종·36개 WebP**, 전체 **3,000,490바이트**를 추가했다. 작은 카드에는 320px, 큰 미리보기에는 320/640px `srcSet`을 사용하며 원본 시트 PNG는 전송하지 않는다. 출처·가공·해시와 실제 모델은 [아트 원장](../../apps/web/public/brand/illustrated-20260928/README.md)에 기록했다. 실제 독립 시트 모델은 **gpt-image-2**이며 ImageGen 2.5 사용으로 표시하지 않는다. 내장 이미지 생성 시안의 모델 세부 버전은 확인되지 않았다.

## 336 URL × 두 화면 크기 전수 관찰

`audit-sitewide-visual-ux.mjs`를 변경 없는 production preview에서 실행했다. **1440×1000 / 390×844, starlight, 672개 고유 조건, 누락 0**이다. 전체 스크롤 및 이미지 로딩 후 각 화면을 캡처했고 14장 비교 시트로 전체 배치를 검토했다. 의심 화면은 원본 크기로 확대했다. 축소 시트 검토를 모든 작은 글씨·정상 데이터 기능의 검수로 확대 해석하지 않는다.

모든 672조건에서 가로 넘침, 깨진 이미지, 이름 없는 버튼, 중복 ID, 누락된 테마 토큰, 고정 요소의 가로 넘침은 **0**이었다. 15분야의 route 디자인 속성도 모두 관찰했다.

실행 조건은 **게스트 세션 200, 나머지 API 503 fixture, GPU 비활성**이다. 원본은 **실패 50 / 경고 668**, readiness는 **ready 632 / blocked 2 / error 30 / empty 8**이다. 실패 결과를 삭제하거나 전체 통과로 바꾸지 않았다.

- 제작 관리 상세 30조건은 가짜 `visual-audit` 프로젝트와 API 503으로 오류 상태가 표시되었다. 실제 로그인 프로젝트의 정상 화면 검증이 아니다.
- 배경 3D 8조건은 포탈 안에 GPU 사용 불가·다른 엔진 선택·재시도 UI가 표시됐지만 일반 route 본문 수집 경계에서는 empty/timeout으로 판정되었다. 원본 화면에서 복구 UI를 확인했으며 GPU 렌더 성공으로 보고하지 않는다.
- 캐릭터·포저 12조건에는 GPU를 사용할 수 없는 조건의 페이지 예외가 기록되었다. 실제 그래픽 가속 및 3D 작업 성공은 별도 검증 대상으로 남는다.

원본 경고에는 대비 자동 판정 보류 668조건, 잘림 76조건, 작은 조작 영역 40조건, 작은 글씨 23조건, 숨김 글씨 2조건이 있다. 잘림 167노드 중 다수는 스크린리더/반응형 전용 텍스트와 skip link지만, 드로잉 도구 설명 22노드는 별도 정밀 검토 대상이다. 작은 영역은 편집기 데스크톱 밀도·비초점 요소와 실제 미달을 구분해야 한다. 일괄 크기 변경으로 기존 도구 배치를 훼손하지 않았다. `/studio/import`의 숨김 경고는 진입 애니메이션 영역 관측이므로 아래 대표 동선 결과와 구분한다. 전체 WCAG 준수 판정이 아니다.

## 전수 검토에서 보완한 사항

- 홈 모듈 제목의 기존 대형 h2 스타일 상속을 수정하고 워드마크와 보조 문구의 우선순위를 정리했다. 작은 카드의 8/9px 문구를 10px 이상으로 보완했다.
- 밝은 테마에서 어두운 히어로 위 워드마크와 예시 작품 제목이 묻히던 문제를 수정했다. 뒤이은 아홉 테마 검사에서 Aurora·Blossom의 4조건 대비 실패를 발견해 동일한 밝은 표면 계약으로 수정했다.
- `/create/promo`, `/showcase/promo`의 고정 흰색 편집 UI를 공통 테마 토큰으로 전환했다. 영상 출력 캔버스의 픽셀·색상·녹화·오디오 동작은 수정하지 않았다.
- 스토리월드 복원/저장소 잠금 오류 분기에도 패널·문구·44px 복구 버튼·초점·긴 오류 줄바꿈을 적용했다. 저장소 재시도와 원본 보존 동작은 유지했다.

후속 runtime 변경은 위 홈 테마와 홍보 영상·스토리월드 표면에 한정한다. 최초 672개 원장은 수정 전 검증 시점을 보존하고 해당 범위의 최종 빌드 재검증을 아래에 별도로 기록한다.

### 최종 강제 색상 및 번들

강제 색상 첫 검사에서는 홈의 글자 소재 예시 `Aa`가 노란색/흰색으로 표시되어 PC·모바일 **2조건**에서 대비 1.2:1을 기록했다. 해당 예시만 시스템 `CanvasText`/`Canvas`와 20px로 보완했다. 일반 테마의 색과 크기는 유지한다. 최종 production의 네 경로 × 두 화면 **8/8 ready, 확정 위반 0, 잘림 0**을 확인했다. `forced-colors-production`의 최초 실패와 `forced-colors-final-production`의 재검증을 구분한다.

## 적용 상태 및 남은 확인

이 문서는 로컬 소스·빌드·관측 근거다. **main 병합과 운영 배포는 실행하지 않았다.** 원격 PR의 Checks와 최종 커밋은 별도 정본으로 확인한다. API·DB·환경변수·마이그레이션·운영 도메인 및 배포 구성은 변경하지 않았다.

실제 로그인 프로젝트·회차·검토 기록과 그래픽 가속을 사용하는 3D 정상 동작, 원장에 남은 작은 글씨·조작 영역·대비 자동 판정 보류의 정밀 검수는 남아 있다. 사이트에 존재하는 모든 사용자 데이터 조합이나 모든 GPU 장치에서 작업 성공을 보증하지 않는다. 공통 시각체계 적용과 각 도구의 완전한 실사용 검증을 구분한다.

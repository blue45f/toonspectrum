## 검증 증거

- 전체 Web/API typecheck: `pnpm run typecheck` 통과. 테스트·입력 파일을 제외해 범위를 축소하지 않았다.
- 변경 기능·DB·인접 회귀 17개 파일 **253개 테스트 통과, 생략 없음**. 로컬 전용 PostgreSQL에서 동시 생성/정원/역할/초대/정책 변경/실제 비소유자 DB 권한을 실행했다.
- 실제 비소유자 DB 역할은 감사·receipt 수정과 마지막 소유자 삭제를 거절한다. 공개 권한 오염을 탐지하고 선언된 계약으로 정규화하는 검사도 포함한다.
- Chromium 관리자 화면 **4개 시나리오 통과**: 무료 기본값, 미검토 유료 전환 차단, 검토 fixture의 양방향 전환/새로고침, 390px 표시, 비관리자 차단. 브라우저 테스트는 API fixture를 사용하며 실제 DB 검증은 별도 위 통합 테스트에서 수행했다.
- 독립 Admin production build, Admin/공용 계약 typecheck, architecture boundary 검증 통과.
- CI에서 발견한 API 계약 subpath의 배포 export 누락을 수정했다. 실제 API build, 런타임 import 검사(788 compiled files / 2451 imports), 배포 경계 27개·법적 문서 경계 7개 테스트를 추가로 통과했다.
- Admin 브라우저 테스트는 `apps/admin/tests/operation-policy.e2e.ts`와 전용 설정으로 분리해 기본 Studio E2E/단위 테스트 수집을 오염시키지 않는다.
- 기존 production-collaboration 모듈 추가 회귀: 77개 통과. 이 추가 실행에서 환경변수 없이 생략된 DB 12개는 위 PostgreSQL 실행에서 모두 별도로 통과했다.
- 코드 lint와 Git hooks/CI를 유지한다. main 병합은 운영 배포나 유료 전환 승인이 아니다.

## 아직 완료가 아닌 설계 범위

현재 원고 작성/검수/협업에는 기존 구현이 있지만, 아래 설계 요구 전체를 신규 운영 정책과 끝까지 연결했다는 증거는 아직 없다. 함수/파일이 존재한다는 이유로 완료 처리하지 않는다.

1. 회차·공정별 불변 DeliveryVersion manifest, 페이지 수정본 중복 제거, 업로드 검증/저장량 예약/GC의 통합.
2. 새 버전 뷰어의 페이지 ID 기반 비교·주석·필수 피드백·원자적 최종본 지정과 기존 제출/승인 연결 전 과정.
3. 텍스트 공동 편집의 영속 ACK·편집 epoch 종료·고정 스냅샷·동시 완료·한글 IME 검증.
4. 보호 공유의 모든 원본/파생물 요청 재검증·워터마크 생성·회수, 실제 파일 형식별 export 전 과정.
5. 기존 Studio/폰트/브러시/WASM/3D/모델 전체의 Rights BOM, 배포 산출물·캐시·정적 URL 검증과 모드별 기능 연결.
6. SaaS 상품·명시적 가격/동의·결제·정기 청구·환불, 고객별 entitlements. 현재 checkout/자동 청구는 두 모드 모두 비활성.
7. 실제 AI 음영 제공자/품질/사용권/비용 통제. 현재 준비되지 않은 제공자는 실행하지 않는다.

이 항목들은 `creco-operating-modes-v1.2-20260922.md`의 경계에 따라 후속 구현·검증이 필요하다. 이번 변경을 '설계한 모든 기능 구현 완료'로 표현하지 않는다.

## 운영 반영

운영 Neon에는 읽기 확인만 했으며 새 migration은 로컬 전용 DB에서만 실행했다. 운영 API/Web/Admin, 환경변수, paid 모드, 라이선스 승인, 결제/외부 AI는 변경하지 않았다. 0084–0086 및 최소 권한 SQL을 운영에 적용하는 것은 별도의 승인된 migration/배포 단계다.

작업용 local Postgres와 synthetic 사용자·토큰·승인 근거는 운영 데이터나 실제 법적 승인이 아니다. 라이선스 불명확 코드를 무료로 제공해도 자동으로 적법해지는 것은 아니며, 이 기능은 검토 기록과 실행 조건을 분리하는 운영 장치다.

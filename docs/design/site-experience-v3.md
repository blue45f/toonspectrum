# ToonStudio Site Experience v3

작성일: 2026-09-09  
대상: `/`, 공통 헤더·모바일 내비게이션·푸터

## 1. 목표

툰스튜디오를 기능 모음이 아니라 **아이디어가 작품이 되는 하나의 창작 흐름**으로 인식하게 만든다.

기존 구조의 장점인 창작자 중심 메시지, 브라우저 기반 스튜디오, 작품 탐색과 커뮤니티를 유지하면서 다음 문제를 해결한다.

- 홈 하단에 별도 리서치 허브가 덧붙어 두 개의 랜딩처럼 보이는 문제
- 데스크톱 메뉴와 모바일 전체 메뉴가 서로 다른 우선순위로 보이는 문제
- 기능 이름 중심의 진입점 때문에 처음 온 사용자가 어디서 시작할지 판단해야 하는 문제
- 창작 도구, 작품 탐색, 영감·리서치, 커뮤니티가 서로 분리된 서비스처럼 느껴지는 문제
- 모바일 전체 메뉴의 많은 목적지가 같은 시각 무게로 나열되는 문제

## 2. 핵심 콘셉트

### Creative Atelier + Spectral Ink

따뜻한 종이와 잉크를 기본 표면으로 사용하고, 툰스튜디오의 스펙트럼을 오렌지·라임·민트·바이올렛의 절제된 포인트로 표현한다.

- **Atelier**: 작업대, 캔버스, 레이어와 같은 실제 창작 도구의 감각
- **Spectrum**: 서로 다른 장르·표현·창작자의 공존
- **Connected flow**: 영감 → 조사 → 제작 → 공유가 끊기지 않는 경험
- **Friendly precision**: 전문 도구의 신뢰감은 유지하되 용어와 진입은 친절하게

## 3. 정보 구조

전체 사이트를 URL이나 내부 도메인이 아니라 사용자의 목적에 따라 네 그룹으로 통합한다.

| 목적 | 설명 | 주요 목적지 |
| --- | --- | --- |
| 만들기 | 아이디어를 장면과 이야기로 | 스튜디오, 컷툰, 캐릭터 셰이퍼, 에셋 마켓 |
| 발견하기 | 취향과 흐름에서 다음 작품을 | 작품 탐색, 랭킹, 연재 캘린더, 맞춤 추천 |
| 성장하기 | 영감·자료·기회를 작업으로 | 오늘의 영감, 리서치 데스크, 작가 기회센터, 인사이트 |
| 함께하기 | 작품과 생각을 사람들과 | 창작 갤러리, 리뷰, 커뮤니티, 놀이터 |

설정과 내 서재는 콘텐츠 목적지가 아닌 개인 유틸리티로 분리한다.

### 데스크톱 1차 메뉴

인지 부하를 줄이기 위해 홈, 작품 탐색, 리서치, 커뮤니티만 1차 탐색에 둔다. 스튜디오는 가장 중요한 전환 행동이므로 독립 CTA로 유지한다. 전체 메뉴는 사이트맵으로 연결한다.

### 모바일 하단 탭

한 손 조작과 반복 사용 빈도를 기준으로 다음 다섯 개를 유지한다.

1. 홈
2. 작품 탐색
3. 스튜디오
4. 에셋 마켓
5. 내 공간

가운데 스튜디오를 시각적으로 올려 창작 시작 행동을 명확하게 한다. 정밀 편집 화면처럼 자체 도구막대를 사용하는 몰입형 라우트에서는 기존처럼 하단 탭을 숨긴다.

## 4. 홈 화면 흐름

### 4.1 Hero — 바로 이해하고 시작

- 첫 문장에서 `아이디어 → 첫 장면` 가치 제안 전달
- 스튜디오 시작을 단일 Primary CTA로 유지
- 브랜드 필름은 Secondary CTA
- 브러시, 컷, 3D, 에셋의 핵심 역량을 짧은 칩으로 노출
- 실제 편집기의 구조를 추상화한 인터랙티브 작업대 미리보기 제공
- 드로잉·컷툰·입체 구상의 시작 방식을 즉시 전환

### 4.2 Quick Start — 기능이 아니라 결과 선택

사용자가 내부 기능 이름을 학습하지 않아도 다음 결과에서 출발하게 한다.

- 자유롭게 그리기
- 컷으로 이야기하기
- 입체적으로 구상하기
- 재료에서 영감 얻기

### 4.3 One Creative Loop — 서비스 전체의 이유 설명

`감각 깨우기 → 근거 모으기 → 장면 만들기 → 사람과 연결하기`를 하나의 흐름으로 표현한다. 서로 다른 도메인의 기능을 나열하지 않고 다음 행동으로 연결한다.

### 4.4 Creator Desk — 리서치 허브 통합

기존 홈 뒤에 별도 카드로 붙던 리서치 허브를 홈의 정식 섹션으로 흡수한다.

- 오늘의 영감
- 리서치 데스크
- 레퍼런스 아틀라스
- 작가 기회센터

어두운 작업대 표면을 사용해 일반 소개 섹션과 구분하면서도 전체 디자인 토큰과 연결한다.

### 4.5 Discover — 창작과 감상의 순환

작품 탐색, 랭킹, 캘린더, 커뮤니티를 `창작 다음의 영감`으로 연결한다. 창작 도구와 콘텐츠 플랫폼이 따로 보이지 않도록 같은 카드 언어와 전환 패턴을 사용한다.

### 4.6 Brand Film / FAQ / Closing

기존 브랜드 필름의 재생, 캡션, 오류 복구, 챕터 탐색을 그대로 재사용한다. FAQ와 마지막 CTA는 새 표면과 타이포그래피로 통합한다.

## 5. 비주얼 시스템

### 표면

- Light: 따뜻한 종이색 배경과 흰색에 가까운 작업 카드
- Dark: 기존 따뜻한 잉크 계열 토큰을 따르는 짙은 작업실 표면
- 카드 계층은 과한 그림자 대신 선, 밝기 차이, 얕은 상승감으로 구분

### 색상

- Primary action: 잉크색 또는 전역 Accent
- Creative highlight: 오렌지
- Growth / positive: 라임·민트
- Spatial / research: 바이올렛·스카이
- 상태 전달은 색상만 사용하지 않고 텍스트·아이콘·선택 상태를 함께 제공

### 타이포그래피

- Display: Space Grotesk 기반의 짧고 강한 제목
- Body: Pretendard 기반의 읽기 쉬운 한국어 본문
- 숫자·Overline은 작은 대문자와 충분한 자간으로 정보 계층 표현
- 한글 문장은 `word-break: keep-all`, 균형 제목은 `text-wrap: balance` 사용

### 움직임

- Hover는 1–4px 범위의 얕은 상승과 화살표 이동만 사용
- 핵심 작업 미리보기는 상태 변경으로 표현하고 자동 애니메이션에 의존하지 않음
- `prefers-reduced-motion`에서는 이동과 전환을 사실상 제거

## 6. 접근성과 사용성

- 모든 링크와 버튼에 44px 이상의 모바일 터치 영역 확보
- `:focus-visible`에 3px 포커스 링과 충분한 간격 제공
- 홈 섹션 점프 후 대상 제목으로 키보드 포커스 이동
- 선택형 시작 방식은 `aria-pressed`로 상태 전달
- 편집기 미리보기는 `figure`와 `figcaption` 구조 사용
- 장식 요소와 아이콘은 스크린리더에서 제외
- 첫 FAQ는 `defaultOpen`으로 제공하되 사용자가 자유롭게 닫을 수 있음
- 기존 모바일 메뉴의 포커스 루프, Escape 닫기, 배경 `inert`, 스크롤 잠금, 호출 버튼 포커스 복원을 유지
- 데스크톱 전환 시 숨은 다이얼로그의 포커스 트랩과 스크롤 잠금을 즉시 해제
- 다크 모드, 430px 소형 화면, 720px 모바일, 900px 태블릿, 1180px 중형 데스크톱을 별도 보정

## 7. 구현 구성

- `site-navigation.ts`: 헤더·모바일 메뉴·푸터가 공유하는 단일 정보 구조
- `CreatorHomeExperience.tsx`: 새 홈 화면과 연결된 사용자 여정
- `creator-home-experience.css`: 홈 전용 비주얼 토큰과 반응형 규칙
- 기존 `CreatorHomePage.tsx`: 브랜드 필름 로직과 기존 회귀 테스트를 위해 유지
- 루트 홈 래퍼: 새 경험 하나만 렌더하여 중복 랜딩 제거

## 8. 검증 기준

- 정보 구조 그룹 내 URL과 ID 중복 없음
- 데스크톱 1차 내비게이션은 네 개의 핵심 목적지만 노출
- 모바일 탭은 다섯 개이며 스튜디오가 중앙
- 모바일 전체 메뉴의 마지막 포커스 대상은 내 서재로 유지
- 한국어·영어 모든 내비게이션 목적지에 레이블과 설명 존재
- 홈은 Studio 엔진이나 Remotion을 초기 번들로 가져오지 않음
- 다크 모드, 포커스, 모바일 브레이크포인트, Reduced Motion 규칙 존재
- 기존 브랜드 필름과 모바일 셸 접근성 테스트가 계속 통과해야 함

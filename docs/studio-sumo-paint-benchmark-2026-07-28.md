# ToonSpectrum Studio × Sumo Paint 벤치마크

작성일: 2026-07-28

검토 대상:

- `https://paint.sumo.app/?lang=ko`
- `https://paint.dev.sumo.app/`
- `https://www.sumo.app/`
- `https://sumo.app/fi/api`

이 문서는 Sumo Paint의 화면·공개 기능 표면을 기준으로 장점을 분석하고,
ToonSpectrum에 필요한 일반적인 편집기 원칙만 독립적으로 구현하기 위한
기준을 고정한다. 제품 고유 에셋, 브러시 데이터, 코드, 상표 표현은 복제하지
않는다.

## 결론

Sumo Paint의 가장 큰 장점은 기능 목록 자체보다 캔버스에서 손을 떼지 않고
도구를 찾고 조절할 수 있는 짧은 상호작용 경로다. 하단 브러시 선반, 우측의
크기·불투명도 슬라이더, 선택 도구에 맞춰 바뀌는 작은 보조 도구 묶음, 전체
화면 메뉴가 같은 원칙으로 동작한다.

ToonSpectrum은 웹툰 제작, 벡터·픽셀 혼합 문서, 3D, 협업, 비파괴 효과에서
범위가 더 넓다. 따라서 Sumo의 메뉴 모양을 복제하기보다 다음 세 가지를
제품 원칙으로 흡수한다.

1. 자주 바꾸는 값은 캔버스 가까이에 두고 한 번의 제스처로 조절한다.
2. 브러시는 이름의 수가 아니라 실제 촉·흐름·간격·압력 반응으로 구별한다.
3. 필터는 이미지 파일을 먼저 첨부하도록 강제하지 않고 현재 편집 가능한
   픽셀 결과를 명확히 준비한 뒤 미리보기와 적용을 제공한다.

## 직접 확인한 강점

### 캔버스 중심 UI

- 아이콘 중심의 얇은 상단 바와 캔버스 전체 화면 구성이 작업 면적을 보존한다.
- 브러시 선반은 화면 아래에 수평으로 놓여 있고 선택한 브러시가 시각적으로
  들려 보여 현재 상태를 즉시 구별할 수 있다.
- 크기와 불투명도는 캔버스 오른쪽 가장자리의 세로 조절기로 빠르게 바꿀 수 있다.
- 대칭, 원근, 중력, 회전과 같은 보조 도구는 작은 부동 팔레트로 분리돼 주
  도구막대를 과도하게 늘리지 않는다.
- 전체 기능은 햄버거 메뉴의 카테고리와 상단 빠른 명령으로 다시 찾을 수 있다.

### 브러시 제작과 품질 제어

- 공식 제품 소개는 300개가 넘는 브러시와 효과를 명시한다.
- 공개된 현재 앱 표면에는 연필, 일반 브러시, 다색, 텍스처, 저장 브러시가
  카테고리로 분리돼 있다.
- Brush Tip, Basic Settings, Dynamics, Randomness를 독립 축으로 편집하고
  사용자 프리셋으로 저장한다.
- 기본·다색·헤어·구름·3D·기계·문자 계열 팁과 사용자 팁·텍스처를 함께 다룬다.
- 이미지를 Coloring Template, Brush Tip, Texture, Brush로 전환하는 짧은
  자산 재사용 경로를 제공한다.

### 필터와 픽셀 도구

- Move, Select, Brush, Gradient, Text, Shapes, Adjustment Brush, Dashed Line,
  Paintbucket, Smudge를 같은 도구 체계에서 제공한다.
- Displace, Pixellate, Spin Blur, XY Blur, Hexallate, Kaleidoscope, Clarity,
  Halftone, Detect Edges가 렌즈 형태로 노출된다.
- Cyan–Red, Magenta–Green, Yellow–Blue 색 균형과 Hue, Exposure, Brightness,
  Contrast, Saturation, Vibrance를 한 조정 화면에서 다룬다.
- 레이어 추가·복제·병합·변형과 레이어/마스크 가져오기, 전체 레이어 내보내기가
  한 메뉴 흐름에 있다.
- Full HD, 세로 Full HD, 4K, 정사각형, 스토리, YouTube, 종이 규격을 새 문서
  프리셋으로 제공한다.

### 외부 연동

공개 API는 URL 이미지, 마스크, 캔버스 폭·높이, 초기 확대율, 작업 식별자,
저장 대상 URL을 인자로 받아 편집기를 시작할 수 있다. ToonSpectrum은
외부 POST 대상에 임의로 원본 데이터를 보내는 모델을 그대로 따르지 않고,
권한 manifest와 출처가 있는 안전한 가져오기/내보내기 계약으로 확장한다.

## 수용하지 않는 부분

- “300개”라는 숫자를 맞추기 위해 같은 렌더러 설정에 이름만 바꾼 브러시를
  추가하지 않는다. 같은 계열이라도 압력, 흐름, 간격, 팁, 질감 중 적어도
  하나가 실제 출력에서 구별돼야 한다.
- Sumo의 에셋, 브러시 팁 이미지, 프리셋 수치, 코드나 메뉴 외형을 복사하지 않는다.
- 필터 적용을 위해 사용자가 모르게 벡터 원본을 파괴적으로 래스터화하지 않는다.
- 외부 URL로 문서를 전송하는 범용 `target` 파라미터는 도입하지 않는다.
  명시적 권한, 호스트 허용 목록, 크기·형식 예산을 갖는 가져오기/내보내기
  adapter만 허용한다.
- AI 보정은 비용과 개인정보 경계를 숨기지 않는다. 로컬/브라우저 처리 우선,
  서버 모델은 명시적 실행과 공급자 failover 정책을 따른다.

## 완료 게이트

- 브러시 카탈로그의 모든 항목은 실제 런타임 엔진 계약과 연결되고, 동일 별칭은
  의도된 변형인지 검증한다.
- 최소 불투명도와 흐름을 정규화해 에어브러시·텍스처 붓이 “보이지 않는 붓”이
  되지 않도록 하되 의도적인 저농도 워시는 유지한다.
- 필터/조정은 이미지, 현재 픽셀 레이어, 벡터 선화에서 각각 진입 가능 여부와
  다음 행동을 제공한다.
- 미리보기는 원본을 변경하지 않고 취소 가능하며, 적용은 한 번의 undo/CRDT
  트랜잭션이어야 한다.
- 비활성 명령에는 이유가 있고, 가능한 경우 `편집 가능한 복사본 만들기` 같은
  직접 복구 행동을 제공한다.
- 데스크톱 포인터, 펜 입력, 390px 터치 화면에서 현재 도구·크기·색·선택 상태가
  가려지지 않는다.

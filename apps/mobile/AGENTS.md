# 모바일 앱 작업 규칙

이 디렉터리에서는 루트 `AGENTS.md`와 이 규칙을 함께 적용한다.

- Web 전용 API와 브라우저 전용 전역을 모바일 런타임에 직접 가정하지 않는다.
- 네이티브 권한, 파일·미디어 접근, 앱 생명주기, 오프라인·재시도 상태를 명시적으로 처리한다.
- 플랫폼별 분기는 공통 계약과 분리하고 iOS/Android의 실패 동작을 각각 검증한다.
- 민감한 값은 번들, 로그, 로컬 저장소에 평문으로 남기지 않는다.
- 사용자 작업 중단을 막기 위해 저장·동기화·업로드의 재개 가능성을 검토한다.
- 최소 검증은 `pnpm harness:verify`와 `pnpm mobile:doctor`다.
- 네이티브 미디어 변경은 `pnpm verify:mobile-native-media`를 실행한다.

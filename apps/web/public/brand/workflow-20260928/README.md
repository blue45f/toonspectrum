# 제작 단계와 작업 역할을 설명하는 이미지

상태: current. 2026-09-28 추가한 설명용 이미지 12종이다. 각 장면은 하나의 역할과 산출물, 다음 작업과의 관계를 표현한다.

| 이미지 | 설명하는 역할 |
| --- | --- |
| plan | 대본·인물 관계도로 이야기 기준 만들기 |
| storyboard | 대본을 장면과 컷으로 나누기 |
| create | 선화·채색·3D 포즈를 사용해 원고 제작하기 |
| collaborate | 담당자별 작업을 다음 단계로 인계하기 |
| review | 원고의 수정 위치를 표시하고 검수본 비교하기 |
| publish | 완성 원고를 모바일에서 확인하고 내보내기 |
| assets | 소재를 선택해 원고에 추가하기 |
| learn | 예제와 결과물을 비교하며 익히기 |
| ai | 도우미의 제안 중 사용자가 후보 선택하기 |
| recovery | 이전 버전으로 돌아가 작업 복구하기 |
| rights | 작품의 사용 권리 확인하기 |
| community | 작품을 둘러보고 의견 나누기 |

## 제작 방식과 비용

`scripts/generate-workflow-illustrations.py`가 기존 `illustrated-20260928`의 AI 생성 캐릭터·배경을 역할별 벡터 도형과 로컬 합성한다. 새 외부 이미지 API 요청, 결제, 크레딧 충전은 실행하지 않는다. 독립적인 새 ImageGen 2.5 출력으로 표시하지 않는다. 모든 사용자 텍스트·링크·체크 상태는 HTML/React가 소유한다.

각 장면을 320×200, 640×400, 960×600의 WebP로 만들었다. 36개 파일 전체는 1,238,300바이트다. `manifest.json`에 제작 방식, 파일 크기, SHA-256을 기록한다. 원본 사용자 작품이나 실제 저장·승인·게시 결과가 아닌 **기능 설명용 예시**다.

## 사용과 복구

공통 `WorkflowIllustration` 컴포넌트가 반응형 `srcSet`, 크기 예약, 지연 로딩, 한국어/영어 대체텍스트와 1회 이미지 fallback을 제공한다. 이미지 실패 시 원고·작업 버튼·설명은 유지한다. 집중 편집기, 캔버스, 승인·게시 상태를 이미지가 대신하지 않는다.

재생성은 저장소 루트에서 `python3 scripts/generate-workflow-illustrations.py`를 실행한다. Pillow가 필요하며 네트워크는 필요하지 않다. `scripts/workflow-illustration-assets.test.mjs`로 종류·변형·해시·규격·전송 예산을 검사한다.

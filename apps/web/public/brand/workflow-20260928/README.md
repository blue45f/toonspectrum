## 생성 정본

3072×1280, 3×2 시트 2장을 `gpt-image-2`, high 설정으로 생성했다. 제작 시트 ID는 `rs4O3CxbxSHemdzUc6aM`, 하위 기능 시트 ID는 `mWPFReR0rpIqUt9evF6i`다. 실제 청구는 총 **USD 0.2571002919708029**이며 외부 생성 2건이다. 변형 4개를 요청했지만 실제 반환은 노드당 1장이므로 8장 생성으로 기록하지 않는다.

이 그림은 기능 설명용 예시다. 실제 사용자 원고·팀 인원·검수 완료·자동 게시 결과가 아니며 글자·단계·버튼·권한 상태는 React DOM이 소유한다. 내장 이미지 도구의 별도 목업은 미술 방향 참고용이며 이 정본 파일의 생성 모델과 혼동하지 않는다.

## 최적화·복구·재생성

`scripts/prepare-workflow-ai-art.py <원본-디렉터리>`를 실행한다. 디렉터리에는 위 생성물의 `production-atlas.png`, `support-atlas.png`가 있어야 한다. 원본 크기를 검증하고 경계선 4px를 제거한 뒤 비율을 유지해 축소한다. 원본보다 확대하지 않으며 WebP 품질은 72다. 파일별 해시·크기·자르기 영역은 `manifest.json`에 남긴다. 36개 파일의 전체 예산을 확인한 뒤에만 정본을 저장한다.

원본 PNG는 운영 정적 자산에 넣지 않는다. 원본·생성 식별자·실측 결과는 작업자의 `toonstudio-visual-workflow-20260928/generated` 검증 디렉터리에 보존한다. 서명된 URL·키·쿠키는 저장소에 넣지 않는다.

초기 로컬 합성 시안 생성기 `scripts/generate-workflow-illustrations.py`는 비교용으로 보존하며 `.qa/workflow-composition`에만 출력해 새 정본을 덮지 않는다. 초기 시안의 비용 0 기록과 새 AI 정본의 비용을 구분한다.

공통 `WorkflowIllustration`은 크기 예약, `srcSet`, 지연 로딩, 한영 대체텍스트, 1회 이미지 fallback을 제공한다. 그림이 실패해도 제목·현재 작업·다음 목적지는 유지한다. `scripts/workflow-illustration-assets.test.mjs`에서 출처·해시·변형·형식·전송 예산을 검증한다.

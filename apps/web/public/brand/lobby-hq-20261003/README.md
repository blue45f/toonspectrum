# ToonStudio 로비 고해상도 일러스트 — 2026-10-03

상태: current. 스튜디오 크리에이터 로비(`StudioCreatorLobby`) 전용 브랜드·예시 아트다.
사용자 프로젝트, 저장된 원고, 실제 3D 렌더 결과와 구분한다.

## 왜 새 세트인가

기존 `brand/illustrated-20260928` 세트는 2048×1360 시트 2장을 3×2로 나눈 것이라 셀
원본이 최대 677px에 머물렀다. 로비 히어로는 약 600 CSS px 너비로 표시돼 레티나에서
0.25~0.37배로 확대 표시됐고, 이 폴더는 그 해상도 부족을 로비 범위에서 해소한다.
구 세트는 사이트 전역(공개 홈·자료·커뮤니티 등)이 공유하므로 건드리지 않는다.

## 출처

- `hero`: 저장소 기존 고해상도 브랜드 아트 `public/images/hero-studio.webp`
  (2048×1152, 밤의 창작 작업실)를 재사용해 파생본만 새로 만들었다.
- `materials`: 저장소 기존 고해상도 브랜드 아트 `public/images/section-studio-lobby.webp`
  (1920×1280, 작품이 걸린 갤러리)를 재사용해 파생본만 새로 만들었다.
- 나머지 9종은 2026-10-03에 내장 이미지 도구로 신규 생성했다. 기존 세트의 화풍
  (남색·보라 밤 팔레트, 네온 핑크·청록, 페인터리 하이엔드 애니메이션 아트)을
  참조 이미지로 고정했다. 구체적인 모델 버전은 확인되지 않았다.
  - 시트 A (1600×1600, 2×2): canvas-noir · storyboard · character-pink · background-city
  - 시트 B (1600×1600, 2×2): blank-canvas · background-classroom · project-romance · character-blue
  - 단독 (1600×1600): project-crimson
- `luna`(AI 디렉터 아바타)는 표시 크기가 64 CSS px이라 기존 세트 해상도로 충분하고,
  마스코트 정체성 유지를 위해 교체하지 않았다. 로비 모델이 이름별로 구 세트로
  폴백하는 이유다.

## 가공과 전송

가공 스크립트는 작업 실행자의 검증 디렉터리에 보존한다
(`prepare-lobby-hq-art.py`: 시트 구분선을 자동 검출해 셀 경계를 제외하고 자른 뒤
WebP q82 파생본을 만든다. 원본보다 확대하지 않는다).
파일별 해시·크기·차원은 `manifest.json`에 기록했다.

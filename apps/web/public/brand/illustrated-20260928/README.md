## 출처

사용자가 제공한 어두운 남색·보라·청록 애니메이션 UI 시안과 이 대화에서 내장 이미지 도구로 만든 시안을 미술 방향의 참조로 사용했다. 버튼·레이블·입력·탭은 이미지에 포함시키지 않고 실제 DOM으로 구현한다.

독립 아트 정본은 ElevenLabs 이미지 작업 공간의 **gpt-image-2**, 2K, high 설정으로 생성한 2048×1360 시트 2장이다. 내장 이미지 도구의 구체적인 모델 버전은 확인되지 않았다. 이 폴더의 파일을 ImageGen 2.5 산출물이라고 표시하지 않는다.

- 캐릭터 시트: `9TXGBhwhK0JwwpKm8TCv` — 검은 머리 주인공, 흑백 원고, Luna, 분홍·푸른 캐릭터, 벚꽃 도시.
- 제작 시트: `XUEKIltKGnuYmkBa5k4V` — 로맨스·액션 표지, 콘티, 소재 정물, 교실, 빈 캔버스.

생성 비용은 각 시트 USD 0.15841393486805162, 합계 약 USD 0.32로 도구 결과에 기록되었다. 4개 변형 요청과 달리 실제 응답은 호출당 1장이다.

## 가공과 전송

`scripts/prepare-illustrated-ui-art.py`가 3×2 시트를 분리하고 각 셀의 경계선 3px를 제외한다. 원본보다 확대하지 않는다. 각 아트에는 320px, 640px, 원본 셀 크기의 WebP가 있다. 전체 12종·36개 파일은 3,000,490바이트다.

원본 PNG는 서비스에서 전송하지 않는다. 해시·크기·생성 ID·자르기 영역·한국어 설명은 `manifest.json`에 기록했다. 초기 홈의 작은 카드에는 320px 파생본을 사용하며 큰 미리보기는 반응형 `srcSet`을 사용한다.

재생성: `python3 scripts/prepare-illustrated-ui-art.py characters <캐릭터-원본.png>` 및 `production <제작-원본.png>`. 원본은 작업 실행자의 검증 디렉터리에 보존하며 signed URL이나 인증정보는 저장소에 넣지 않는다.

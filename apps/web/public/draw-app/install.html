같은 엔진,
더 드로잉답게.

별도의 간이 편집기가 아닙니다. 서비스 안에서 쓰는 동일한 Studio 문서·브러시·레이어·저장 엔진을 캔버스 중심 UI로 실행합니다. 설치해 앱처럼 열어도, 사이트 안에서 순수 드로잉으로 전환해도 기능과 작업 데이터는 그대로 이어집니다.

  • 전문 브러시 엔진
    필압·기울기·안정화·브러시 라이브러리·즐겨찾기/최근 브러시
  • 레이어·선택·변형
    레이어, 마스크, 블렌딩, 선택·변형·퀵마스크와 편집 도구
  • 프로 작업 흐름
    PSD/프로젝트 입출력, 히스토리, 자동 저장, 백업과 복구
  • 캔버스 우선 UX
    퀵 액세스, 컬러 휠, 플로팅 팔레트, 캔버스만 보기와 멀티터치 제스처

순수 드로잉은 제품 분기가 아니라 UI 프레젠테이션입니다. 언제든 “전체 스튜디오”로 돌아가도 같은 문서가 열리고, 다시 드로잉 프레젠테이션으로 전환해도 별도 변환이나 복사가 필요 없습니다.

브라우저 설치 가능 여부를 확인하고 있습니다.

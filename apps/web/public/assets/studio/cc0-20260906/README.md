# ToonSpectrum CC0 자산 배포 묶음

- 상태: **검토된 정적 배포 자료**
- 생성 기준일: **2026-09-06**

원본 파일은 `assets/`에 있으며 `index.html`에서 검색·다운로드할 수 있다.

- GLB는 texture를 내장하며 Studio 3D model import에서 사용할 수 있다.
- surface image는 material base-color texture로 사용할 수 있다. 별도 companion PBR map은 제공하지 않는다.
- effect mask는 512px 이상 native mask이며 전체 panel artwork가 아니다.
- source와 license record를 파일과 함께 유지한다.
- font, 유료 자산, 사용자 upload, 사용자 작품은 포함하지 않는다.
- 기술 검사, 제외 항목과 duplicate 기록을 보존한다.

예술 검토와 Studio runtime round-trip은 이 배포 묶음의 존재와 별도의 release gate다.

# ToonStudio refined prop pack v8

These original Blender models are released under CC0 1.0, consistent with the
first-party source pack. Author: ToonSpectrum.

Source generator: `scripts/blender/generate_studio_refined_props_v8.py`.
Editable Blender sources and comparison renders are retained outside the web
bundle in `artifacts/studio-asset-quality-v8/`.

Models: `hanging_sign.glb`, `traffic_light.glb`, `mailbox.glb`, `blackboard.glb`,
`desk.glb`, `chair.glb`, `sofa.glb`, `bubble_tea.glb`, `ice_cream_cone.glb`,
`fox_mask.glb`, and `robot_pet.glb`.

The previous version's URLs remain available for existing projects. The new
revision uses its own directory; it must not overwrite those original files.

# ToonSpectrum webtoon environment pack v7

All delivered GLB geometry, generated 128px material textures, thumbnails, and scene arrangement in this directory were authored by ToonSpectrum and released under **CC0-1.0**.

Generator: `scripts/blender/generate_environment_pack_v7.py` with Blender 5.2.

A no-cost web-generator preview was used only to review subject coverage for the rooftop set. No third-party model, image, texture, font, or remote runtime resource is embedded in the delivered files. The corner-store and street-prop sets are original procedural compositions produced by the same generator.

License: https://creativecommons.org/publicdomain/zero/1.0/

Review status is separate from licensing: each thumbnail records one reviewed oblique overview and does not claim all-angle artistic approval.
